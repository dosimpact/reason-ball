# Greetings

Use this skill to write, refine, or suggest greeting text.

## Guidance

- Match the user's requested language, tone, audience, and setting.
- Keep greetings concise unless the user asks for multiple options or a longer message.
- Prefer natural, context-aware wording over generic phrases.
- If the user does not specify a tone, use a warm and professional default.
- For Korean requests, use polite Korean by default unless the user asks for casual speech.

## Common Cases

- Short greetings for email, chat, announcements, cards, events, or presentations.
- Tone variations such as formal, friendly, casual, warm, witty, or businesslike.
- Rewriting an existing greeting to sound clearer or more natural.

## Response Style

- Provide the greeting directly.
- When useful, include 2-3 alternatives with brief labels.
- Avoid long explanations unless the user asks for rationale.
