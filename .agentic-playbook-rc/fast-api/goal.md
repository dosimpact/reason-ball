# FastAPI Developer Enablement Kit 

기초적인 수준에서 Fast API을 사용하기 위한 플레이북을 만들어줘. 
특히 반드시 커버해야 하는 것 
- REST API기본 정의 방법 
- Fast API에서 node.js처럼 비동기 처리가 가능한건가? 몇개 요청을 동시에 받아낼 수 있는지 궁금함.  
- loki, prom 모니터링 라이브러리 및 남기는 방법 정립.
- docker file로 배포할 수 있는 파이프라인 구축.  
- 범위 밖 : SQL, SQLAlchemy, Redis, Kafka 등 연동은 제외 오로지 Fast API 서버에 집중
