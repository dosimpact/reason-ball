# Reason Ball

pnpm workspace + Turborepo monorepo scaffold.

## Requirements

- Node.js 24.14.0 or compatible
- pnpm 10.33.4

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm test
pnpm lint
pnpm typecheck
```

## Workspace Layout

- `apps/*` for runnable applications
- `packages/*` for shared packages and libraries
