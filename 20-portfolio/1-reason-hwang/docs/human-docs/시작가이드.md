# 이 프로젝트에 대해서

## 시작하기: infra 셋팅  

### 1.Infra 올리기

`1-infra-graph-rag` 이동
- 사전 설정 : docker, colima 등 설치

```
# 전체 실행
pnpm infra:up

# 상태 확인
pnpm infra:ps

# 전체 종료
pnpm infra:down
---
 ✔ Container reason-postgres
 ✔ Container reason-graph-neo4j
 ✔ Container reason-cadvisor
 ✔ Container reason-postgres-exporter
 ✔ Container reason-alloy
 ✔ Container reason-neo4j-exporter
 ✔ Container reason-loki
 ✔ Container reason-prometheus
 ✔ Container reason-grafana
```

아래 3가지 주요 서비스 접속확인
```js
   Neo4j Browser    http://localhost:7474
   PostgreSQL       localhost:5432
   Grafana          http://localhost:3001


# [Loki] 컨테이너 로그 집계 및 검색을 위한 중앙 로그 저장소
ㄴ   # [Alloy] Docker 소켓을 감시하여 모든 컨테이너 stdout/stderr 로그를 수집 후 Loki로 전달

# [Prometheus] 각 Exporter 및 cAdvisor로부터 시계열 메트릭을 주기적으로 스크랩 및 저장
ㄴ   # [cAdvisor] Docker 데몬 및 컨테이너별 CPU/메모리/네트워크 리소스 사용량 실시간 수집
ㄴ   # [Neo4j Exporter] Neo4j Bolt/APOC 프로시저를 호출하여 지식그래프 메트릭 노출 (내부 통신)
ㄴ  # [PostgreSQL Exporter] Postgres 내부 통계 지표를 Prometheus 포맷으로 노출 (내부 통신)
```


주의 
- browser에서 https로 연결할때 reason-neo4j.domain.com:443 포트까지 명시해야한다.  

### 2.Codex OAuth proxy올리기  

2.2-codex-oauth-proxy 실행 
- 목적:gpt api없이 codex를 이용해서 llm api 연동을 할 수 있다. 비용 절감
 
```js
# 설치
    "install": "uv sync --frozen",
# 인증
    "oauth": "uv run python -m core.oauth_login --manual-callback",
# 체크
    "health-check:sdk": "OPENAI_BASE_URL=http://127.0.0.1:2890/v1 OPENAI_API_KEY=chatgpt-oauth-placeholder uv run python examples/sdk.py",
# 서비스 up
    "infra:up": "docker-compose up -d",
```
