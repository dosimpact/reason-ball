


## Open UI 시각화 - 디자인 시스템  

캔들차트 : TradingView Lightweight Charts를 사용 - 
- 디자인 시스템은 시각적 규칙과 OpenUI 계약을 함께 관리 : open ui lang 정의 -> generate 으로 langgraph system prompt 동기화.  


### 캔들 스택 + 실시간 가격 데이터 연동 차트  

목적 : 단순 가격 데이터 조회  
- 지원: 일봉/주봉, Yahoo 가격 API에서 제공하는 티커  

- CandlestickChart 기존 시스템과 어울리는 디자인
- OpenUI Lang의 공식 @Query 기능으로 Yahoo 가격 API 연결  
- OpenUI 런타임에서 호출하는 연결은 추가 : 현재 bff 와 langgraph fast api 연동은 nest.js reverse proxy를 이용한다. nest.js는 api스펙을 몰라도 pass하는 역할   

[디자인]
- @Query를 지원하는 컴포넌트는 Refresh 아이콘을 추가해서 사용자가 직접 갱신할 수 있도록 한다.  
- '티커, 주기, 봉 수' 등 쿼리 인자는 커스텀할 수 있겠끔 같이 제공
