## 공통 원칙 
- playwright 검증 후 크롬을 잘 닫아야 한다. 안그러면 메모리 이슈 발생  
- 특별히 내가 질문이 먼저 물어보지 않는다면, 우선 가능한 작업을 먼저 진행하고 blocking issue, 스펙 질문, 모호한것은 구현 후 질문한다.  
- 서브에이전트를 활용할 수 있으면 병렬로 작업해서 속도를 올려라.

## open ui lang에서 제공하는 agent interface로 마이그레이션
- fe host에 모든 ui는 langgraph를 사용하고 있다. 근데 open ui lang에서 제공하는 에이전트 인퍼테이스를 사용 안하는게 문제이다. 이를 사용하도록 마이그레이션 하자. 

## fe host nav메뉴 리팩터링

nav에서 적당히 그룹 만들어줘. 
- remote apps 관련 네브, chat 관련 기능 등등

## fsd 리팩터링  
1-fe-host에 'https://github.com/feature-sliced/steiger' 라이브러리를 설치하고 fsd 구조로 마이그레이션하자.  
- 최대한 파일들을 건드리지 않고 fsd구조로 리팩터링 할 수 있도록 하자. 
- copy, mv명령어를 주로 쓰며 정 안되는 경우 fsd구조로 함수 수준 분리 가능하다. 그래도 불가피하면 코드 리팩터링도 가능.
