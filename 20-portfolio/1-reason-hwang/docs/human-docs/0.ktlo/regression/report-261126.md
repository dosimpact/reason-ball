# AI Chat 샘플 질문 회귀 검증

- 검증일: 2026-11-16 (Asia/Seoul). 파일명은 요청하신 `261126`을 그대로 사용했다.
- 상태: **65개 질문의 실제 제출과 답변을 확인했다.** 정상으로만 판단할 수 없는 질문이 있으며, 일부 차트의 완전 로딩 및 테스트 세션 정리는 미확인이다.
- 대상: 기술적 분석 인라인·Canvas, TA-Lib 채팅, SEC API Agent, SEC Research Chat의 시작 질문 전체.
- 방법: Playwright로 실제 화면에서 시작 질문을 클릭하고 실제 모델·Yahoo/SEC 연결의 답변, 차트·오류와 스크린샷을 확인한다. 검증용 Host `127.0.0.1:33083`은 별도 빌드 디렉터리를 사용하며, 그래프 런타임 `127.0.0.1:32982`와 기존 FastAPI/BFF를 연결한다.
- 증거: [질문별 스크린샷과 원문](evidence-261126/). 화면별 질문·판정과 스크린샷은 아래 표에 정리했다.

## 환경 장애와 복구

기존 Host(2983)에서 Canvas 그래프가 등록되지 않았다는 안내가 처음 관찰됐다. 추가 검증용 Host를 처음 실행할 때 기존 Host와 동일한 `.next` 디렉터리를 사용한 실수로 기존 Host와 OpenUI validator에 500 오류가 발생했을 가능성이 높다. 검증용 Host를 종료하고, 별도 디렉터리로 실행한 Host의 동일 버전 생성물에서 누락 파일만 복원했다. 기존 Host는 재시작하지 않았고 5개 화면의 HTTP 200 및 브라우저 로드와 validator POST 200을 확인했다. 해당 시간대의 시각화 실패는 환경 영향으로 분리하며 복구 후 재시도한다.

검증용 LangGraph 서버는 다른 소스 변경에 따른 자동 재시작이 관찰됐다. 실행 중인 질문에 미친 영향이 확인되면 시간 초과·환경 중단으로 구분한다.

## 검증 자원과 한계

- Playwright MCP는 기존 브라우저 프로필 사용 중 오류가 발생해 연결하지 못했다. 사용자 브라우저를 종료하지 않고 작업 소유의 별도 Playwright Chromium에서 실제 사용자 클릭을 실행했다. 따라서 MCP 기반 검증은 미완료이며 별도 Chromium 실행 결과를 기록했다.
- 검증용 Host 33083과 LangGraph 32982, 검증 전용 Chromium 및 확인된 자식 프로세스는 종료했고 두 포트가 해제된 것을 확인했다. 기존 2980·2981·2982·2983 서버와 사용자 브라우저는 종료하지 않았다. Host 2983의 다섯 경로 및 validator는 복구 후 HTTP 200을 확인했고, FastAPI 2981 health도 200을 확인했다.
- TA-Lib에서 식별한 테스트 thread 34개와 인라인 테스트의 기록된 thread 14개는 삭제하고 재조회로 확인했다. [인라인 정리 결과](evidence-261126/inline/thread-cleanup-results.json). SEC Research 세션 2개는 위에서 설명한 대로 식별자가 없어 삭제하지 못했다.
- 검증용 LangGraph 32982가 기존 2982의 개발용 thread 저장소를 공유하는 것을 뒤늦게 확인했다. Canvas 실행에서 일부 테스트 thread의 식별자를 수집하지 못해 기존 대화와 안전하게 구분할 수 없으므로 추측해 삭제하지 않았다. 캡처된 별도 진단 thread 1개만 삭제했다. 따라서 개발용 저장소에 이번 테스트 대화 일부가 남아 있을 수 있고 **정리 미완료**다.
- 답변은 실제 모델·외부 서비스 실행 결과로, 같은 질문을 재실행하면 값·문장·소요 시간이 달라질 수 있다. PNG의 로딩 상태를 완료 화면으로 간주하지 않았다.
