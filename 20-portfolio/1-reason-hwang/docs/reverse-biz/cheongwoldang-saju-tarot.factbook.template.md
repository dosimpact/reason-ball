## 0. 팩트북 작성 규칙

### 0.1 목적

이 문서는 실제 서비스 탐색에서 직접 확인한 사실만 저장한다. 역기획서의 모든 관찰 근거는 이 팩트북의 Fact ID, 화면 캡처 또는 행동 기록을 참조해야 한다.

### 0.2 기록 가능한 사실

- 화면에 실제 표시된 짧은 문구, 레이블, 가격, 상태, 순서
- 확인한 URL과 이동 전후 URL
- 화면 내 섹션, 요소, 이미지, 캐릭터의 실제 배치
- 버튼, 링크, 입력, 선택, 스크롤 등 직접 실행한 동작
- 동작 전후에 실제 관찰된 화면·데이터·상태 변화
- 브라우저와 화면 크기에 따른 실제 배치 차이
- 로그인, 구매, 프로필 상태에 따른 실제 노출 차이
- 로딩, 빈 상태, 오류, 중단, 재진입 시 실제 반응

### 0.3 기록하지 않는 내용

- 화면이나 기능의 의도·목적·타깃에 대한 해석
- 좋음·나쁨·세련됨·트렌디함 등의 평가
- 확인하지 않은 백엔드, 알고리즘, 데이터 모델 추정
- 경쟁 서비스와의 비교 또는 개선 제안
- 관찰 근거 없이 일반화한 사용자 행동

해석과 가설은 [역기획서](cheongwoldang-saju-tarot.template.md)에만 작성한다.

### 0.4 문구·이미지 기록 원칙

- 메뉴명, 버튼명, 제목 등 짧은 UI 문구는 그대로 기록한다.
- 긴 본문은 전체를 복제하지 않고 제목, 시작·끝 위치, 글자 수, 화면 캡처를 기록한다.
- 화면 캡처는 `assets/cheongwoldang/{도메인}/{화면-ID}/` 아래에 저장한다.
- 캡처에 개인정보가 보이면 분석에 불필요한 부분을 가린 사본을 사용한다.
- 이미지 자체와 이미지에서 관찰한 사실을 분리한다. 분위기나 의도는 팩트로 기록하지 않는다.

### 0.5 식별자 규칙

| 식별자 | 대상 | 예시 |
| --- | --- | --- |
| `FACT-` | 단일 관찰 사실 | `FACT-C-001` |
