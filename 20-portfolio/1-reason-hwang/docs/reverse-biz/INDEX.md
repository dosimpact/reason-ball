# Reverse Business Documentation

이 디렉터리는 외부 서비스를 관찰해 제품 구조, 사용자 흐름, 비즈니스 규칙, 데이터 및 시스템 동작을 재구성한 역기획 문서를 관리합니다.

## 작성 원칙

- 직접 확인한 사실과 추론한 내용을 분리합니다.
- 탐색에서 얻은 문구, 화면, 이미지, 배치, 동작은 팩트북에 먼저 기록합니다.
- 범위 내 실제 화면과 동작을 전수 확인하고 커버리지 감사를 통과한 뒤 역기획 본문을 작성합니다.
- 화면 설명보다 사용자 목적과 비즈니스 규칙을 우선합니다.
- 확인할 수 없는 내부 구현은 단정하지 않고 가설과 검증 과제로 기록합니다.
- 개인정보 입력, 결제, 메시지 전송 등 외부 상태를 바꾸는 조사는 실행 전에 별도 확인합니다.
- 현재 상태를 설명하는 본문과 조사 이력을 담는 증거 로그를 함께 유지합니다.
