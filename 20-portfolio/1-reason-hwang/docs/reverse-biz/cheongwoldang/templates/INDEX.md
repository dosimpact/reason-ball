# 세부 기록 템플릿

한 화면·상품·여정·기능에 긴 설명이 필요하면 아래 틀을 복제해 독립 파일로 작성한다.

| 템플릿 | 용도 | 작성 위치 |
| --- | --- | --- |
| [화면 팩트](screen-fact.template.md) | 화면 상태, 문구, 배치, 행동을 상세 기록 | factbook/screens/ 아래의 새 파일 |
| [상품 팩트](product-fact.template.md) | 상품별 전체 이용 경로와 차이 기록 | factbook/products/ 아래의 새 파일 |
| [여정 분석](journey-analysis.template.md) | 팩트 조사 후 사용자 목적·전환·이탈 해석 | analysis/journeys/ 아래의 새 파일 |
| [기능 명세](feature-spec.template.md) | 목적·정책·상태·인수 기준을 개발 단위로 작성 | analysis/features/ 아래의 새 파일 |

위 디렉터리는 실제 기록 생성 시 만든다. 새 문서 생성과 동시에 부모 INDEX와 관련 인벤토리에 링크한다. 동일한 규칙은 공통 정책 문서에서 소유하고, 상세 파일에는 차이와 근거만 연결한다.
