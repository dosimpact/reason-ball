# 타로 해석·결과·재열람

> 상태: 작성 대기. [타로 결과 팩트](../../factbook/tarot/03-results-replay.md) 참조.

## 입력에서 결과로

{질문 맥락·선택 카드·카드 위치·방향 등이 실제 결과에 어떻게 나타나는지 FACT를 연결한다. 그 뒤 카드 사전·조합 규칙·생성 모델 후보를 가설로 설명한다.}

## 생성 시점과 결제

{카드 공개·미리보기·생성·결제·잠금 해제의 실제 순서를 상품별로 연결한다. 미확인 구간은 신규 설계에서 선택할 정책으로 분리한다.}

## 재열람과 다시 뽑기

{같은 질문·카드의 결과 유지, 다시 뽑기와 새 질문의 구분, 재결제 여부, 이전 결과 보관·비교. 결과 ID와 세션·이용권 관계를 명세한다.}

## 품질·캐릭터 말투

{카드명·위치·질문과 설명이 일치하는지, 조합 해석과 개별 해석의 모순, 결과 분량·읽기, 캐릭터의 호칭·말투 일관성을 검수한다.}

## 실패·인수 기준

{선택은 완료됐지만 생성이 실패한 경우, 결제 이후 결과가 없을 때, 카드 이미지 누락, 결과 도중 재접속의 FR·UI·AC를 연결한다.}
