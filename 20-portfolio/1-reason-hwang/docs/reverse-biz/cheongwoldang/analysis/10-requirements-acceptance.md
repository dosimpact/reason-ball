## 개발 착수 게이트

- [ ] 조사 범위와 커버리지 판정이 확정되었다.
- [ ] 현행 사실과 내부 구조 가설, 재구축 제안이 구분되었다.
- [ ] MVP 기능마다 이유·입출력·정상·실패·복구가 명세되었다.
- [ ] 사주 계산 기준과 타로 선택 정책의 구현상 결정을 명시했다.
- [ ] 결제·이용권·결과 보관·환불의 상태와 권리가 정의되었다.
- [ ] 화면·컴포넌트·콘텐츠·에셋의 제작 입력이 충분하다.
- [ ] 데이터·API·이벤트 계약과 인수 기준이 FR에 연결되었다.
- [ ] 차단 미결정이 없거나 합의된 구현 범위에서 제외되었다.
