# 사주 결과·오늘의 운세·재방문

> 상태: 작성 대기. [결과 팩트](../../factbook/saju/03-results-daily-fortune.md) 참조.

## 결과를 읽는 흐름

{요약 → 근거 정보 → 주제별 상세 → 조언 → 다음 행동의 실제 구조와 사용자 의도를 연결한다. 화면의 실제 순서가 다르면 관찰을 따른다.}

| CT ID | 섹션·목차 | 사용자 질문 | 개인화 입력 | 출력 형식 | 공개·잠금 | 근거 |
| --- | --- | --- | --- | --- | --- | --- |
| {CT ID} | {관찰값} | {분석} | {필드} | {명세} | {정책} | {FACT 링크} |

## 오늘의 운세 정책

- 날짜·시간대·갱신 기준과 같은 날 재접속의 일관성
- 프로필별 결과 구분과 과거/미래 날짜 접근
- 일별 결과 보관, 구매 결과와의 목록 관계
- 자정 전후 생성 중·열람 중의 기준 날짜
- 무료 경험에서 상품 추천으로 이어지는 실제 접점

각 항목에 관찰 또는 가설, 재구축 선택을 표시한다. 다음날 동작을 실제 확인하지 못하면 GAP를 유지한다.

## 결과 저장·수정·재생성

{인물 입력 변경, 계산 기준 또는 콘텐츠 버전 변경, 결과 생성 실패 이후 재시도, 기존 구매자의 재열람 정책과 공통 이용권 명세를 연결한다.}

## 품질과 예외

{표·차트·문장에 동일 인물·기간이 반영되는지, 값이 없는 입력의 처리, 결과 섹션 누락·너무 긴 문장의 읽기와 접근성 기준을 정의한다.}

## 개발 연결

{FR·UI·CT·EV·AC 링크와 미해결 질문.}
