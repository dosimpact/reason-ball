- 한 번의 결제가 상품·인물·질문·결과 중 무엇에 대한 권리인가?

- 결제 성공 후 생성 실패, 생성 중 이탈, 중복 결제는 어떻게 복구하는가?

- 가격 변경 이전 구매의 결과와 영수 정보는 유지되는가?
