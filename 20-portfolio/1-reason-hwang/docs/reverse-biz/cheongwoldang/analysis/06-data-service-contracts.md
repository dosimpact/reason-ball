## 외부 연동 경계

{인증, 결제, 사주 계산, 콘텐츠 생성, 파일 제공 등의 필요 여부와 입력·출력·실패 책임. 화면에 보이는 공급자와 내부 연동 공급자 추정을 구분한다.}

## 데이터 생명주기

{입력 초안 → 확정 스냅샷 → 계산·선택 → 결과 → 구매·권리 → 보관·만료. 수정·삭제·환불·가격 변경·재생성이 이전 데이터에 미치는 영향을 적는다.}

## 오류·비용·권한

{중복 클릭, 지연 응답, 결제 성공/이용권 갱신 실패, 생성 성공/저장 실패, 로그인 만료 시 일관성·복구 정책을 정의한다.}
