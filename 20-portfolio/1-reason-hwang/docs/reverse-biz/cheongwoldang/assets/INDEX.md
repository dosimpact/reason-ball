# 청월당 관찰 증거 자산

> 현재 상태: 캡처 수집 전. 이미지·영상 파일은 아직 없다.

## 위치

실제 탐색 시 이 폴더 아래에 도메인/화면 ID/관찰 날짜별로 저장한다. 예시: `saju/sc-s-0001/2026-09-21/cap-s-0001-default.png`.

## 연결

캡처 파일의 단일 원장은 [사실·증거 원장](../factbook/09-evidence-register.md)이다. 기록에는 캡처 시각, 화면 ID, 사용자 상태 코드, 뷰포트, 스크롤 위치를 포함한다.

## 원본과 사본

분석에 불필요한 개인정보를 담은 원본은 공유 문서에 연결하지 않는다. 비식별 사본에는 가린 항목 종류를 명시한다. 스크린샷 속 이미지는 관찰 증거이며, 개발에 재사용할 수 있는 에셋으로 자동 승인된 것이 아니다. 제작할 에셋의 출처·이용 범위는 개발 명세에서 별도로 정의한다.
