> 상태: 조사 전. 표의 숫자는 빈 양식이며 확인 실적이 아니다.

## 요약

확인율 = 확인 완료 조합 수 ÷ (등록 조합 수 − 범위 제외 조합 수). 차단은 분모에 포함한다. 분모가 0이면 `미산정`으로 기록한다. 화면 수와 행동 조합 수는 다른 단위로 집계한다.

발견한 모든 화면에 조사 범위·관찰일·등록 조합을 연결한다. 신규 상품·조건을 발견하면 분모를 갱신한다. 조사 완료 판정은 알려진 범위의 종료 판정이며 모든 미래 조건을 검증했다는 뜻이 아니다.

## 조사 완료 판정

- [ ] 모든 발견 화면이 화면 인벤토리에 있다.
- [ ] 모든 조작 요소가 커버리지 표에 있다.
- [ ] `미조사` 상태가 없다.
- [ ] 차단 항목의 분석 영향이 기록되었다.
- [ ] Fact ID와 캡처·동작 증거 연결이 끊기지 않았다.
- [ ] 차단 항목이 없거나 사용자가 구체적인 조사 제한을 수용했다.
