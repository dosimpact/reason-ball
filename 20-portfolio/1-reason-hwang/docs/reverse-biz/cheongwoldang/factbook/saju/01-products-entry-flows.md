# 사주 상품과 진입·이용 흐름

> 상태: 조사 전. 실제 관찰값과 증거를 채운다.

## 확인할 범위

- 홈, 사주 카테고리, 무료 카테고리, 검색, 추천, 보관함에서 발견되는 상품을 각각 등록한다.
- 오늘의 운세와 무료·유료 상품의 접근 조건을 실제로 확인한다.
- 상품 상세 → 프로필 입력 → 로그인 → 미리보기 → 결제 → 생성 → 결과의 실제 순서를 기록한다. 이 순서는 조사 질문이며 사전 가정이 아니다.
- 본인 풀이와 상대방이 있는 풀이의 분기를 기록한다.
- 동일 상품의 여러 진입 경로에서 가격, 입력값, 결과 이용권 표시가 달라지는지 확인한다.
