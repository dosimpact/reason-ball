## 문서 책임

- 상품별 진입 경로와 입력·결제·결과 순서는 상품과 흐름 문서에서 소유한다.
- 필드, 달력, 시간, 관계자 입력의 실제 동작은 입력과 검증 문서에서 소유한다.
- 결과의 구성과 당일 운세 변경 관찰은 결과 문서에서 소유한다.
- 가격과 결제 공통 정책은 [공통 상품 팩트](../05-product-price-payment-facts.md)를 참조한다.
- 각 상품은 독립된 조사 대상으로 등록한다. 외형이 비슷하다는 이유로 다른 상품의 확인 결과를 대신 적용하지 않는다.
