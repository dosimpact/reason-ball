# 사주 입력과 검증 팩트

> 상태: 조사 전. 화면에 없는 필드는 없는 것으로 추정하지 않고 확인 범위를 기록한다.

## 조사 항목

- 이름·성별·생년월일·양력/음력·윤달·출생시간·출생지가 실제로 요구되는가?
- 시간 모름 선택, 기본값, 달력 선택 방식, 미래 날짜와 필수값 누락에 대한 화면 반응은 무엇인가?
- 본인과 상대방 입력 수, 관계 레이블, 기존 인물 선택, 수정과 재사용은 어떻게 보이는가?
- 정보 수정 후 이전 결과가 유지되는지, 다시 생성하거나 결제하도록 안내하는지 확인한다.
- 검증은 허용된 화면 조작과 승인된 테스트 입력으로 수행한다. 실제 인물 정보는 원문 증거에 넣지 않는다.
