# SEC A2UI 업무 범위

## 확정 범위

사용자가 선택한 공시를 근거로 분석·요약 보고서를 생성한다. 보고서 생성은 SEC 원문 수집·다운로드 작업을 뜻하지 않는다. 기존 회사·공시 API와 저장 원문을 사용하고 DB 스키마를 추가하지 않는다.

| ID | 사용자 흐름과 완료 증거 |
| --- | --- |
| SEC-A2UI-01 | 회사명·티커 검색, 빈 결과, 페이지 이동을 A2UI 입력/버튼/결과로 제공한다. 실제 BFF 결과와 화면을 비교한다. |
| SEC-A2UI-02 | 회사를 선택하면 해당 CIK의 공시 목록을 표시한다. form·기간·상태·접수번호와 원본/수정본 관계를 보존한다. 다른 회사의 결과가 섞이지 않는지 검사한다. |
| SEC-A2UI-03 | 공시 선택 후 요약/분석 생성 action으로 보고서를 만든다. 서버가 CIK와 accessionNo로 원문을 다시 읽는다. 클라이언트의 본문이나 회사명을 신뢰하지 않는다. |
| SEC-A2UI-04 | 기본 보고서는 핵심 요약·사업·재무·위험을 제공하며, 분석 요청이 있으면 요청한 항목만 표시한다. 선택한 항목에 정보가 없으면 근거 없음으로 표시하고 분석 한계와 근거는 항상 유지한다. 근거 ID와 실제 원문 발췌를 검증하고 표시한다. |
| SEC-A2UI-05 | 로딩·빈 원문·미다운로드·상위 API 실패·모델 실패·중복 제출·취소 및 재시도를 검증한다. 실패를 성공 보고서로 바꾸지 않는다. |
| SEC-A2UI-06 | thread별 회사/공시/보고서 선택을 격리한다. 회사 변경 후 이전 공시 action, 다른 thread의 action을 거절한다. |
| SEC-A2UI-07 | 전용 SEC 카탈로그와 해시, Storybook, Bruno HTTP E2E, 순차 MCP 브라우저, 실제 저장 SEC 원문과 실제 모델 보고서 증거를 남긴다. fixture 통과와 실서비스 통과를 구분한다. |
| SEC-A2UI-08 | 검색·회사·공시·보고서 단계에 필요한 영역만 표시한다. 빈 공시 목록에는 안내와 필터를 제공하고 빈 보고서/선택기를 노출하지 않는다. |
| SEC-A2UI-09 | 선택 공시에 대한 사용자 요청으로 분석 항목·순서와 카드/표/접이식 표현을 선택한다. 허용된 계획과 인용을 검증하며 선택 문서와 출처는 서버가 유지한다. |
| SEC-A2UI-10 | 자연어 요청의 의도에 따라 일반 안내, 회사/공시 조회, 선택, 분석과 화면 구성을 결정한다. 일반 질문으로 기존 선택이 바뀌지 않고 회사 변경은 채팅으로도 가능하다. 모델은 조회 결과의 식별자만 선택하며 Fixed 조회 화면과 제한된 Dynamic 보고서 도구를 사용한다. |

## 기술 문서

구현·상태·action·근거 검증·제한은 [A2UI SEC 기술 설계](../tech-shared/a2ui-system/sec.md)에 통합했다. [A2UI 문서 지도](../tech-shared/a2ui-system/INDEX.md)에서 공통 계약과 운영 문서로 이동한다. 기존 [공시 시스템](system-design.md)은 수집·저장 API의 원본이다.

## SEC-A2UI-11: 대화 결과와 작업 화면

기본 채팅 결과는 새 화면으로 남겨 이전 결과를 보존한다. Canvas를 선택하면 대화 옆 하나의 작업 화면을 갱신한다. 두 위치는 같은 조회/분석 agent를 사용하며, Canvas 버튼은 해당 화면의 회사/공시 선택 상태를 사용한다. 최신 채팅 화면만 상호작용 가능하고 이전 결과는 읽기 전용이다. Fixed/Dynamic은 위치 선택과 별개다. 상세 상태 계약은 [공용 SEC 설계](../tech-shared/a2ui-system/sec.md#sec-a2ui-11-inline-이력과-고정-canvas), 증거는 [변경 기록](../../flow/2026-09-22-sec-inline-canvas.md)을 따른다.

## SEC-A2UI-12: 직접 선택과 분석 바로가기

회사 결과에서 공시 보기를 누르고, 분석 가능한 연간보고서에서 문서를 선택한 뒤 핵심 요약/위험 요인/전체 분석을 요청한다. 분기보고서·전체 공시와 추가 조건으로 범위를 변경할 수 있으며 현재 조건을 항상 표시한다. 자유 분석 요청, 다른 회사/공시 선택, 원문 근거/분석 범위 확인을 유지한다. 과거 대화 결과는 읽기 전용으로 접고, Canvas는 선택 시에만 처음 나타난다. 보고서 위에는 회사와 공시의 종류·기간·제출일을 유지한다. 기술 계약과 검증 증거는 [SEC-A2UI-12](../tech-shared/a2ui-system/sec.md#sec-a2ui-12-조회와-분석의-단계별-ux)를 따른다.

## 재무 시각화: 확정 요구사항

| ID | 확정 범위 |
| --- | --- |
| SEC-CHART-001 | 추출 범위는 선택 공시 한 건이며 그 안의 비교 기간을 포함한다. 다른 공시 및 원본/수정본을 자동 병합하지 않는다. |
| SEC-CHART-002 | 목차와 표 색인에서 필요한 부분을 선택해 읽는다. 문서 전체를 모델에 전달하지 않으며 미열람 범위를 알린다. |
| SEC-CHART-003 | 보고서 본문의 재무제표 표를 우선 사용한다. 별도 SEC 구조화 데이터 API 사용 여부는 후속 결정으로 남긴다. |
| SEC-CHART-004 | 막대·그룹 막대·누적 막대·선·영역·도넛을 등록하고 AI가 여러 차트·표·지표 카드를 선택·배치한다. |
| SEC-CHART-005 | 에이전트는 재무 데이터 추출 결과를 확인한 뒤 차트 렌더 도구를 선택한다. 표현만 바꾸는 경우 검증된 데이터를 재사용한다. |
| SEC-CHART-006 | 숫자의 기간·단위·출처와 누락을 보존한다. Inline의 독립 이력과 Canvas의 동일 surface 갱신을 유지한다. |

구체적인 구현 계약과 제한은 [SEC 재무 차트 설계](../tech-shared/a2ui-system/sec-financial-charts.md)에 통합한다. 구현 및 실행 검증 상태는 연결한 기술 문서를 따른다.
