# 사주·타로 핵심 제품 기획 v1

> 2026-09-22 · 기획 정제본 / 구현 전. 청월당 내부 프롬프트·계산식을 복원한 문서가 아니다.
> 사용자 확정 범위는 사주·타로 기능 중심, LangGraph·UI 구현 가능한 명세, 시각 디자인 분리다. 아래 세부 정책은 이를 실행하기 위해 정한 **신규 제품 설계 기본안**이며, 모두 사용자가 개별 승인한 정책이라는 뜻은 아니다.

## 한 문장 정의

사주는 검증된 생년월일시 계산 자료를, 타로는 사용자가 선택한 고정 카드 조합을 근거로 **질문에 맞는 해석·한계·실행 가능한 조언**을 제공한다. 캐릭터는 이를 안내하지만 계산과 해석의 근거가 되지 않는다.

## 범위와 완료의 의미

이번 핵심 제품은 **1인 사주 해석 1종 + 질문형 3장 타로 1종**이다. 오늘의 운세·궁합·자녀사주·대운·결제·회원·영구 보관함·추천은 후속 범위다. 청월당 상품 종류를 전부 구현하는 계획이 아니다. 입력/카드/결과의 임시 복구는 핵심 이용 완료를 위해 포함한다.

- 문서: 본 묶음을 신규 제품의 구현 기준으로 사용한다. 세부 기본안 변경 시 관련 계약과 인수 기준을 같이 갱신한다.
- 코드: 아직 구현하지 않았다. 기존 기술 구조는 [공유 설계](../tech-shared/system-design.md)를 따른다.
- 계산·콘텐츠·모델·그림: [출시 게이트](quality-acceptance.md)에 따라 실제 검증/제작해야 한다. 문서 완성이 품질 검증 완료는 아니다.
- 청월당 조사: 원 서비스 전수 조사는 완료되지 않았다. 미조사·유료 결과는 여전히 미확인이다. 조사 원본은 이 문서 묶음에 포함하지 않는다.
- 개발 경로: 새 remote와 독립 그래프. 기존 `1-fe-host`와 `main_graph`의 비즈니스 흐름은 변경하지 않는다.

## 사실과 설계의 경계

관찰에서 가져오는 것은 입력 맥락, 카드 선택의 참여감, 근거와 해석의 연결, 읽기 쉬운 결과 구조다. 원 서비스의 확률·점수·날짜·내부 알고리즘·AI 사용 여부는 검증된 정확성 근거가 아니다. 이 문서의 FR/BR/API/프롬프트는 모두 **우리 제품의 명세**다.
