# 인물·일러스트·시각 디자인 — 기능과 분리

> 자체 제작 방향 v1. 시장 전체의 유행이나 원 서비스의 제작 방식을 확인한 문서가 아니다. 에셋 미제작 상태. [UI 기능 계약](ui-design.md)과 [풀이 프롬프트](prompts.md)는 별도 소유한다.

## 1. 관찰과 해석의 경계

청월당에서 확인한 대비는 사주의 푸른 한복 인물·두루마리 안내와 타로의 검정 바탕·금색 카드 뒷면·분홍/붉은 빛 결과 표현이다. 조사 원본 캡처는 이 문서 묶음에 포함하지 않는다.

2026-09-21 조사 표본에서는 포스텔러의 만화형 인물·동물, 헬로우봇의 라마 캐릭터·보라/노랑 대비, 점신의 둥근 입체 인물·흰색/연두 화면이 확인됐다. 이는 **캐릭터가 기능의 안내자·정서적 입구로 사용된다는 디자인 가설**을 뒷받침하지만, 특정 스타일의 시장 점유율·성능·“요즘 대세”를 입증하지 않는다. 외부 출처와 관찰 화면의 원본은 이 문서 묶음에 포함하지 않는다.

따라서 “전통=실사 한복, 타로=진한 신비주의”를 필수 조건으로 복제하지 않는다. 이번 선택은 **같은 그림체의 성인 안내자 2명 + 읽기 편한 본문 + 절제된 상징**이다. 세 표본에서 관찰한 표현을 참고한 자체 제품 방향이며 원본 인물/로고/카드 이미지를 가져오는 결정이 아니다.

## 2. 캐릭터 기획

| 요소 | 사주 안내자 CHAR-S01 | 타로 안내자 CHAR-T01 |
| --- | --- | --- |
| 역할 | 정보를 정확히 확인하고 차분하게 해석을 안내 | 질문을 정리하고 선택과 조언을 안내 |
| 인물 | 명확한 성인 30대 중성적 인물, 짧은 검정 머리 | 명확한 성인 30대 중성적 인물, 어깨 길이 짙은 갈색 머리 |
| 의상·소품 | 청록·아이보리 현대적 겹깃 재킷, 접은 종이와 펜 | 자주·크림색 재킷, 텍스트 없는 카드 3장 |
| 표정 | 경청·차분한 미소, 우월/권위적 표정 없음 | 호기심·편안한 미소, 유혹/공포 표현 없음 |
| 차별점 | 출생정보·원국·성찰을 연결하는 안내자 | 카드·질문·선택을 연결하는 안내자 |
| 금지 | 실존 점술가/유명인 닮은꼴, 원본 청월당 캐릭터 모사 | 원본 타로 인물 복제, 성적 이미지·위협적 의식 |

공통 그림체: 정돈된 가는 외곽선, 부드러운 면 채색, 은은한 종이 질감, 인체 비율을 유지한 에디토리얼 일러스트. 과도한 광택·실사풍 피부·극단적 SD 비율을 혼합하지 않는다. 캐릭터가 운세의 정확성을 보증하는 배지나 “실존 전문가” 소개를 가지지 않는다.

두 인물은 성격·톤 일관성이 중요하다. 기준 정면/3분의 4 시점·머리/의상/팔레트 시트를 먼저 만들고 모든 표정·포즈를 이 시트에 맞춘다. 생성형 이미지 사용 여부와 무관하게 동일 승인 절차를 적용한다.

## 3. 아트 디렉션과 UI 스킨

기본 팔레트 제안: 배경 #F7F3EB, 본문 #252432, 사주 포인트 #255C55, 타로 포인트 #68446F, 장식 금색 #B18B4F. 금색은 주요 본문색으로 사용하지 않는다. 타로 선택 구간에만 짙은 #242033 배경을 허용하고 결과 긴 본문은 밝게 유지한다. 대비 수치는 구현 후 측정해 통과한 조합만 승인한다.

본문은 시스템 한국어 sans-serif 우선; 장식 명조는 제목 일부에만, 배포 폰트 라이선스 확인 후 사용. 텍스트를 그림 안에 굽지 않는다. 카드 앞면은 그림+UI 카드명 분리, 오행 아이콘은 도형+라벨, 관계·성별을 색이나 외모로 고정하지 않는다.

인물은 랜딩/입력 헤더에서 모바일 높이 약 160–220px, 결과에서는 작은 아바타로 축소한다. 답보다 인물이 더 큰 결과 화면을 만들지 않는다. 반짝임·부유·카드 뒤집기는 180–300ms, reduced-motion이면 정적. 결과 텍스트 도착을 연출 때문에 지연하지 않는다.

## 4. 에셋 명세

| Asset ID / 수량 | 원본·납품 규격 | 용도·완료 조건 |
| --- | --- | --- |
| CHAR-S01, CHAR-T01 각 1 sheet | 정면/3분의 4, 얼굴·의상 팔레트·금지 변형 | 후속 모든 이미지의 기준 |
| 각 캐릭터 hero 1, avatar 1, thinking 1, guide 1 = 8개 | hero 1200×1600 RGBA, avatar 512×512, 포즈 1024×1024 | 동일 얼굴/의상, 손·소품 오류 없음 |
| BG-S01, BG-T01 2개 | 1600×900, 텍스트 없음 | 모바일 크롭에서도 인물/문장 충돌 없음 |
| CARD-BACK-v1 1개 | 720×1200, 동일 외곽선·안전 여백 | 모든 선택 뒷면 완전히 동일 |
| CARD-FRONT 78개 | 720×1200, 3:5, 같은 프레임·색감 | canonical cardId 78개와 1:1 매핑 |
| UI-SYMBOL 5개 | SVG, 24/32px 격자 | 오행 라벨과 함께 사용; 도형 단독 의미 의존 금지 |

PNG는 보관 마스터, 배포는 WebP/AVIF 적합한 포맷 선택. 모바일 hero 200KB 이하, 카드 80KB 이하, avatar 40KB 이하를 초기 예산으로 검수한다(품질 훼손 시 원인/대안 기록). 고정 width/height, lazy loading, 현재 덱 뒷면만 우선 로드하며 78장 앞면을 선택 전에 미리 가져오지 않는다.

asset manifest 필수: `assetId,version,path,width,height,bytes,hash,creator,source,license,commercialUseConfirmed,reviewStatus,characterId/cardId`. 그림체·카탈로그 의미 일치·권리 확인이 approved인 것만 운영 빌드에 포함한다. 캐릭터 source는 original 또는 licensed로 명시; 외부 연구 캡처는 research-only이며 배포 asset 경로에 복사하지 않는다.

## 5. 제작용 브리프

사주 인물:
> 성인 30대의 중성적인 가상 안내자. 짧은 검정 머리, 청록색 현대적 겹깃 재킷과 아이보리 안쪽 옷. 종이와 펜을 들고 사용자의 이야기를 경청하는 편안한 자세. 가는 외곽선과 부드러운 면 채색의 에디토리얼 일러스트, 은은한 종이 질감, 읽기 공간을 남기는 단순한 구도. 실존 인물이나 기존 서비스 캐릭터를 닮지 않게. 글자·로고·운세 숫자 없음. 인물 단독 투명 배경.

타로 인물:
> 같은 시리즈 그림체의 성인 30대 중성적 가상 안내자. 어깨 길이 짙은 갈색 머리, 자주색 재킷과 크림색 셔츠. 텍스트 없는 카드 세 장을 테이블 위에 펼치며 차분히 선택을 안내하는 자세. 자연스러운 손, 편안한 미소, 작은 별 장식만. 공포·종교 권위·과도한 광택·성적 연출 없음. 글자·로고 없음. 인물 단독 투명 배경.

카드 덱:
> 78장을 하나의 세계관과 프레임으로 제작한다. cardId별 승인된 상징 요약을 먼저 받고, 그림만으로 핵심 의미를 읽을 수 있게 구도를 설계한다. 카드마다 화풍·인물 비율·빛 방향이 바뀌지 않도록 기준 시트를 유지한다. 숫자·카드명은 이미지 밖 UI로 표시한다. 폭력적·공포스러운 상징은 은유적으로 표현하되 카드 의미를 다른 카드로 바꾸지 않는다.

이 브리프는 실제 이미지 생성 결과가 아니다. 2개 인물 컨셉과 대표 카드 3장을 먼저 제작·검수한 뒤 전체로 확장한다. 전체 덱 제작/라이선스 준비 전에는 텍스트 카드로 기능 테스트할 수 있으나 **최종 디자인 완료**로 표시하지 않는다.

## 6. 기능과의 연결

UI는 assetId만 참조한다. 누락 시 텍스트·이름·위치가 남아 읽기가 가능해야 한다. 캐릭터 변경이 facts, selectedCards, InterpretationBody를 바꾸지 않는다. 그림 속 카드와 서버 cardId 불일치는 배포 차단 오류다. [인수 기준의 VIS 항목](quality-acceptance.md)을 별도로 통과시킨다.
