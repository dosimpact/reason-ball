# TA20 계산·조회 계약

## TA-IND-020: 공통 카탈로그

`domains/technical_analysis/catalog.py`는 schemaVersion2/catalogVersion `ta20-1`의 기본값·매개변수 범위·series 표시 계약을 소유한다. SMA, EMA, MACD, PSAR, CCI, STOCH, RSI, STOCHRSI, WILLIAMS_R, AO, TSI, UO, TRIX, BBANDS, KELTNER, DONCHIAN, OBV, PVT, AD, CMF를 지원한다. 기존 ADX·ATR과 여섯 기존 계산기는 유지한다.

설치 확인 버전은 Python wrapper/core0.7.1이다. 현재 설치에는 AO/TSI 함수가 없어 별도 계산기를 사용한다. 다른 버전에도 함수가 없다는 주장은 아니다. 신규14개는 `infrastructure/technical_analysis/talib/extended.py`, 기존8개는 기존 categories를 사용한다.

## 수치·null 정의

AO는 median price의 SMA5−SMA34다. STOCH는 raw %K를 SMA K/D로 평활한다. STOCHRSI는 Wilder RSI를 별도 stochastic 기간으로 정규화한 뒤 SMA K/D로 평활하며0~100이다. 평활창의 null은 gap으로 유지한다. TSI는 변화량/절댓값의 long/short EMA 비율×100이고 EMA는 연속 유효구간 SMA seed 후 alpha=2/(n+1)이다. TRIX는 TA-Lib triple EMA 변화율이다. TSI/TRIX signal_period 기본0은 주 지표만 뜻하며 showSignal=true는 생략된 signal을9로 활성화한다.

Keltner는 close EMA20±2×Wilder ATR10이다. Donchian은 현재 봉 포함 H 최고/L 최저 채널이다. BBANDS 기존 MA code/표준편차 구현은 유지한다. PVT는 이전 close 대비 변화율×volume 누적, 첫 값0이다. AD는 money-flow multiplier×volume을 첫 봉부터 누적한다. CMF는 기간 money-flow volume 합/volume 합이다. AD와 ADOSC는 다르다.

H=L이면 AD/CMF multiplier0, CMF volume 합0은null이다. CCI 편차0, stochastic·Williams·TSI·UO 분모0도null이다. PVT의 이전 close0은 이후 누적 기준이 불명확하므로 null을 전파한다. 기존 RSI 라이브러리 동작은 유지한다. 모든 series는 OHLCV 길이에 정렬하고 비유한 수치를 null로 직렬화한다. 부족한 이력은 status/error와 경고로 표현한다.

## 지표별 시그널

`signals.py`는 EMA·PSAR의 close 대비 위/아래/같음, STOCH/STOCHRSI K/D 위치·교차 및20/80 범위, CCI −100/100·Williams −80/−20·UO30/70 범위를 계산한다. 경계값과 같으면 해당 상/하단 범위에 포함한다. 밴드 경계와 같은 값은 밴드 안이다.

Donchian 돌파는 표시 채널과 별도로 직전 완성 채널을 현재 close와 비교한다. AO/TSI/TRIX/CMF는0 대비 부호·교차, 선택 signal은 그 위치·교차도 제공한다. OBV/PVT/AD는 같은 누적 기준에서 증가/감소/변화 없음만 표시한다. 교차는 직전<=0·현재>0 또는 직전>=0·현재<0이며 현재0에 닿는 것만으로 교차가 아니다. 두 유효 봉이 없으면 판단 불가다. 기존 SMA/RSI/MACD 해석은 유지한다. 자동 매매나 종합 점수는 없다.

## TA-QUERY-002: 버전·인스턴스

기존 GET `/technical-analysis/chart`는 schema_version 기본1이며 기존3지표 요청·snapshot 구조를 유지한다. v2는 schema_version=2 및 instances JSON 문자열을 받는다. 각 항목은 instanceId/name/parameters/showSignal이다. 기본은 기존3개, indicators=all은20개다. 최대40인스턴스·200표시봉이며 명시 ID는 영문자로 시작하는64자 이내 영숫자/underscore/hyphen이다. 생략 ID는 이름+정규화 매개변수 hash다. 같은 설정 복사본은 다른 명시 ID를 쓰며 충돌은422다.

GET `/technical-analysis/catalog`는 기본값, 매개변수별 default/min/max/type, supportsSignal, panel, series descriptor를 제공한다. v2 응답은 공통 bars와 indicators 배열을 분리한다. series는 bars 인덱스 정렬 values와 key/label/unit/display를 가진다. panel은price/oscillator이며 밴드는 upper/middle/lower role·bandGroup, PSAR는circle markers다. signal에는 state/cross 외 scalar 근거·범위가 추가될 수 있다.

누적 OBV/PVT/AD가 포함되면 실제 Yahoo start=2000-01-01 이후 첫 유효 완료 봉을 계산 origin으로 사용한다. IPO가 늦으면 첫 이용 가능 봉이 origin이다. count는 표시만 자르므로 같은 원본의 겹치는 날짜 값이 유지된다. 응답 origin은 실제 날짜·사용 봉 수·정책·기준값을 명시한다. 공급자 과거 수정은 숫자를 바꿀 수 있으며 전체 상장 이력을 주장하지 않는다. 원본은20000봉 제한, 별도16개 TTL/singleflight cache를 사용한다.

## 두 agent와 OpenUI

두 agent는 같은 도구·카탈로그·계산 결과를 쓴다. all_indicators=true는 전체20이고 인스턴스 목록은 복수 설정을 지원한다. inline 구조화 재분석은 analysis_request, Canvas는 canvas_context.request이며 같은 execute_analysis_request helper가 두 도구를 결정적으로 실행한다. inline presentation과 Canvas report UUID/custom 출력은 유지한다.

새 agent 분석은 기본3개일 때도 v2 snapshot을 만들어 지표 추가·복수 설정 controls를 제공한다. 기존 GET v1 응답과 저장된 v1 프로그램 reader는 유지한다. v2 프로그램은 $chart_instances JSON·IndicatorControls·카탈로그 Query를 사용한다. chart fallback의 숫자 배열은 비우고 모델 없는 Query가 실제 snapshot을 읽는다. 숫자를 DSL에 복사해60000자를 넘기거나 모델이 재작성하게 하지 않는다. 기존 v1 프로그램은 유지한다. Query는 LLM을 호출하지 않으며 해석은 최초 snapshot 기준이다. 명시적 재분석만 새 해석을 생성한다.

## TALIB-REG-001: 카탈로그 필터와 유한 가격 창

전체 네이티브 TA-Lib 도구의 `list_talib_functions`는 group/search 양끝 공백을 제거하며 빈 문자열·공백 group은 필터 생략과 같다. 알 수 없는 실제 group은 여전히 빈 목록이다.

Yahoo 일반 가격 조회는 요청한 최근 count개 provider 행을 먼저 선택한 뒤 검증한다. 장기간 조회용 `period=max`의 요청 범위 밖 과거 조정가격 오류가 최근 주봉 분석을 막지 않는다. 선택 범위 안 잘못된 음수 가격 등은 여전히 `invalid_provider_data`이며 숫자를 고치거나 추정하지 않는다. 결측 행 제외 때문에 실제 반환은 count보다 적을 수 있다. 누적지표 fixed-origin 경로는 전체 origin 이력을 엄격하게 검증하는 기존 정책을 유지한다.
