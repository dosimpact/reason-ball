# 기술적 분석 비즈니스 설계

## TA-001 진입과 범위

Host `/chat`에서 기술적 분석 에이전트를 선택한다. Yahoo ticker를 입력해 일봉(`1d`) 또는 주봉(`1wk`) OHLCV를 분석한다. 기본은 일봉 최근 완료 봉 120개다. 미국 한정 필터는 없으며 Yahoo가 인식하는 `.KS`, `.KQ` 등의 ticker도 입력할 수 있다. 공급자별 실제 데이터 가용성은 조회 결과로 판단한다.

## TA-002 계산

RSI(14), SMA(20), MACD(12/26/9)를 기본 지원한다. 대화로 기간, ticker, 봉 주기, 표시 개수를 변경한다. 표시 개수는 2~200, 지표 기간은 2~200, MACD slow는 3~200이며 fast < slow다. 지표별 한 설정만 지원한다. EMA·백테스트·주문·통합 매매 점수는 범위 밖이다.

수정 OHLC를 사용한다. 현재 진행 중인 일봉은 제외한다. 주봉은 거래소 현지 다음 월요일부터 완료로 간주하는 보수적 정책이다. 휴일별 주간 조기 종료 판정은 하지 않는다. 준비 구간은 `max(250, 5 * 최대 lookback)`이며 표시 범위 앞에 추가 조회한다. 이력 부족과 null은 숨기지 않고 판단 불가/제한을 표시한다.

## TA-003 지표별 시그널

- RSI: 70 이상 과매수, 30 이하 과매도, 나머지 중립.
- SMA: 종가-SMA의 부호로 위/아래/동일. 직전 차이 ≤0이고 현재 >0이면 상향 교차, 직전 ≥0이고 현재 <0이면 하향 교차.
- MACD: MACD-Signal에 같은 위치/교차 규칙을 적용하고 histogram을 표시한다.

최신 완료 봉과 직전 봉을 사용한다. 두 유효값이 없으면 교차 판단 불가다. LLM은 결정적 계산 결과를 설명하며 과매수/과매도를 자동 매수·매도 명령으로 해석하지 않는다.

## TA-004 표현과 오류

종가/SMA, RSI(30/70 기준선), MACD/Signal 및 histogram 차트를 제공한다. 날짜 범위·통화·수정주가 여부·기준일·조회 시각·Yahoo 출처를 함께 표시한다. 값은 서버의 TA-Lib 결과로 직접 OpenUI 프로그램에 삽입한다. 공급자 실패 시 기존 분석을 최신 결과로 재출력하지 않는다. UI 검증 실패 시 계산 시그널을 텍스트로 제공한다.

## TA-005 대화 격리

같은 thread의 후속 요청은 이전 ticker·주기·기간·지표 설정을 유지한다. 그래프 변경은 새 thread를 시작하며 실행 중에는 선택을 비활성화한다. 기존 메시지 차트는 새 분석으로 덮어쓰지 않는다. 새로고침 후 브라우저 대화 복원은 현재 범위 밖이다.
