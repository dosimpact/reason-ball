- 요구사항: SEC-CHART-002, SEC-CHART-005, SEC-CHART-006
- 대상: `3-langgraph-fast` 추출 도구, 실제2820 사용자 프롬프트 회귀
- 상태: 수정 반영, 실서비스 재검증 진행 중
- Stock: [재무 차트](../stock/tech-shared/a2ui-system/sec-financial-charts.md)

## 관찰과 원인 범위

사용자 Chrome의 SEC 화면에서 Coupang 2026-02-26 제출 10-K 선택과 “이 보고서의 매출과 영업이익을 연도별 그룹 막대로 비교해줘” 요청의 NO_VERIFIED_DATA 응답을 확인했다. 동일 원문·동일 문장을 직접 실제 모델에 다시 전달했을 때 section-24/table-169에서 6개 관측치가 정상 검증됐다. 따라서 원문 데이터 부재는 아니다. 최초 실패의 셀 매핑/거절 사유는 기존 코드가 일반 오류로 대체했으므로 최초의 정확한 세부 사유는 복구하지 못했다. 재현 성공을 최초 원인의 확정으로 취급하지 않는다.

기존 코드는 schema-valid ExtractionProposal도 셀 검증에 모두 실패하거나 observations가 비어 있으면 즉시 일반 오류로 종료했다. 구체적인 거절 사유를 모델에 전달하는 교정 경로가 없었다. 기존 브라우저 테스트는 회사·공시·연도·연결 범위를 한 문장에 명시하여 사용자 예시의 두 단계 흐름과 달랐다.

## 변경

- 모델 입력에 서버 선택 공시의 formType/reportDate/filingDate를 문맥으로 추가한다.
- 검증된 숫자가 하나도 없을 때 이미 읽은 표와 최대12개 거절 사유로 매핑을 한 번 교정한다. 외부 읽기·다른 공시·숫자 생성은 허용하지 않고 동일 검증기를 다시 적용한다. 기존120초 전체 상한을 유지한다.
- 교정 후에도 실패하면 최대3개/600자 상세 사유를 도구 오류로 반환한다. 이전 화면과 선택은 보존한다.
- 테스트는 먼저 공시를 선택한 뒤 페이지의 짧은 예시 문장을 그대로 제출한다.

## 현재 검증

- 파서/차트 계획/도구 Python: 31 PASS. 새 회귀는 잘못된 기간 헤더 교정, 빈 매핑 교정, 존재하지 않는 셀의 재거절 및 상세 오류를 검사한다.
- API와 실제 브라우저 결과·자원 정리는 후속 최종 검증 기록에 추가한다. 이 기록만으로 전체 완료를 선언하지 않는다.
