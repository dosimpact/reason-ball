# 청월당 사주·타로 조사·역기획 문서 골격

- 날짜: 2026-09-21
- 범위: 외부 서비스 역기획 자료, `docs/reverse-biz/`
- 관련 결정: CWD-DOC-001
- 상태: 문서 구조 검증 완료. 서비스 조사·트렌드 조사·역기획 분석은 시작 전.

## 맥락

사용자는 사주와 타로를 모두 분석하고, 실제 화면·동작을 전수 조사한 뒤 역기획서를 작성하도록 요청했다. 관찰 사실을 별도 문서로 보존하며 UI·이미지·캐릭터의 최신 트렌드와 개발 착수에 필요한 비즈니스 맥락을 충분히 담아야 한다. 하위 파일 수는 제한하지 않는다.

## 변경

- [청월당 문서 맵](../reverse-biz/cheongwoldang/INDEX.md)을 중심으로 49개 작업 문서와 하위 템플릿을 구성했다.
- [프로젝트 계약](../reverse-biz/cheongwoldang/00-project-contract.md)에 범위, 문서 소유권, 분할 기준, 조사·개발 착수 게이트를 정의했다.
- [팩트북](../reverse-biz/cheongwoldang/factbook/INDEX.md)에 공통 화면·행동·문구·배치·자산·가격·회원·보관함과 사주·타로별 기록을 분리했다.
- [사실·증거 원장](../reverse-biz/cheongwoldang/factbook/09-evidence-register.md)과 [커버리지](../reverse-biz/cheongwoldang/factbook/07-coverage-gaps.md)를 단일 원본으로 지정했다.
- [역기획 맵](../reverse-biz/cheongwoldang/analysis/INDEX.md)에 통합 비즈니스·시스템 문서, 공통 정책, 도메인별 입력·생성·결과, 시각 트렌드·제작 계약, 요구사항·인수 기준을 연결했다.
- [세부 템플릿](../reverse-biz/cheongwoldang/templates/INDEX.md)으로 화면·상품·여정·기능 단위의 추가 파일 작성을 지원한다.
- 기존 두 단일 파일 템플릿은 전체 항목 확인용으로 보존하고 실제 기록은 하위 문서에서 작성하도록 안내했다.
- 상위 [문서 맵](../INDEX.md)에 외부 서비스 연구의 진입 경로를 추가했다.

## 이유와 원본 경계

FACT → 근거 있는 해석·가설 → 재구축 제안·합의 → 기능·계약·인수 기준으로 추적한다. 많은 파일로 분리해도 맥락이 유지되도록 INDEX와 통합 설계 문서를 둔다. 예시 표·ID·가설은 실제 서비스 사실로 취급하지 않는다.

외부 서비스 연구 자료이므로 제품 구현 stock에는 반영할 변경이 없다. 현재 저장소의 실제 기능이나 시스템 구조를 변경한 것이 아니다. 관련 없는 기존 변경과 기존 flow는 수정하지 않았다.

## 검증

문서 전용 변경이므로 [검증 원칙](../validation/INDEX.md)의 링크·구조·diff 검사만 적용했다. VAL-API-001, VAL-VIEW-001, VAL-BROWSER-001은 코드·동작 변경이 없어 적용 대상이 아니다.

- Node의 읽기 전용 재귀 검사로 reverse-biz 아래 52개 Markdown의 상대 링크, 표 열 수, 코드 블록 닫힘, 제목 뒤 빈 줄을 확인했다: 오류 0.
- 진입 INDEX에서 링크를 따라 52개 문서 모두에 도달함을 확인했다: 고립 문서 0.
- `git diff --check -- docs/INDEX.md` 통과. 추가한 문서 라우팅과 기존 변경을 구분해 검토했다.
- 서비스 기능, 실제 트렌드, 상품 가격, 결제 후 동작에 대한 검증은 수행하지 않았다. 문서 구조 검증을 서비스 조사 완료로 표시하지 않는다.

## 후속 작업

실제 브라우저 탐색을 통해 환경·화면·상품별 FACT와 캡처를 먼저 수집한다. 미조사 항목과 차단 항목을 추적하고 조사 완료 판정 후 분석 문서를 작성한다. 가격·결과 생성·이용권 등 내부 정책이 확인되지 않으면 가설 또는 신규 설계 결정으로 구분한다.
