# SEC Chat 대화 기록

- 배경: 페이지 전환이나 새로고침 후 이전 대화를 열 수 없었다.
- 변경: 브라우저 localStorage에 최근 50개 대화의 메시지·표시 정보·기업 및 분석 세션을 저장하고 대화 기록에서 다시 연다. 새 대화는 이전 기록을 지우지 않는다. 서버 세션이 만료되면 기존 대화는 보존하고 재질문 시 공시를 다시 준비하도록 안내한다. 서버 재시작 뒤 이전 서버 대화 문맥 자체는 복원되지 않는다.
- Stock: [SEC Chat](../stock/sec-chat.md).
- 검증: 저장/복원·잘못된 데이터·개수 제한 단위 테스트 2/2 및 변경 파일 lint PASS. Host 전체 typecheck는 별도 작업 중인 LangGraph 채팅의 ChatContextValue runtime 타입 오류 3건으로 실패했다. 브라우저 검증은 사용자가 수행한다는 기존 요청에 따라 실행하지 않았다. 저장·복원 E2E 시나리오를 추가했다.
