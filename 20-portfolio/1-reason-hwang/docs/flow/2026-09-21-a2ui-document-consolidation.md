# A2UI 기술 문서 통합

- 날짜: 2026-09-21.
- 사용자 요청: `docs/stock/tech-shared/a2ui-system/`에 모든 A2UI 기술 내용을 정리한다.
- 결정 DOC-A2UI-001: 해당 폴더의 [INDEX](../stock/tech-shared/a2ui-system/INDEX.md)를 공통 진입점으로 사용한다. 시스템·Registry·React·LangGraph·프로토콜/action/SSE·SEC·운영/검증으로 분리한다.
- 기존 패키지 a2ui.md는 원본 기술 문서로 연결하는 안내문으로 변경한다. SEC 도메인은 업무 요구사항을 유지하고 기술 원본을 새 폴더로 연결한다. 사용자 명시 요청에 따른 기술 문서 소유 위치 변경이며 다른 도메인 문서 정책은 변경하지 않는다.
- 현재 코드의 manifest(4프로필), 66개 inventory, 모델 설정, SSE 진행 callback, SEC 발췌/인용/상태 코드를 대조했다. 오래된 공통 문서 테스트 개수는 운영 문서의 실행별 증거로 통합했다.
- 불일치: SEC `원문 조회` 시각은 실제 코드에서 모델 생성 후 기록한다. 문서에 제한 및 후속 코드 보정 필요를 명시했으며 이 문서 작업에서 코드를 변경하지 않았다.
- 미완료: API-key 실모델, SEC 예외 시나리오 전체, 최종 build/wheel/lint 재검증 등은 완료로 바꾸지 않았다.
- 이력 원칙: 기존 flow는 수정하지 않았다. 문서 이동을 위해 과거 실행 기록을 다시 쓰지 않았다.
- 검증: 새 문서와 수정된 진입점의 로컬 링크·파일 존재, manifest/inventory 대응과 diff 공백 검사를 수행한다. 문서만 변경하여 API/Storybook/브라우저 실행 검증은 이번 변경 자체의 대상이 아니다.
