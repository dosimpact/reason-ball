# SEC A2UI 목표 확장

- 날짜: 2026-09-21 KST
- 배경: 사용자가 기존 데모 이후 SEC 회사 조회와 보고서 생성 use case의 A2UI를 추가 요청했다.
- 확정: 보고서 생성은 선택한 공시를 근거로 분석·요약 보고서를 만드는 기능이다. 사용자 선택으로 확인했다. 원문 수집 작업과 구분한다.
- 영향: [SEC 전용 설계](../stock/us-corporate-filings/a2ui-system.md), 공용 카탈로그, Host, LangGraph. 기존 BFF 조회 계약을 재사용한다.
- 검증 계획: SEC-A2UI-01~07의 회사 검색·공시 선택·근거 보고서·오류·격리를 순차 단위/Storybook/API/MCP 검증한다.
- 현재 상태: 기존 A2UI OAuth 검증은 완료됐지만 별도 API-key 실증은 미완료다. 목표에서 제외하거나 완료로 바꾸지 않는다. SEC 기능은 설계 단계이며 아직 구현 완료를 주장하지 않는다.
- 보존: 새로 관찰한 사용자 소유 `docs/reverse-biz/` 파일은 수정하지 않는다.
