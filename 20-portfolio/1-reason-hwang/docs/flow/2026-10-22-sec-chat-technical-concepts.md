# 2026-10-22 · SEC Chat 기술 개념 정리

- **맥락:** 사용자가 SEC Chat stock에 구현 이해에 필요한 주요 기술 개념 정리를 요청했다.
- **변경:** `SEC-DOC-001`로 실행·데이터 접근, 응답·이벤트, 근거·상태, SEC 용어, 화면별 책임과 카탈로그 유지보수를 추가했다.
- **이유:** LangGraph와 Deep Agent, tool calling과 HTTP, OpenUI DSL과 AG-UI/SSE, 세션과 체크포인트를 구분하여 현재 코드의 책임과 한계를 설명한다. 추천 질문 after-answer는 기존 채팅에만 연결되고 전체 수집 제한은 프롬프트 정책임을 명시했다.
- **Stock:** [SEC Chat 주요 기술 개념](../stock/sec-chat.md#주요-기술-개념).
- **검증:** 관련 그래프·도구·출력 파서·라우터·동기화 스크립트와 대조했다. 문서 상대 링크와 diff 검사를 수행했다. 실행 코드 변경이 없어 API·Storybook·브라우저 테스트는 적용 대상이 아니다.
