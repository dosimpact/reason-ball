# 2026-09-30 화면 UX 검토와 현재 상태 동기화

## 날짜·배경

2026-09-30. 실제 브라우저의 발견·채팅·기록·프로필·저작·상세 화면에서 중복 탐색, 과도한 목록, 구현 용어와 어두운 테마의 낮은 대비를 확인했다. 변경 전후 자료는 [`evidence/2026-09-30-ux-refactor/`](evidence/2026-09-30-ux-refactor/)에 있다. 후속 수정한 홈·캐릭터 목록/상세·미션 상세·Artifact 화면을 다시 캡처했다. [화면별 색인](evidence/2026-09-30-ux-refactor/README.md)에 13개 페이지 템플릿과 추가 탭·대화상자의 대표 상태를 연결했다. 이는 모든 오류·데이터 조합의 시각 검증을 뜻하지 않는다. 세부 코드 정리와 개별 정적 검증은 [`2026-09-30-code-cleanup.md`](2026-09-30-code-cleanup.md)에 기록했다.

## 변경·이유·영향

- `REF-03/04`, `DISC-01`: 데스크톱 중복 사이드바를 정리하고 상단 탐색과 모바일 메뉴·하단 탐색을 사용한다. 홈의 가짜 오디오·신뢰도 표시와 같은 캐릭터의 중복 노출을 제거해 보이는 행동과 실제 연결을 일치시켰다.
- `CHAR-07`, `MISSION-06`, `DISC-03/04`: 캐릭터 상세의 관련 미션은 최대 6개로 제한하고 전체는 캐릭터 필터 링크로 연다. 미션 목록은 이전·현재 페이지 선택·다음으로 모든 페이지를 탐색한다. 카테고리별 장소 옵션과 로딩·오류·빈 결과를 분리한다. 대화 수를 학습자 수로 오인하지 않게 표시하고, 실제 평점 데이터가 없는 캐릭터 카드·상세의 임의 별점을 제거했다. 자유 대화와 추천 미션 행동도 분리했다.
- `CHAT-02/04`, `REF-08`: 채팅 본문의 내부 대화 ID는 숨기되 관리 화면에서 확인할 수 있다. 모델 capability의 지원·미지원·미확인 구분은 유지하고 배포 구현 설명을 줄였다. 추천 질문·모델 선택 컨트롤에는 테마 색상 토큰을 적용했다.
- `PROFILE-01`, `REF-04`, `REF-24~30`, `NFR-02`: 기록·프로필과 해당 하위 카드, 저작·상세·Artifact 작업영역에서 밝은 카드에 밝은 글씨가 겹치던 부분을 semantic token으로 정리했다. Artifact 목록·편집기·미리보기·버전 비교의 어두운 테마 대비를 맞췄다. 기록의 `turnCount`는 실제 메시지 수로 표시하며 빈 미리보기를 설명한다. 의도된 고정 색상 히어로와 개인정보 안내는 배경·글자 짝을 유지한다.
- 저작 화면의 mock·Route 구현 문구를 사용자 행동 안내로 바꾸고 근거 없는 자동 난이도 보장 문구를 제거했다. AI 초안·이미지 생성 상태와 실제 지원 여부의 서버 판단은 유지한다.

후속 소스 확인에서 캐릭터 이미지 후보의 출처 배지도 `AI 이미지 후보`로 바뀌었다. 이는 사용자에게 보이는 해당 구현 용어의 정리이며 AI 공급자의 이미지 품질 검증은 아니다. 평점 제거는 평점 집계 기능의 구현을 뜻하지 않으며, Artifact 색상 수정은 저장·버전 로직을 변경하지 않는다. 영향받는 저량 절은 `business-design.md` 2·4장과 `system-design.md` 2.1·5.2다.

최종 문서 대조에서 `REF-03` 저량 표에 남은 `desktop/mobile sidebar` 표현을 현재 상단 탐색·모바일 메뉴·하단 탐색 구조로 바로잡았다. 화면별 색인의 13개 경로와 `after/` 캡처 32개도 파일 존재를 확인했다.

## 검증·후속

`pnpm --filter @ai-english-chat/web exec tsc --noEmit --noUnusedLocals --noUnusedParameters`가 통과했다. 앱 lint는 오류 0건, 기존 `<img>` 권고 경고 3건이다. 각 수정 단위의 typecheck·ESLint 결과는 코드 정리 기록에 구분해 남겼다. 원격 production 전체는 118 PASS / 4 FAIL, 수정·영향 범위 재검증은 31 PASS / 1 FAIL, 마지막 목표 추적 재검증은 2 PASS였다. 발견된 실패는 모두 해당 후속 실행에서 통과했으며 [실행별 기록](2026-09-30-production-e2e.md)을 따른다. 변경 후 Chrome 캡처 32개를 확보했고 점검 계정과 소유 데이터를 정리했다. 최종 계약 검사 292개와 미사용 지역 변수·매개변수 검사가 통과했다. 원격 DB·실제 AI 품질·전 화면 시각 완료 판정은 [테스트 설계](../stock/test-design.md)의 최종 검증 기록을 따른다.
