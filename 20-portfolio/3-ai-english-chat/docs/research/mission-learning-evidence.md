## 미션 작성 계약

1. **필요성:** 학습자가 겪는 구체적 불편과 완료 후 얻는 결과를 한국어 한 문장으로 적는다. 상대 역할, 장소, 필요한 정보, 선택 또는 제약이 있어야 한다.
2. **준비:** 초보에게 뜻과 사용처를 설명하고 짧은 표현 예시를 제공한다. Pre-A1은 알파벳·이름·숫자·yes/no·도움 요청 같은 진입 과제를 포함한다. 독립 문장 생성과 암묵적 문법 지식을 진입 조건으로 요구하지 않는다.
3. **수행:** 상대가 확인 질문을 하거나 미공개 정보를 제공한다. 사용자의 응답이 다음 진행에 실제 영향을 주도록 한다. 예시 문장의 정확 일치나 메시지 개수는 성공 기준이 아니다.
4. **지원:** 의도 → 핵심 표현 → 예문 지원은 선택 가능하게 한다. 지원 사용을 실패로 처벌하지 않으며 도움받은 성공과 독립 수행을 구분한다. 점진 지원 방식은 본 서비스의 설계 선택이고 위 논문이 이 정확한 세 단계 UI를 검증한 것은 아니다.
5. **피드백:** 먼저 과업 결과를 확인한다. 의미 전달을 막거나 학습 목표와 직접 관련된 오류를 우선하여 짧게 설명한 뒤 재시도한다. 자연스러운 표현의 차이를 무조건 오류로 처리하지 않는다.
6. **회상·전이:** 예문 없이 다시 해보고 정보·상대·조건 중 적어도 하나를 바꾼다. 새 상황에서 수행해야 암기한 대본 의존을 확인할 수 있다.
7. **간격:** 예를 들어 1/3/7/21일 재방문은 실행 가능한 초기 가설이며 논문이 검증한 최적 스케줄이 아니다. 실제 성취와 부담을 보고 조정한다. JSON의 일정은 향후 실행할 제안이며 자동 스케줄러 구현을 뜻하지 않는다.

## 수준과 규모

Pre-A1은 완전 초보의 진입을 지원하고 A1/A2는 예측 가능한 거래와 짧은 사회적 대화, B1은 설명과 문제 해결, B2는 근거·대안·협상, C1은 정교한 관계 조율과 전문 담화, C2는 함축·문체·다자 이해관계·복합 매개를 연습한다. 이는 작성 방향이며 독립적으로 검증한 CEFR 시험 등급이 아니다. 고급 과제의 난이도를 희귀 단어·긴 문장만으로 올리지 않는다.

미션 수는 과학적으로 정해져 있지 않다. 실제 필요의 폭, 수행 기능, 난이도 증가, 전이 조건을 기준으로 수를 결정한다. 단순히 같은 텍스트의 이름과 숫자를 바꾸어 수천 개로 늘리는 것은 교육과정 확대가 아니다. 모든 카테고리를 모든 레벨에 억지 배치하지 않고 학습자가 관심 분야를 선택하되 기초 의사소통 기능을 반복 접하도록 한다.

C2는 모든 원어민과 동일하다는 뜻이 아니다. 완료 개수만으로 원어민 수준을 보증하지 않는다. 텍스트 AI 대화는 발음·청취·실시간 회화 능력을 충분히 측정하지 못한다. 실제 듣기·말하기·읽기·쓰기 경험과 외부 상호작용은 병행해야 하며 오디오가 없는 과제를 청취 평가로 표시하지 않는다.

## 검증과 운영의 구분

- **콘텐츠 정합성:** JSON 구조, 고유 ID, 경로, 출처·선수 참조, 레벨과 카테고리, 필수 목표와 평가 항목을 검사한다.
- **교육 내용 검토:** 영어 자연스러움, 한국어 설명, 대상 수준, 실제 필요, 분기와 정보 차이, 목표-루브릭 대응을 사람이 검토한다. 스키마 통과만으로 이 검토를 대체하지 않는다.
- **효과 검증:** 사전 과제 대비 즉시 수행과 지연 수행, 새로운 조건의 전이, 도움 사용, 이탈 이유를 기록한다. 실제 학습자 표본 없이 효과 PASS로 표시하지 않는다.
- **고급·민감 상황:** 의료·법률·금융·긴급 상황은 의사소통 연습이다. 모델의 전문 판단을 정답으로 두지 않고 필요한 정보를 전달하고 해당 담당자에게 확인하는 결과를 둔다.

연구 파일은 작성 근거다. 앱 importer, 원격 게시, CEFR 인증, 실제 학습자 효과 실험이 이 파일로 구현되거나 완료되지는 않는다.
