## 내용 검토 결과와 한계

- pre-A1은 이름·숫자·선택·확인·중단·도움 요청의 한 단어 또는 짧은 청크를 허용하며 한국어 cue를 제공한다. 초급의 복사·치환 연습은 가능하지만 새로운 독립 미션 수로 세지 않는다.
- A1/A2는 구체 정보 전달과 일상 거래, B1/B2는 이유·문제 복구·대안·기준 비교를 요구한다. C1/C2는 함의, 전제, 역할·권한, 과장 정정, 관계와 사실의 긴장을 중심으로 작성됐다. 긴 문장이나 희귀 어휘만으로 난도를 정하지 않았다.
- 업무의 고급 예문은 선택 가능한 표현 모델이다. 모든 학습자가 해당 전문 지식을 이미 가진다고 가정하지 않도록 가상 입력 사실이 필요하다. 이번 검토에서 명확히 발견한 입력 누락 4건을 수정했다. 이 편집 검토는 모든 가능한 실행에서 AI가 모호함 없이 응답한다는 보증이 아니다.
- 관계의 고급 미션은 부탁·거절·사과를 반복하되 과업 결과를 다르게 둔다. 예를 들어 초대의 공개 범위 변경, 개인 경계와 타인 통제, 집단 대표성, 설명과 옹호의 차이는 서로 다른 판단을 요구한다. 이를 난해한 표현 암기 시험으로 운영하지 않는다.
- 고급 예시는 한국어 목표와 cue를 읽고도 어려울 수 있다. 실제 학습자 표본에서 이해 부담, 현실 필요성, 무힌트 전이를 검증한 뒤 난도와 지원량을 조정해야 한다. 현재 상태는 `draft`다.
- 업무 outcome은 목표들을 `/`로 연결한 요약 형식이 많다. 내용상 과업에 대응하지만 출시 편집에서 자연스러운 실생활 결과 문장으로 다듬을 수 있다. 파일 생성·참조 검증 통과와 교육 효과를 구분한다.

## 실행한 확인

Python JSON 파싱 및 교차 집계로 두 파일 각각 다음을 확인했다.

- 168개 레코드, 세부 분류 6개 × 수준 7개 = 42개 셀, 셀마다 4개
- 파일별 slug 168개 모두 고유
- 모든 미션 단계 3개 = 파일별 504개 단계
- 모든 단계의 goal/example/cue 비어 있지 않음

이 검사는 본문 schema/연구 참조/생성 catalog 검증을 대체하지 않는다. 수정한 원본을 다시 컴파일하고 전체 catalog validator를 실행해야 한다. 실제 음성, 독립 대화 수행, 학습자 효과는 별도 검증이다.
