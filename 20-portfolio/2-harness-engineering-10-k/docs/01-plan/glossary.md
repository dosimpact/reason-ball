# Glossary

> **Summary**: Terminology for the initial simple chatbot project.
>
> **Author**: Codex
> **Created**: 2026-03-21
> **Status**: Draft

---

| Term | Definition | Korean | Example |
|------|------------|--------|---------|
| Chat Session | A single in-memory conversation shown in the UI during one browser session | 채팅 세션 | Open the page and exchange messages before refresh |
| Message | One chat item authored by the user or assistant | 메시지 | "Hello" or the assistant reply |
| Role | The sender type of a message | 역할 | `user`, `assistant`, `system` |
| Prompt | The text entered by the user to request a response | 프롬프트 | "Explain Next.js briefly" |
| Response | The assistant output returned through the AI flow | 응답 | Generated chatbot answer |
| Chat UI | The visible page containing the message list and input form | 챗 UI | Main chatbot screen |
| Vercel AI SDK | The library used to manage AI chat interactions in the app | Vercel AI SDK | `useChat` or equivalent chat helpers |
