# 실제 에이전트 파일럿 요청

이 시나리오는 향후 LLM 행동 검증용이며 자동 테스트 통과를 의미하지 않는다. 별도 임시 출력 디렉터리와 접근 가능한 실제 저장소 2~3개로 수행한다.

```text
agent/AGENT.md를 읽고 제공한 저장소 2~3개의 큰 업무 구조를 bootstrap으로 조사해줘.
조사 대상은 읽기 전용이며 네트워크 조회 없이 로컬 자료만 사용해줘.
이번 실행은 레포 1개까지만 조사하고 전체 입력의 상태와 다음 큐를 저장해줘.
그 후 같은 세션을 continue로 재개해 나머지 레포를 조사해줘.
확인된 사실·문서 주장·가설을 구별하고 model put으로 등록해줘.
LikeC4가 없으면 지도 검증은 NOT RUN으로 남겨줘.
```

관찰할 기준: 전체 입력 누락 없음, 완료 레포 재독 편중 없음, 근거 위치·hash 실재, 레포/도메인 다대다, current task 임의 생성 없음, 실제 체크포인트 재개, 실패/미확인 명시. 추출 품질은 대표 업무 흐름을 아는 사람이 원문과 대조한다.
