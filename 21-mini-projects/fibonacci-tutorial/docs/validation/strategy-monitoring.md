## 핵심 확인 사항

- 자동 중단: 진입 전 무효화는 체결 없이 취소하고 보유 중 무효화는 모의 청산한다. SL과 별도 가격 경계를 사용한다.
- 순서 불명: 같은 봉에서 경쟁 조건이 발생하면 INDETERMINATE로 보존한다. 고정 최초 위험으로 R을 계산한다.
- 중복·불변성: 같은 봉을 다시 읽어도 이벤트가 늘지 않는다. stale/중복 중단은 409이며 이전 revision과 평가 기록을 보존한다.
- 평가: 기존 touch-v1 가격 비교와 실행 모니터링 손익을 구분한다. 수동 중단도 새 평가 요약 또는 이벤트 감사 기록으로 남는다.
- UI: 기본 정책, 경고 전용 경계, OPEN→수동 ABORTED, 로그, 중복 거절을 검사한다. 실제 개발 화면에서 라이트·다크·모바일 표시도 확인했다.
- 자동 감시: 시작 즉시 조회, 60초 주기, 중지 후 무호출을 Playwright 가상 시계와 응답 mock으로 검증했다. 이 검사는 외부 Binance의 실시간 가용성 증거가 아니다. Binance 어댑터는 별도의 API stub 계약 검사로 검증한다.
- Storybook: PENDING, OPEN, WARNING, INVALIDATED_STOP, ABORTED 상태와 기존 화면·다크 테마를 검사한다.

## 검증 중 발견 및 수정

강화된 계획 검증은 확정 순간 종가가 이미 무효화 가격 이하인 계획을 거절한다. 기존 시장 테스트가 이런 기준점을 선택해 최초 통합 실행에서 API 4건이 연쇄 실패했다. 유효한 공개 종가 조건을 테스트의 기준점 선택에 추가했으며 서버 검증은 유지했다.

## 적용 범위

교육용 long 모의매매, 수량 1·수수료 및 슬리피지 0이다. 현재가는 마지막 확정봉 종가이며 틱 실시간 가격이 아니다. 브라우저의 Binance 자동 감시는 화면을 열고 시작한 동안 동작한다. 서버 백그라운드 거래나 실제 주문은 포함하지 않는다.

최종 통합은 42개 브라우저 검사와 동시 Replay·서버 재시작 복원을 통과했다. 소유한 테스트 프로세스와 임시 데이터는 정리했으며 사용자 개발 서버 4310은 유지했다.
