# 독립 전략 계획·모니터링 페이지 계획

날짜: 2026-09-27. 결정 ID: SM-002. 상태: 계획 반영 완료·구현 전.

## 맥락과 변경

사용자가 연습 내 모니터링 외에 계획 → 모니터링만 수행할 수 있는 별도 페이지를 요청했다. master-plan의 해당 섹션을 전용 전략 목록·계획 작성·상세 모니터링 흐름으로 확장했다. 튜토리얼 진도와 독립적으로 초안·확정·revision·실행 이력을 관리하고 공통 상태 머신과 데이터·UI를 재사용하도록 정했다.

## 이유와 영향

튜토리얼 과제 없이 실제 시장 전략을 작성하고 다시 확인할 수 있어야 한다. 가짜 유닛에 종속시키지 않도록 독립 전략 문맥을 설계하고 기존 JSON 호환을 요구했다. [비즈니스 설계](../stock/business-design.md)와 [시스템 설계](../stock/system-design.md)에 확정 계획을 미구현으로 구분해 반영했다. 기존 완료 flow와 검증 결과는 변경하지 않았다.

## 검증과 후속

이번 변경은 문서만 수정했다. 경로·상태 명칭·기존 정책과 상대 링크를 점검했다. 독립 페이지의 런타임 검증은 수행하지 않았다. 다음 작업은 세션 종속 계약의 분리와 독립 저장/API 상세 설계, 더미 데이터 Walking Skeleton 구현 및 검증이다.
