# 독립 전략 백테스트·포워드 요구 추가

날짜: 2026-09-27. 결정 ID: SM-003. 상태: 요구사항 반영 완료·구현 전.

## 요청과 결정

사용자가 계획 이후 백테스팅과 포워드 테스팅을 모두 수행하도록 요구했다. 독립 페이지 계획에 모드 선택, 과거/현재 기준 시점, 백테스트 재생·일괄 실행, 새 확정봉 포워드 감시를 추가했다. 전략·계획 revision·실행 ID를 분리해 결과를 보존한다.

## 판단 근거

미래 데이터를 본 뒤 세운 과거 계획과 사전 확정한 실시간 관측은 검증 의미가 다르다. 미래 정보 차단, 확정 이후 봉 사용, 방식·구간·체결 가정 표시를 명시했다. 과거 계획의 현재 적용은 재검증한 revision으로 남기며, 실행 완료·일시정지와 매매 청산 상태를 구분한다.

## 영향과 검증

master-plan의 전략 모니터링 섹션과 business/system stock에 반영했다. SM-002 계획에 대한 추가 결정이며 완료된 flow는 수정하지 않았다. 문서 링크와 요구사항 일관성을 점검했고 코드는 변경하지 않았다. 독립 백테스트·포워드 기능의 실행 검증은 구현 후 수행한다.

## 다음 작업

상세 스키마·API를 확정하고 더미 백테스트 수직 흐름부터 구현한다. 동일 입력의 재생/일괄 결과와 미래 정보 차단을 검증한 뒤 Binance 과거 데이터 및 포워드 감시를 연결한다.
