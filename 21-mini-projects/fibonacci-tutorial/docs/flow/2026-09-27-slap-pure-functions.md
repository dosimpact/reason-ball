# SLAP 순수 함수 원칙 보강

- 날짜: 2026-09-27
- 맥락: SLAP에서 저수준 작업을 최대한 순수 함수로 빼야 한다는 사용자 기준.
- 변경: 계산·변환·판정은 순수 함수로 분리하고 네트워크·저장·시간 조회는 부작용 경계로 두는 원칙을 계획, 시스템 stock, 프로젝트 작업 규칙에 반영.
- 이유: 저수준 규칙의 재현성과 단위 검증 가능성을 높이고 상위 흐름의 추상화 수준을 일정하게 유지하기 위해.
- 영향 stock: `docs/stock/system-design.md`의 슬라이스 의존과 SLAP.
- 검증: 계획·stock·작업 규칙의 원칙 일치 확인, Markdown 25개 파일의 로컬 링크 누락 0건. 코드 변경 없음.
- 후속 상태: 실제 함수 경계와 순수 함수 테스트는 구현 시 확인.
