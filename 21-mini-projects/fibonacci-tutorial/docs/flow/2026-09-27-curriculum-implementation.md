# 44유닛 커리큘럼 구현

날짜: 2026-09-27. 상태: 완료. 목표: CUR-EW-001 전체10챕터44유닛과 커리큘럼 메인 구현.

## 구현 계약

- 기존9개 v1 유닛·세션·TradePlan을 보존한다. 신규13이론·22연습을 추가한다.
- 메인(`/`, `/tutorials`)은 전체 챕터/유닛·목표·모드·진행/이어서 학습을 보여준다. 챕터 메인에서도 소속 유닛을 볼 수 있다.
- 이론5단계/퀴즈3문항2정답, 연습유닛별 과제·기본/반례/변형 사례·명시적 완료증거를 구현한다.
- 가격 측정·방향·차수·내부 구조·패턴 정책은 순수 도메인 로직, 시점·저장·네트워크는 서버 경계에 둔다.
- 공개 lesson view와 서버 answer key/미래봉은 분리한다. 실전 해석에 유일 정답을 강제하지 않는다.
- 신규 분석 계획은 매매 가격 없이도 관망/주·대안·무효화를 기록한다. revision/Replay/평가/회고를 원본과 분리한다.
- H/HR은 실제 Binance 과거 고정자료3구간, M은 동일UTC20일 1h480/4h120/1d20을 보존한다. 실데이터의 특정 파동 패턴은 보장하지 않는다.

## 역할

Sol 서브에이전트가 entities/콘텐츠·순수검증, server/API, UI/메인·Storybook을 분담하고 루트가 역사 데이터 원본 확보·통합·검증·문서 동기화를 담당한다.
