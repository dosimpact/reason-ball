# 단일 Elliott Wave 커리큘럼 확정

날짜: 2026-09-27. 결정: CUR-EW-001.

## 맥락과 결정

사용자가 기존 튜토리얼 외의 콘텐츠를 추가할 전체 커리큘럼 작성을 요청했다. 질문에 Elliott Wave/Fibonacci 심화를 선택한 뒤, “엘리엇트 파동이론 기술적 분석만 하나만 제대로”라고 범위를 명확히 했다. 이에 여러 독립 과정을 만드는 안을 채택하지 않고 단일 Elliott Wave 과정으로 확정했다.

10챕터44유닛(기존9 + 신규35)을 정의했다. Fibonacci는 파동 측정 도구로 포함하며 일반 지표·자산배분·자동매매 등은 제외한다. 각 신규 유닛의 ID·모드·학습/수행 내용·데이터 프로필·완료 증거를 작성했다. 공통 데이터 공개·규칙과 해석 분리·수료 기준·실전 평가·제작 순서를 명시했다.

## 근거와 한계

EWI Waveopedia의 패턴 분류와 Fidelity의 되돌림 설명을 확인하여 출처 문서를 남겼다. Leading Diagonal의 정의 차이, 입문 가격 동률 정책, 실전 복수 카운팅을 별도로 다룬다. 자료의 예측 보장 표현은 채택하지 않았다.

커리큘럼은 확정했으나 신규35유닛의 화면별 스크립트·OHLC fixture·실전 UTC 구간·런타임 구현은 앞으로 제작할 산출물이다. 기존9유닛과 과거 MVP 완료 기록은 보존했다.
