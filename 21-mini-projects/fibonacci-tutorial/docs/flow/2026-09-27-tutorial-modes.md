# 이론·연습 모드 설계

- 날짜: 2026-09-27
- 맥락: 튜토리얼이 나중에 확장 가능해야 하며, 단계별 설명·차트가 바뀌는 이론 모드와 사용자가 직접 수행하는 연습 모드가 필요하다는 요청.
- 변경: 유닛의 `mode`를 이론·연습으로 구분하고 이론 단계 모델, 연습 과제 모델, 모드별 진행 상태를 설계. 이론 `Next`와 Replay `Next Candle`을 구별.
- 이유: 새 유닛과 학습 방식을 추가할 때 기존 콘텐츠나 공통 차트 기능의 변경을 줄이기 위해.
- 영향 stock: `docs/stock/business-design.md`의 모드별 경험, `docs/stock/system-design.md`의 유닛 모델·진행 구조.
- 검증: 계획·stock의 모드 계약 일치 확인, Markdown 17개 파일의 로컬 링크 누락 0건. 구현 및 브라우저 검증은 없음.
- 후속 상태: 이론 단계의 상세 차트 명령, 진행 상태 보존 방식, 유닛별 과제·완료 조건은 상세 설계에서 결정.
