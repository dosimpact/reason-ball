# 독립 전략 페이지 구현

날짜: 2026-09-27. 결정: SM-002 / SM-003. 상태: 구현·검증 완료.

사용자가 확정한 전용 페이지·백테스트·포워드 테스트 요구를 실제 구현하도록 요청했다. [설계 및 수락 기준](../design/standalone-strategy-workspace.md)을 기준으로 진행한다. 도메인/서버, UI, API 검증을 Sol 에이전트가 분담하고 root가 공통 위젯 타입·통합·완료 감사를 담당한다.

기존 튜토리얼 저장 계약을 보존하고 독립 전략 ID·revision·run을 도입한다. 상세 검증 결과는 후속 기록한다. 영향 stock: 독립 전략 작업 공간, 백테스트·포워드 실행 모델.

## 첫 API 검증

독립 전략 시나리오 45건을 포함한 Bruno 133건과 Next 빌드가 통과했다. 독립 전략의 동시 진행 요청에서 한 요청만 적용되고 다른 요청은 409를 받았으며, 소유 서버 재시작 후 동일 JSON view가 복원되었다. 검증 서버와 임시 데이터는 정리했다. `/tmp/standalone-api.log`에 실행 로그를 남겼다. 최종 UI·Storybook·내보내기 계약 보완 이후 전체 검증을 다시 수행한다.

## 최종 구현과 검증

독립 목록·작성·상세, 부분 초안 저장, 불변 계획 revision, BACKTEST/FORWARD별 run, 오류 저장·재개, 자동 중단, 평가·JSON 내보내기를 구현했다. 더미 기준 봉·관측 수 선택 및 Binance 과거/최신 확정봉·캐시를 연결했다. 초기 자동 감시 타이머 재설정 문제를 수정하고, canonical JSON과 실행 감사 정보를 분리했다.

단위 86, Bruno 138, UI 27·Storybook 26, ESLint/FSD·타입·Next/Storybook 빌드와 동시 진행/서버 재시작 복원을 검증했다. 전체 통합 이후 최종 폼 변경을 포함한 새 빌드에서 UI 27건을 재실행해 통과했다. 실제 Binance 조회는 공식 OHLC와 일치했고 확인용 전략은 삭제했다. 소유 테스트 프로세스·포트·임시 데이터를 정리했으며 사용자 서버 4310은 유지했다.

master-plan의 독립 페이지 미구현 표기를 현재 구현으로 정정했다. business/system stock, 설계, 문서 지도·검증 안내·README·AGENTS를 동기화했다. 상세 증거와 남은 빌드 파일 추적 경고는 [검증 문서](../validation/standalone-strategy.md)에 기록한다. 실제 주문과 서버 상시 감시는 합의한 범위에 포함되지 않는다.
