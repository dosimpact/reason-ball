# 독립 유닛 모델·디렉터리 설계

- 날짜: 2026-09-27
- 맥락: 사용자가 각 튜토리얼을 독립적으로 구성할 수 있는 모델과 디렉터리 구조를 요청.
- 변경: Chapter·TutorialUnit·ChartScenario 모델, 유닛별 디렉터리와 공통 엔진 경계, 카탈로그 등록 방식을 설계. Lesson 1–6을 초기 유닛 주제로 정리.
- 이유: 새 유닛을 추가하거나 개별 유닛을 수정할 때 다른 유닛의 콘텐츠와 공통 로직을 건드리지 않도록 하기 위해.
- 영향 stock: `docs/stock/business-design.md`의 유닛 요구, `docs/stock/system-design.md`의 모델·디렉터리 구조.
- 검증: 계획·stock의 모델 및 경계 일치 확인, Markdown 14개 파일의 로컬 링크 누락 0건. 구현과 런타임 검증은 없음.
- 후속 상태: 실제 데이터 출처, 차트 시나리오 전달, 챕터 배치와 이동 방식은 상세 설계에서 결정.
