# 전략 실행 모니터링

날짜: 2026-09-27. 상태: 완료. 결정 ID: SM-001.

## 맥락과 결정

사용자가 master-plan의 전략 상태 머신, 매 봉 무효화, 조기 중단, UI 오버레이, 이벤트와 평가 연결을 구현 범위에 추가했다. 사용자가 선택한 기본 정책은 **미진입 취소·보유 포지션 자동 모의 청산**이다. 경고 전용 정책도 선택할 수 있다.

## 구현

- 순수 상태 머신, 서버 저장·복원, UI를 Sol 에이전트가 분담하고 root가 차트 오버레이·API 통합 검증·문서를 연결했다.
- 확정 계획의 정책과 무효화 규칙을 고정하고 공개된 봉만 순서대로 평가한다. OHLC 내부 순서 불명은 INDETERMINATE로 남긴다.
- 계획 revision별 상태와 이벤트를 보존하며 중복 봉·중복 중단을 방어한다. 수동 중단은 이유와 마지막 공개 종가를 기록한다.
- 차트의 무효화선·실행 이벤트와 패널의 건강도·손익·R·이격도를 제공한다. Binance 감시는 명시적으로 시작·중지하며 60초마다 확정봉을 조회한다.
- 기존 touch-v1 가격 비교 평가와 실행 결과를 구분한다. 수동 중단 결과도 평가 요약 또는 export 감사 기록에 남긴다.

## 검증과 수정

단위 78건, Bruno 88건, Playwright UI 23건·Storybook 19건, lint·FSD 경계·typecheck·Next/Storybook 빌드가 통과했다. 동시 Replay·서버 재시작 복원도 통과했다. 실제 개발 화면에서 라이트·다크·모바일 표시와 수동 중단을 확인했다.

최초 통합에서는 기존 시장 테스트의 무효화 기준점이 현재 종가보다 높은 경우 강화된 계획 검증에 걸려 API 4건이 실패했다. 유효한 기준점을 선택하도록 테스트를 수정하고 전체 통합을 다시 통과했다. 서버 검증은 유지했다. 자동 감시 UI 주기 검사는 가상 시계·응답 mock이며 외부 Binance 가용성을 의미하지 않는다.

테스트 소유 프로세스·임시 데이터를 정리하고 사용자 개발 서버 4310은 유지했다. 상세 증거와 적용 범위는 [검증 보고서](../validation/strategy-monitoring.md)를 따른다.
