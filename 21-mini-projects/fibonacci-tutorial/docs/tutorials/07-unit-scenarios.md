# Lesson 1–6 유닛 시나리오 명세

상태: 2026-09-27 전체 튜토리얼 구현 기준. 이 문서는 학습 내용과 시나리오의 기대 동작을 기록한다. 실행·저장 계약은 `docs/stock/system-design.md`를 따른다.

| 챕터 | 유닛 | 모드·과제 | 학습 완료 |
| --- | --- | --- | --- |
| 기초 | `impulse-theory` | 이론 4단계, 공개 봉 2→5→9→12개 | 마지막 설명 뒤 완료 |
| 기초 | `wave-counting` | 시작점과 1–5파 6점 카운팅 | 구조·3대 규칙 통과 |
| 기초 | `rules-theory` | 이론 4단계, 공개 봉 5→11→12→12개 | 경계 정책·가이드라인 확인 뒤 완료 |
| 기초 | `rules-practice` | 6점 카운팅 수정·재검증 | 구조·3대 규칙 통과 |
| 계획 | `wave-three` | 기존 8/12봉에서 0–2파, 계획, Replay | Replay 종료 및 평가 확인 |
| 계획 | `fibonacci-theory` | 이론 3단계, 공개 봉 4→7→12개 | 후보 가격의 의미 확인 뒤 완료 |
| 계획 | `fibonacci-practice` | 0–2파 기준점 3점 선택 | 올바른 기준점과 계산 확인 |
| 평가 | `trade-review` | 초기 8봉/전체 20봉에서 계획, Replay, 5파 이후 청산 판단 회고 | 원본 계획·결과·회고 확인 |
| 평가 | `market-lab` | 더미 또는 공개 Binance Spot 선택, 계획과 나중 평가 | 확정봉 기준 평가 확인 |

## 예시와 경계

| 유닛 | 데이터 소스 | 초기 공개/전체 봉 |
| --- | --- | --- |
| `impulse-theory` | 더미 전용 | 단계별 2→5→9→12 / 12 |
| `wave-counting` | 더미 전용 | 12 / 12 |
| `rules-theory` | 더미 전용 | 단계별 5→11→12→12 / 12 |
| `rules-practice` | 더미 전용 | 12 / 12 |
| `wave-three` | 더미 전용 | 8 / 12 |
| `fibonacci-theory` | 더미 전용 | 단계별 4→7→12 / 12 |
| `fibonacci-practice` | 더미 전용 | 8 / 12 |
| `trade-review` | 더미 전용 | 8 / 20 |
| `market-lab` | 더미 또는 Binance Spot | 더미 8 / 12, Binance 최대 80 / 120 |

- 6점 더미 예시는 봉 인덱스 `[0,2,4,6,8,10]`이다. 가격은 `100→120→110→140→125→150`으로 구성했다. 예시는 시도 전 응답에 포함하지 않는다.
- 3점 더미 예시는 `[0,3,6]`이며, 기존 `wave-three`의 초기 8봉·전체 12봉을 보존한다.
- `trade-review`만 초기 8봉/전체 20봉이다. 초기 0–2파 `[0,3,6]`에서 시작해 Wave 3 고점 11번 봉 145, Wave 4 저점 14번 봉 130, Wave 5 고점 17번 봉 160을 관찰한다. 18–19번 봉은 5파 뒤 127까지 내려가는 조정 사례다. 전체 6점 예시 `[0,3,6,11,14,17]`는 20봉 Replay가 완료된 뒤에만 공개한다.
- 6점 규칙 학습에서 Wave 2가 Wave 1 시작 가격과 **같으면 허용**, 더 낮으면 실패한다. “넘어서지 않는다”의 경계를 가격 비교로 명시한 튜토리얼 정책이다. 기존 3점 매매 계획의 `selectWavePoints`는 수익·위험 계산 가능한 유효한 반등을 요구하므로 시작점보다 엄격히 높은 Wave 2만 허용한다.
- Wave 3 길이가 Wave 1 또는 5와 **같아도 허용**한다. 두 파동보다 엄격히 짧을 때만 “가장 짧음”으로 실패한다.
- 이 튜토리얼의 표준 상승 구조는 고점이 계속 높아지는 경우를 연습한다. Truncated Wave 5는 확장 범위이며 이 연습의 통과 조건에 포함하지 않는다.
- 일반 Impulse의 Wave 4 저가가 Wave 1 고가에 **닿으면 겹침**으로 실패한다. Diagonal은 이 튜토리얼에서 다루지 않는다.
- 균등·교대는 힌트이며 불변 규칙 검증 결과를 바꾸지 않는다.
- Wave 1 `100→120`일 때 38.2%, 50%, 61.8% 되돌림 후보는 `112.36`, `110`, `107.64`다. Wave 2가 `110`이면 1.618 확장 후보는 `142.36`이다. 가격은 확정적 예측이 아니다.
- 무효화 가격은 선택한 카운팅의 기준이다. 사용자 Stop Loss는 실행 가능한 청산 계획의 가격이다. 둘은 다를 수 있다.
- 5파 완료 뒤 조정 가능성을 고려해 `close` 또는 `hold`와 이유를 기록한다. 이 판단은 과거 체결 결과를 바꾸지 않으며 ABC 카운팅이나 자동 익절을 뜻하지 않는다.
