# Lesson 3 — 불변 규칙과 참고 가이드라인

- Elliott Wave 3대 불변 규칙:
  - Wave 2는 Wave 1의 시작점을 넘어설 수 없다.
  - Wave 3은 Wave 1, 3, 5 중 가장 짧을 수 없다.
  - 일반적인 Impulse Wave에서 Wave 4는 Wave 1의 가격 영역과 겹치지 않는다.
- 선택형 힌트에서 규칙과 가이드라인의 차이를 소개한다. Wave 3이 확장된 경우 Wave 1과 5의 길이가 비슷해질 수 있다는 균등 가이드라인, Wave 2와 4의 조정 형태가 달라질 수 있다는 교대 가이드라인은 참고용이며 정답·무효 판정에 사용하지 않는다.
