# 엘리엇 파동이론 기술적 분석 — 전체 커리큘럼

결정 ID: CUR-EW-001. 버전: 1.1. 날짜: 2026-09-27.

**단일 과정 / 10챕터 / 44유닛 구현. 이론16·연습28.** 사용자가 확정한 주제는 엘리엇 파동이론 기술적 분석이다. 이 문서는 그 범위에 따른 커리큘럼 기준선이다. 앱 메인과 챕터 페이지에서 전체 목록과 학습 진행을 확인할 수 있다.

## 과정의 도착점

학습자는 주어진 시점의 가격 데이터로 파동의 종류와 차수를 설명하고, 주 카운팅·대안·무효화 기준을 기록한다. Fibonacci와 채널은 그 해석의 후보 가격·관찰 조건을 측정하는 도구로 사용한다. 이후 데이터를 열어 원래 분석의 타당성과 변경 이유를 검토할 수 있어야 한다.

- Fibonacci는 파동 분석 안의 측정 도구로 다룬다. 독립적인 Fibonacci 일반 과정으로 분리하지 않는다.
- 캔들·시간봉·위험/보상 설명은 파동을 읽고 판단을 기록하는 데 필요한 범위만 포함한다.
- RSI/MACD/이동평균, 일반 차트 패턴, 펀더멘털, 자산배분, 자동매매, 실거래 주문은 본 커리큘럼에 넣지 않는다.
- 수익률이나 미래 가격 적중은 수료 조건이 아니다. 규칙 적용·근거·시점 준수·재평가를 평가한다.

## 학습 대상과 진입

OHLC 캔들의 시가·고가·저가·종가와 시간 순서를 읽을 수 있는 입문자부터 시작한다. 해당 개념이 낯설면 C01 첫 단계의 용어 도움말에서 보충한다. 별도 일반 트레이딩 과정을 선행 필수로 만들지 않는다. 각 유닛은 독립 재방문 가능하며 선행 챕터는 권장 순서다. 종합 수료에는 전체 챕터 완료 증거가 필요하다.

C01–C03은 작은 전체 흐름을 먼저 경험하는 입문 구간이다. 이후 C04–C09에서 같은 흐름의 분석 깊이를 확장하고 C10에서 종합한다. 기존 Lesson 1–6의 번호와 새 C01–C10은 서로 다른 체계이며 [입문 매핑](chapters/01-03-foundation.md)에 연결했다.

권장 순서: `C01 → C02 → C03 → C04 → C05 → C06 → C07 → C08 → C09 → C10`. 예상 학습량은 이론 유닛 10–20분, 연습 20–40분이며 실전 재평가의 대기 시간은 별도다. 이는 제작용 추정치이며 측정된 수강 시간은 아니다.

## 이론과 연습의 역할

- 이론: 개념·표기 → 차트 사례 → 반례 → 적용 범위. Next/Prev로 설명과 차트가 함께 바뀐다.
- 연습: 직접 기준점/구간/차수 선택 → 규칙별 피드백 → 수정 → 예시 비교. Replay형은 원래 해석을 확정한 후 다음 봉을 공개한다.
- 숫자·규칙·시점은 자동 검증한다. 실전 카운팅의 유일한 정답을 가정하지 않으며 해석의 근거는 별도 루브릭으로 비교한다.
- 신규 유닛별 데이터·완료 기준은 각 챕터 문서에 고정했다. 공통 동작은 [학습 계약](learning-contract.md)을 따른다.

## 수료 조건

1. 이론16개를 완료하고, 신규 이론은 각 확인 질문3개 중2개 이상을 통과한다. 기존 이론3개는 현재 단계 완료 방식을 유지한다.
2. 연습28개에서 해당 유닛의 완료 증거를 제출한다. 재시도 횟수에는 제한을 두지 않는다.
3. C10 최종 포트폴리오의 세 사례는 서로 다른 관측 구간을 사용한다. 분석 당시 기록·새 데이터·평가·회고를 모두 남긴다.
4. 미래 정보 사용·원본 분석 덮어쓰기·객관 규칙 위반을 숨긴 제출은 재작업한다. 분석 유보·매매하지 않음은 근거가 있으면 유효한 결과다.
