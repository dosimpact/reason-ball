# Elliott Wave 학습·데이터·평가 계약

CUR-EW-001 v1. 신규35유닛의 콘텐츠 제작 기준이다. 기존9유닛의 구현 상태는 별도 매핑을 따른다.

## 공통 이론·연습 규격

이론은 기본5단계(개념/기준/차트/반례/요약)와 확인 질문3개로 구성한다. 각 단계는 독립 설명과 표시할 지점을 갖고 Next/Prev로 이동한다. 신규 이론 완료는 마지막 단계와 질문2개 이상 정답이다. 질문은 규칙과 가이드라인, 관찰과 추측을 구별하게 만든다.

연습은 선택/표기/근거 제출을 먼저 받는다. 수치와 객관 규칙을 검사한 뒤 피드백·수정·예시를 제공한다. 해석이 여러 개면 예시를 유일 정답으로 부르지 않는다. 예시를 본 시도와 블라인드 시도는 구분한다. 복습은 자유롭고 완료 이력은 보존한다.

## 데이터 프로필

숫자는 초기 공개/전체 봉이다. 더미는 상승·하락·반례를 재현하는 직접 제작 자료이며 실제 Binance 데이터인 것처럼 표시하지 않는다.

| T | 더미60봉 | 12→24→36→48→60으로5단계; 단계별 라벨 공개. 공개 구간 안에서만 설명 |
| D60 | 더미60/60 | 완성 구조·가격 계산 연습. 미래 예측 과제가 아니므로 전체 구조 공개 |

- H/HR/M은 제작자가 과거 UTC 구간을 지정하고 자료를 검토한 뒤 고정한다. 시장 API를 매번 호출해 임의의 정답 패턴을 기대하지 않는다. 실제 시작/끝 시각·내용 hash는 유닛 fixture 명세에 기록한다.
- M의 일봉 경계는 UTC다. 상위봉이 닫힌 시간까지만 하위 봉도 보여주며 진행 중 상위봉을 확정봉으로 전달하지 않는다. 기존 단일 시간봉 어댑터에 추가 구현이 필요하다.
- L의 사용자는 지원 심볼/간격을 고른다. 가격 데이터는 실제 관측이고 매매는 모의 평가다. 현재4000봉 사후 조회 한도를 초과하면 일부 데이터로 성공 처리하지 않는다.
- 동일 학습 과제의 데이터 공급 계층은 분리한다. 특정 유닛을 더미 전용으로 정한 이유는 규칙·반례를 재현하기 위해서다. 모든 실제 시장 구간에 교과서 패턴이 있는 것으로 가정하지 않는다.
- 가격·규칙 연습의 시간은 분석용 상대 시각으로 충분하다. 실전 분석은 source/symbol/interval/UTC/asOf를 함께 기록한다.

## 사례 제작 단위

신규 연습 유닛마다 기본사례1, 반례1, 평가용 미공개 변형1을 만든다. 복합 패턴 비교 과제는 유닛에 명시한 사례 수만큼 추가한다. 각 사례의 시나리오 ID는 `<unit-id>-<case-id>-v1`이며 서로의 내부 파일을 가져오지 않는다.

필수 명세: 학습 목표, source/profile, 초기 공개 수, 전체 범위, 각 단계의 허용 정보, 구조/차수/규칙 정책, 예시 해석과 허용 대안, 무효화·경계 사례, 피드백, 완료 증거. 실전 데이터의 예시 해석에는 검토자 근거를 남기고 객관 정답과 구분한다.

## 측정 규약

파동 시작 S, 끝 E, 투사 기준 P로 고정한다. 되돌림 후보는 `E - r × (E - S)`, 투사 후보는 `P + r × (E - S)`다. 부호를 유지하면 상승·하락에 같은 식을 사용할 수 있다. 비교는 반올림 전 값으로 하고 표시 정밀도와 제출 허용 오차는 fixture에 명시한다. 더미 가격 문제는0.01, 비율은0.000001 이내를 기본으로 한다.

Fibonacci 수준·균등·교대·채널·시간 비례는 해석을 돕는 가이드라인이다. 비율 근접만으로 카운팅의 유효성을 판정하지 않는다. 시간 도구는 봉 수 비교로 한정하고 특정 날짜의 반전을 예언하는 과제를 만들지 않는다.

## 규칙과 해석의 분리

1. **객관 검사:** 시간순 지점, 공개 범위, 패턴별 내부 분할과 가격 경계, 수치 계산. 실패 규칙을 이름·근거와 함께 반환한다.
2. **규약 선택:** 표준 Impulse/절단/Diagonal/조정 유형마다 `rulePolicy`를 구분한다. 기존 입문 규칙을 바꾸어 옛 저장 평가를 재해석하지 않는다.
3. **해석 평가:** 주/대안 카운팅, 차수 일관성, 근거, 무효화, 유보 조건. 실전에서 복수 카운팅을 허용하며 자동 언어 평가를 구현됐다고 가정하지 않는다.
4. **관측 결과:** 이후 무효화·후보 구간 도달·형태 변화. 맞춘 결과와 좋은 분석 절차를 별개로 기록한다.

EWI 분류를 기본 용어 출처로 삼되 입문 가격 동률 규약과 Leading Diagonal 내부 분할 차이는 [출처 정책](sources.md)에 따른다. 합의되지 않은 해석을 임의의 자동 정답으로 승격시키지 않는다.

## 분석형 연습 루브릭

객관 오류를 수정한 뒤 다음5항목을 각각0/1/2점으로 확인한다. 0=누락·모순, 1=기록했으나 근거 부족, 2=관측 증거와 연결. 합계8점 이상, 어느 항목도0이 없으면 통과한다. 이는 학습 운영 규약이며 예측 신뢰도 점수가 아니다.

- 현재 패턴·차수와 공개 구간의 연결.
- 적용 규칙과 가이드라인의 구분.
- 기준점·측정값·무효화 조건의 재현 가능성.
- 대안 또는 판단 유보의 근거·재검토 조건.
- 미래 정보 차단 및 관측 후 변경 이력·회고.

더미는 사전 작성된 기준으로 채점한다. 실전의 해석 항목은 학습자 자기 점검과 예시 비교를 기본으로 표시하며 전문가 인증 점수로 부르지 않는다. 객관 검사 통과와 주관 자기 점검 결과는 별도 저장한다.

## TradePlan·TradeEvaluation 연결

기존 TradePlan은3점 상승 모의 매매 모델이다. 심화 과정에서는 파동 분석 자체의 계획이 먼저 필요하다. 패턴/방향/차수, 주·대안 카운팅, 기준점·Fibonacci/채널 근거, 무효화, 다음 관측 조건, asOf·스냅샷을 보존한다. 매매 선택 시만 entry/stop/target과 청산 전략을 덧붙인다. 관망에는 가짜 주문 가격을 강요하지 않는다.

평가는 원본 분석을 참조하고 새 관측 범위, 규칙 위반/유지, 후보 도달, 대안 전환, 회고를 기록한다. 모의 손익은 주문 가정이 있는 경우만 계산한다. 원본은 불변이며 수정은 새 revision이다. 신규 분석 스키마와 기존 v1의 호환 방식은 시스템 stock의 후속 구현 과제로 관리한다.
