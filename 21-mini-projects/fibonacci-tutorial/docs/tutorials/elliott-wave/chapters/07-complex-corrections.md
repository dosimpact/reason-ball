상태: 커리큘럼 확정 v1 / 5유닛 구현. 선행: C06.

## 학습 목표

ABCDE와 WXY 계열을 구분하고 복잡한 횡보를 임의의 파동 추가로 설명하지 않는다.

## 설명·채점 원칙

복합 패턴을 모르는 구간의 만능 이름으로 사용하지 않는다. 각 하위 구성요소를 표시할 수 없으면 추가 데이터 필요로 분류한다. Triangle 뒤의 움직임 방향을 결과만 보고 과거 가설에 소급 반영하지 않는다.

## 이론 단계와 연습 흐름

이론은 각 유닛의 개념 소개 → 표기·기준 → 단계별 차트 사례 → 반례·적용 한계 → 요약·확인 순으로 작성한다. Next/Prev는 설명·차트·라벨을 같은 단계로 이동시킨다. 연습은 과제 확인 → 공개 구간 선택·근거 작성 → 규칙 확인 → 필요한 경우 Replay → 비교·회고 순서다. 자세한 캔들 fixture와 화면별 문장은 실행 콘텐츠 정의에서 관리하며 본 문서의 범위·산출물·완료 조건은 유지한다.
