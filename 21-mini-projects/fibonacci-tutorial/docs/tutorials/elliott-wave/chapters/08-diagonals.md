# C08 — Diagonal과 경계 사례

상태: 커리큘럼 확정 v1 / 5유닛 구현. 선행: C05·C06·C07.

## 학습 목표

Ending/Leading Diagonal을 상위 위치·겹침·내부 분할로 구분하고 일반 Impulse 규칙을 무조건 재사용하지 않는다.

## 설명·채점 원칙

Diagonal 유형마다 사용할 규약을 문제에 표시한다. Leading 내부 분할처럼 문헌 차이가 있는 항목은 단일 보편 정답으로 자동 채점하지 않는다. 소스가 주장하는 후속 반전의 확실성은 학습 성과나 예측 보장으로 채택하지 않는다.

## 이론 단계와 연습 흐름

이론은 각 유닛의 개념 소개 → 표기·기준 → 단계별 차트 사례 → 반례·적용 한계 → 요약·확인 순으로 작성한다. Next/Prev는 설명·차트·라벨을 같은 단계로 이동시킨다. 연습은 과제 확인 → 공개 구간 선택·근거 작성 → 규칙 확인 → 필요한 경우 Replay → 비교·회고 순서다. 자세한 캔들 fixture와 화면별 문장은 실행 콘텐츠 정의에서 관리하며 본 문서의 범위·산출물·완료 조건은 유지한다.
