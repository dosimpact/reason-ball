# C10 — 파동 분석 계획과 종합 평가

상태: 커리큘럼 확정 v1 / 5유닛 구현. 선행: C01–C09.

## 학습 목표

엘리엇 파동 분석을 시간 고정된 판단 기록으로 남기고 후속 데이터로 분석의 타당성을 검토한다.

## 설명·채점 원칙

매매 결과가 수익이라는 이유로 잘못된 카운팅을 통과시키지 않는다. 이 과정의 목적은 엘리엇 분석의 일관성·검증 가능성이다. 일반 투자·포트폴리오·레버리지 강의는 포함하지 않는다. 실전에서 무효화된 가설도 적시에 폐기하고 이유를 보존했다면 올바른 학습 결과로 인정한다.

## 이론 단계와 연습 흐름

이론은 각 유닛의 개념 소개 → 표기·기준 → 단계별 차트 사례 → 반례·적용 한계 → 요약·확인 순으로 작성한다. Next/Prev는 설명·차트·라벨을 같은 단계로 이동시킨다. 연습은 과제 확인 → 공개 구간 선택·근거 작성 → 규칙 확인 → 필요한 경우 Replay → 비교·회고 순서다. 자세한 캔들 fixture와 화면별 문장은 실행 콘텐츠 정의에서 관리하며 본 문서의 범위·산출물·완료 조건은 유지한다.
