# C01–C03 — 기존 입문 유닛 매핑

상태: 구현9유닛. 상세한 현재 데이터/경계는 [기존 시나리오](../../07-unit-scenarios.md)를 따른다. 새 커리큘럼을 위해 기존 ID·URL·저장된 계획을 바꾸지 않는다.

C02는 기존 유닛 순서를 보존한다. Wave 3 계획을 먼저 맛본 다음 Fibonacci 근거를 학습하며 재방문할 수 있다. C03의 실제 시장 사례는 파동 정답 맞히기가 아니라 시점을 고정한 분석과 후속 관측의 차이를 익히는 실습이다.

현재 앱의 trade-review `complete`는 Replay 종료를 나타낸다. 커리큘럼의 챕터 수료는 회고 제출까지 요구하므로 향후 과정 수료 판정에서 별도 확인해야 한다. 시장 재평가에서 새 봉이 없으면 현재 관측 결과와 대기를 구분한다.

## 기존 Lesson과 연결

- Lesson1·2·3 → C01.
- Lesson4·5 → C02.
- Lesson6 → C03, 이후 C10 심화 평가.

현재 입문의 고점 갱신·3점 반등 조건은 표준 상승 시나리오의 제한이다. 절단/하락/Diagonal 사례에 그대로 적용하지 않는다.
