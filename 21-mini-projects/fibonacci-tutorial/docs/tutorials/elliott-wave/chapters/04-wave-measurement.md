# C04 — 파동의 가격·시간 측정

상태: 커리큘럼 확정 v1 / 5유닛 구현. 선행: C01–C03.

## 학습 목표

파동 기준점을 고정한 뒤 되돌림·투사·채널을 계산하고, 후보 구간과 무효화 조건을 구분한다.

## 설명·채점 원칙

핵심은 비율을 맞추기 위한 카운팅 변경을 방지하는 것이다. 되돌림은 같은 파동의 시작·끝, 투사는 측정 구간과 별도 투사점을 먼저 기록한다. 선형 가격 기준을 기본으로 쓰며 로그 화면의 시각적 길이를 계산값으로 대신하지 않는다. 후보가 여러 개 겹쳐도 성공 확률을 자동 부여하지 않는다.

## 이론 단계와 연습 흐름

이론은 각 유닛의 개념 소개 → 표기·기준 → 단계별 차트 사례 → 반례·적용 한계 → 요약·확인 순으로 작성한다. Next/Prev는 설명·차트·라벨을 같은 단계로 이동시킨다. 연습은 과제 확인 → 공개 구간 선택·근거 작성 → 규칙 확인 → 필요한 경우 Replay → 비교·회고 순서다. 자세한 캔들 fixture와 화면별 문장은 실행 콘텐츠 정의에서 관리하며 본 문서의 범위·산출물·완료 조건은 유지한다.
