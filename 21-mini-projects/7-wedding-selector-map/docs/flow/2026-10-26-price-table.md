# 2026-10-26 지도 없는 가격표 페이지

## 맥락

사용자가 기존 탐색·저장·비교 흐름과 별도로, 지도 없이 가격을 넓은 테이블에서 연속 비교하는 새 페이지를 요청했다. 새 `/prices` 페이지와 가격표 내비게이션을 추가하고 기존 지도 탐색은 유지한다.

## 결정과 구현 범위

- TABLE-001 독립 페이지: `/prices`는 지도 없는 가격 비교 화면이다. 기존 `/` 지도 탐색, 관심 저장과 최대 3곳 비교 동작을 보존한다.
- TABLE-002 웨딩홀 계산: 공통 하객 수에 적용되는 같은 홀·조건의 성인 식대·대관/대관장식·보증/계산 인원·참고액·조건을 연결한다. 각 항목의 독립 최저값을 조합하지 않고 미확인 비용은0으로 표시하지 않는다.
- TABLE-003 준비대행 단위: 상품 분류×산정 단위를 명시해 같은 종류의 기본가를 비교한다. 패키지와 개별상품, 1인과 상품 단위의 금액을 임의 합산하거나 하나의 가성비 순위로 표현하지 않는다.
- TABLE-004 탐색: 검색·지역·예산·가격 확인·저장 필터, 열 정렬, 페이지 이동, 결과 범위, 표 머리글·업체 열 고정과 모바일 내부 스크롤을 제공한다.
- TABLE-005 후보·내보내기: 지도와 같은 관심/비교 저장을 공유하고 상세와 비교함을 재사용한다. 현재 필터 결과 전체의 CSV는 가격·단위·조건을 보존하며 원본/출처 URL은 제외한다.
- TABLE-006 검증: 계산·누락·정렬·단위·CSV의 회귀와 새 페이지 직접 URL/내비게이션·필터·저장·비교·상세·CSV·모바일·지도 요청 부재를 실제 브라우저에서 구분해 검증한다.

## 진행과 검증 상태

기존 stock·내비게이션·가격 함수·소비자 JSON 응답을 읽고 업무 및 시스템 설계에 새 가격표 범위를 반영했다. 기존 탐색·저장·비교는 현재 버튼 상태/모달을 포함한 흐름이며, 이번 `/prices`를 새 독립 route로 구성한다.

최초 기록 시점에는 페이지·행 모델·테이블 위젯 구현이 진행 중이다. 소스 및 문서의 계획은 런타임 완료 근거가 아니다. 필터 URL 정책과 실제 구현 계약을 확인한 뒤 이 기록에 후속 검증·스크린샷을 추가한다. 지도 위젯을 조합하지 않는 구조와 브라우저의 지도 청크/타일 요청 부재는 별도 검증으로 구분한다.

다른 프로젝트·기존 정적 `client`·원본 데이터와 이전 flow는 이번 변경 범위가 아니다.

## URL과 초기 상태 계약

가격표는 전국·웨딩홀·하객200명·공개비용 낮은순·20행·1페이지로 시작한다. 다음 상태를 URL로 복원한다.

```text
/prices?kind=venue|planning&q=검색어&region=전체|서울|지역
  &guests=200&metric=package:package&budget=금액
  &priced=1&saved=1&sort=price&dir=asc&size=20&page=1
  &year=all|unknown|2026
```

`metric`은 준비대행 상품 분류와 산정 단위를 함께 지정한다. 지원되지 않는 값은 허용된 값/기본값으로 정규화한다. 필터 결과 전체 CSV와 현재 페이지 표본은 구분한다. URL 계약은 구현·브라우저 검증 후 실제 복원 결과로 확인한다.

선택 offer의 `mealUnit`, `guarantee`, `hall`, `totalMax`, `rentalMax`를 비용 분해에 추가해 표에 같은 조건의 단가·대관·인원을 표시하는 방향을 채택했다. 이는 업체별 독립 최저값을 다시 조합하지 않기 위한 것이다.

## 구현 완료 및 1차 검증

- `/prices` route, FSD 가격표 행 모델·위젯·페이지, 공유 vendor-details 기능과 탐색 진입 링크를 구현했다. 준비대행 최초 진입은 가격 확인 업체가 가장 많은 상품×단위를 선택하며 명시한 URL metric은 보존한다.
- 같은 offer의 식대·대관·보증 인원을 사용하고, 미확인은0으로 바꾸지 않는다. 하객 수는1–2000의 정수로 입력한다.
- `pnpm -C app test`:39개 통과. lint/format/typecheck/production build 통과.
- 실제 브라우저:200→275명, 서울 지역, URL 새로고침 복원, 내림차순, 다음 페이지,50행, 관심 저장/필터,3곳 비교 및 상세, 준비대행 메이크업1인 단위, 빈 결과/초기화 동작 확인. JS pageerror0건. 최초 가격표 resource에 지도 타일/Leaflet 요청 없음.
- 서울 CSV는 표50행 상태에서도102개 업체·18열 전체를 저장하며 원본 URL을 포함하지 않는다.
- 390×667에서 비교함을 열지 않아도 표가 지나치게 작아지는 문제를 발견했다. 후속 UX 리뷰 수정과 최종 검증은 [전체 지도 및 UX 리뷰](2026-10-26-full-map-ux-review.md)에 기록한다. 최초 스크린샷은 수정 전 상태이며 최신 증거와 구분한다.
