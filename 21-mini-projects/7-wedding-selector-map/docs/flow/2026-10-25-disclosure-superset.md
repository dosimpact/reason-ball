# 2026-10-25 공시 슈퍼셋 모델 초안

## 맥락과 결정 MODEL-001

사용자는 모든 업체 자료를 담는 상위 데이터 모델을 요청했다. 기존 가격 비교 카탈로그의 공통 필드로 축약하지 않고 원본 보존, 근거, 의미 해석, 서비스용 집계를 분리한다. 초안 스키마와 실제 원본 일부를 매핑한 예제를 추가한다. 전체 공시 이관이나 기존 카탈로그 교체는 이번 작업의 완료 조건에 포함하지 않는다.

## 조사 근거

로컬 파일 985개의 목록과 JSON·TXT·MD를 확인했다. XLSX 276개의 ZIP/XML에서 모든 시트 305개와 값이 있는 셀 19,074개를 읽었다. 추가 PDF 35개는 텍스트를 추출했고 텍스트가 거의 없는 6개는 렌더링 후 OCR로 보완했다. HWP 14개와 실제 HWP인 XLS 1개의 텍스트 레코드, HWPX 2개와 DOCX 1개의 XML을 읽었다. 기존 이미지 OCR 76건과 추가 이미지/OCR 대상 21개도 조사했다. 이는 모든 페이지와 이미지의 사람 수준 시각 검수 또는 모든 가격의 정규화 완료를 의미하지 않는다. EMF 2개의 시각 해석은 미실시다.

- 이안스퀘어 원본 C5/D5의 10,000원/5,000원은 할인액이다. E5의 모두 적용 후 금액은 46,000원이다. 현재 카탈로그에는 할인액까지 식대로 들어 있다.
- 루이비스 강서 원본 C8의 전문사회 300,000원, E8의 남성 혼주미용 77,000원은 각각 식대·대관료가 아니다. 현 카탈로그에 오분류되어 있다.
- 그래비티 판교는 150명 기준 식사 총액과 추가 1인 단가를 같이 표기한다.
- 목장원은 같은 문서에 2026년과 2027~2028년 상반기 가격을 표기한다.
- 원본 XLSX 해시는 기존 추출 검증 기록 276건과 모두 일치하지만 업체 MD 275건은 당시 해시와 다르다. 현재 MD는 의미 중심 문서로 재구성된 상태다. 예전 좌표형 MD 검증을 현 MD의 검증으로 인용하지 않는다.

## 산출물과 반영

[시스템 설계 MODEL-001–008](../stock/system-design.md#model-001-슈퍼셋-모델의-범위)에 모델과 경계를 통합한다. [업무 설계 MODEL-BIZ-001](../stock/business-design.md#model-biz-001-공시-슈퍼셋)에 데이터 보존 원칙을 반영한다. 실행 가능한 스키마·예제·검증기는 `packages/wedding-data-model/`에 둔다.

## 검증 상태

구조 검증, ID 참조, 금액 범위, 실제 원본 해시 대조 및 잘못된 데이터 거부 검증 결과는 작업 완료 시 아래에 추가한다. 전수 변환·가격 계산 엔진·UI 연동은 후속 작업이다.


## 완료 검증

- `uv run --no-project --with jsonschema python packages/wedding-data-model/validate.py --check-sources`: 실제 자료 부분 매핑 예제 5개 모두 PASS. JSON Schema 자체의 유효성, 구조·참조·기본 금액, 연결된 원본 5개 SHA-256을 대조했다.
- 오류 입력 9개를 거부했다: 중복 ID, 존재하지 않는 참조, 확정 가격의 금액 누락, 잘못된 가격 역할, 0인 산정 분모, 뒤집힌 범위, 무료 상태의 양수 금액, 원본 해시 불일치, 허용하지 않은 핵심 속성.
- 한쪽 경계만 있는 범위, 기준 금액 참조를 가진 비율, 다른 금액을 참조하는 계산식의 유효 입력을 각각 수용했다. 계산식은 구조만 검증하며 실행하지 않았다.
- 새 설계·안내·이력의 로컬 문서 링크 검사와 기존 stock 문서의 `git diff --check`를 통과했다.
- 원본 데이터, 기존 카탈로그, 기존 업체 MD/TXT 및 UI 코드는 수정하지 않았다. 수치 전수 검수·전수 이관·UI/브라우저 검증은 이번 초안 작업에서 수행하지 않았다.
