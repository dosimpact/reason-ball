# 2026-10-25 Wedding Atlas 정적 애플리케이션

## 요청과 결정

사용자가 데이터 전체를 보여주는 `client` 정적 HTML 웹을 요청했다. 지도 연계, 가격 비교 백분율과 분포 그래프, 전체 테이블·필터·검색·정렬을 포함한다. 이어 MD를 Excel 좌표 형식에서 벗어나 모든 정보를 재가공한 문서로 만들도록 수정 요청했다. 두 요청을 같은 의미 중심 데이터 모델로 구현한다.

## 적용 설계

- [WEB-001–006](../stock/business-design.md)
- [SYS-001–004](../stock/system-design.md)

## 진행

기존 원본·문서·디렉터리를 읽고 사용자 파일 상태를 확인했다. 가격 조건과 근거를 보관하고, 패키지 총액·소인·추가 인원 단가를 기본 성인 식대와 구분하는 방식을 채택했다. 구현과 검증 결과를 완료 시 추가한다.


## 정적 client 구현 완료

- `client`에 HTML·CSS·JavaScript 앱을 구현했다. 실행 중인 미리보기는 http://127.0.0.1:3077/client/ 다.
- 기본 공시 275건과 추가 원본 58개 및 전체 게시물 기본정보를 연결해 338개 공시 프로필을 제공한다. 기존 MD 275개를 재구성하고 추가 읽기 프로필 63개를 생성했다.
- 실제 가격 분포와 정규분포 참고 곡선, 평균 대비 백분율과 경험적 상대 순위, 전체 표·필터·검색·정렬·페이지 이동, 관심 목록·최대 4개 비교·CSV 저장을 구현했다.
- Google 주소 지도와 네이버/Google 열기 링크, 원본 형식별 다운로드를 제공한다. Google 지도는 브라우저 MCP에서 실제 표시와 위치를 확인했다. E2E에서는 외부 지도 응답을 고정해 기능 테스트와 제공자 응답을 구분했다.
- 기본 식대 236개, 공간 대관료 222개, 대관·장식 합계 6개의 원본을 비교한다. 소인·음주류·추가 인원·패키지 총액·할인액·미검증 OCR 가격과 이전 공시를 기본 통계와 구분했다.
- 모바일 필터 닫기 버튼이 패널에 가려지는 문제를 실제 테스트에서 찾아 고쳤다. 기존 3078 포트의 별도 Next.js 서버는 재사용·종료하지 않았고, E2E를 3097 소유 서버로 분리했다.
- 정적 서버는 client/database/docs 및 루트 이동만 제공하고 숨김 파일과 별도 app 경로를 제공하지 않는다.
