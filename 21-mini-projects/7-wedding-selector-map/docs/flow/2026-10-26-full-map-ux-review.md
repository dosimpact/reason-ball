# 2026-10-26 전체 높이 지도와 Astra UX 리뷰

## 맥락 및 결정

가격표 구현 뒤 사용자가 헤더 때문에 지도 높이가 줄어드는 문제를 지적하고, 첨부 예시처럼 전체 높이 지도와 Astra의 전반 UX 리뷰 및 수정 반영을 요청했다. 데이터가 상위 database를 실행 중 참조하는지도 질문했다.

- MAP-FULL-001: 지도는 내비게이션 레일 옆에서100dvh를 사용한다. 전체 너비 헤더/소개/푸터 대신 왼쪽 검색·목록 dock이 지도 위에 뜬다. 상세는 동일한 위치의 패널로 바뀐다.
- MAP-FULL-002: 모바일은 목록/지도 전환을 유지한다. 지도 모드에서 검색 패널은 상단에 뜨고 지도 조작 버튼은 오른쪽 아래에 배치한다. 목록 모드 뒤의 지도는 키보드 초점을 받지 않는다.
- MAP-FULL-003: 결과 맞춤과 선택 좌표 이동은 host가 전달하는 CSS 안전 여백을 반영한다. 지도 범례는 목록 패널 뒤에 가리지 않으며 비교 트레이가 있으면 위로 이동한다.
- UX-001: 검색 dock을 지도보다 먼저 DOM에 배치하고 skip link를 focusable dock에 연결한다. 지도 목록의 가격분포는 접혀 시작한다.
- UX-002: 모바일 및 높이800px 이하 가격표는 문서 세로 스크롤을 허용하고 표 최소360px을 확보한다. 모바일 고정 업체열을 줄이고 이름2줄·가격 범위 줄바꿈을 사용한다. 주요 가격 조건·미확인 설명은11–12px 및 어두운 색으로 조정한다.

## 데이터 의존성 확인

`app/src/entities/vendor/api/catalogue.server.ts`는 앱 내부 `vendors.json`을 import한다. 목록, 가격표 및 `/api/vendors/[id]`는 이 가공 데이터로 동작한다. 데이터 재생성·검증·지오코딩 스크립트와 일부 원본 대조 테스트는 상위 `database`를 입력으로 사용한다.

`app/app/api/documents/route.ts`는 여전히 `../database`를 런타임 파일 경로로 읽는다. 소비자 UI에는 이 API 링크가 없다. 이번 요청은 데이터 흐름 확인이며 API 제거/standalone 전환까지 완료했다고 주장하지 않는다. `output: standalone` 설정 및 격리 배포 검증은 별도 후속 작업이다.

### 최종 재검증 결과

- 최종 production build, TypeScript, ESLint, Prettier 통과. 가격 계산 및 URL·CSV 포함39개 테스트 통과.
- 1440×800: 지도 x76/y0/height800.390×667: 지도 y0/height667.320×568: 지도 y0/height568. 헤더가 지도 높이를 차감하지 않는다.
- 가격표 내부 스크롤 높이는390×667에서241px,320×568에서191px,1440×800에서305px. 모바일 가격열 오른쪽 끝은 각각376/306px로 뷰포트 안에 들어온다. 문서 가로 넘침 없음.
- 390/320px에서 실제 지도 확대·축소 클릭 성공. 도구는 각각 y450/351로 검색 패널 아래에 위치한다.
- skip link Enter 후 focus=`explore-results`, 다음 Tab은 dock의 브랜드 링크. DOM에서 dock이 지도보다 먼저다. 가격분포 기본 접힘 확인.
- 지도 상세는1440×900에서 x92/y16/w410/h868,320×568에서 x10/y10/w300/h548로 화면 안에 유지한다. 닫기·Escape, 지도↔가격표 링크와 공유 저장 상태 확인. 소비자 원본 API 링크0개.
- 최종 흐름 JS pageerror0건. 배경 지도 타일은 외부 서비스이며 업체 가격 데이터는 내부 JSON이다.
- 최신 시각 증거: `output/playwright/price-table/final-map-desktop.png`, `final-map- 390.png`, `final-map-320.png`, `final-map-detail.png`, `final-prices- 1440.png`, `final-prices- 390.png`, `final-prices-320-header.png`. 초기/Astra 스크린샷은 수정 전 근거로 보존한다.
- 자동화 첫 실행은 목록 모드에서 의도적으로 숨긴 지도에 visible을 기다려 멈췄다. 지도 초기화는 attached로, 지도 상호작용은 지도모드 전환 후 검증하도록 수정해 재실행했다. 애플리케이션 실패와 구분한다.

320px에서는 장식 제목과 통계 보조문구를 압축해 첫 가격 행이 상단에서 더 일찍 보이도록 추가 조정했다. 제목은 보조기술용으로 유지한다.
