# 2026-10-25 지도·가격 비교 Next.js 앱

## 맥락과 결정

사용자 요청: 참가격 웨딩홀 자료와 결혼준비대행 자료를 함께 활용하는 종합 비교 사이트. `app`에 Next.js, TypeScript, Tailwind, shadcn/ui, FSD와 SLAP을 적용하고 고급 웨딩 디자인 및 실브라우저 검증까지 수행한다. 막히는 외부 의존성은 분리하고 기능 구현을 우선 진행한다.

기존 `client` 정적 웹 및 원본·모델은 보존한다. 새 앱은 별도 pnpm 루트로 구성한다. 기존 MODEL-001–008의 근거·조건·가격 단위·미공개 구분을 조회용 projection에 적용하며, 전체 슈퍼셋 이관을 완료한 것으로 표현하지 않는다.

## 구현 대상

- APP-001: 두 자료집 전체 업체 검색, 지역·종류·가격·인원 조건, 정렬, 모바일 대응.
- APP-002: 실제 지도와 검증된 위치 마커, 지오코딩 누락 구분.
- APP-003: 업체 상세·공시 원문·출처·가격 조건.
- APP-004: 같은 하객 수 기준 공개비용 비교, 최대 3곳 비교 및 저장.
- APP-005: 웨딩홀 식대·대관과 준비대행 개별상품·패키지 구분.
- APP-006: FSD·SLAP, 핵심 가격 로직 검증 및 실제 브라우저 흐름 검증.

## 진행

원본 폴더·기존 문서·모델·작업트리 확인. 다른 프로젝트의 사용자 변경은 건드리지 않는다. 데이터 projection, 지도/좌표, 상세/비교 위젯을 병렬 구현하며 부모 작업에서 앱 구성·검색·탐색·저장을 통합한다. 검증 결과와 stock 반영은 후속 기록한다.

## 입력 확장과 가격 교정

작업 시작 시 기존 카탈로그는 웨딩홀 275건이었다. 실행 중 입력 카탈로그가 338건으로 갱신된 것을 확인했다. 본 작업에서는 원본 입력을 덮어쓰지 않고, 추가원본 manifest의 332개 첨부 연결과 무첨부 게시글 6건 및 실제 파일을 확인해 새 앱에 반영했다. 결혼준비대행 108건을 합쳐 최종 조회 레코드는 446건이다. 입력 스냅샷은 `app/src/entities/vendor/data/metadata.json`의 생성 시각과 입력 7개 SHA-256으로 고정한다.

MH컨벤션은 업체명·주소·전화 및 실제 첨부 바이트 동일성을 확인해 현재 게시글로 통합했고, 이전 공시와 근거는 source와 historical disclosure로 보존했다. 파일명만으로 업체를 합치지 않았다.

가격 독립 표본 점검에서 소인 식대, 회원/군 대상 한정 가격, 인원 범위를 벗어나는 대체 메뉴, 드레스 피팅/헬퍼 열, 패키지 안의 무료 항목 등이 대표 기본가로 들어갈 수 있는 패턴을 발견해 규칙과 회귀 테스트를 보강했다. 같은 홀·시즌 열 안에서 식대와 대관료를 연결하고 가격 항목별 실제 셀 근거를 수정했다. 소풍컨벤션의 무료 촬영 헤어/메이크업은 단독 판매가 불명확해 대표 최저가에서 제외하고 원문에는 보존한다. 루이르의 남성 1인 기본가와 신랑신부 합계는 구분한다.

최종 데이터 스냅샷은 웨딩홀 338건·준비대행 108건, 성인 식대 확인 238건, 준비대행 유료 기본가 확인 66건, 가격 항목 3,577개다. 전체 의미를 사람이 전수 검수했다는 뜻은 아니다. 미해석 HWP/PDF/이미지 등도 원본과 설명에 남긴다.

## 화면 및 구조

아이보리·플럼·세이지 색상과 세리프 제목을 사용한 `오롯` 브랜드를 구현했다. 목록·지도·상세를 연결하고 모바일에는 목록/지도 전환과 전체 상세 패널을 제공한다. 검색어 NFKC/공백 정규화·여러 단어 검색, 복합 필터, URL 복원, 저장, 최대 3곳 비교, 하객 변경, CSV, 공시 원본 및 모델 JSON 다운로드를 연결했다.

FSD 페이지는 영역 조합을 맡고 필터·저장·상세 요청·가격·지도는 독립 모듈에서 처리한다. slice 공개 API로 하위 레이어를 참조한다. 초기 목록 데이터는 원문·근거를 제외한 약 632KB 요약이며 상세 선택 시 API에서 전체 공시를 받는다. 저장소 쓰기 실패 시 세션 저장이 계속 동작한다.

CARTO 타일이 HTTP 200으로 `API KEY REQUIRED` 이미지를 반환하는 것을 실제 스크린샷에서 발견했다. OpenStreetMap 공식 타일을 기본으로, OSM France HOT를 대체로 연결하고 실제 이미지 내용을 확인했다. 주소 일치 좌표 151곳(웨딩홀 116·준비대행 35)은 가격 마커로, 나머지는 지역 대표 배지로 구분한다. 이 좌표는 주소 검색 결과이며 현장/영업 검증이 아니다. 지오코딩은 [Nominatim 사용 정책](https://operations.osmfoundation.org/policies/nominatim/)에 따라 직렬·지연·캐시를 사용하는 선택적 빌드 작업이며 브라우저 런타임에서 호출하지 않는다.

## 준비대행 비교·접근성 보강

준비대행의 최저 기본상품은 서로 다른 서비스일 수 있다. 서버에서 원본 가격 항목을 분류×산정 단위별 작은 profile로 파생하고 카드에 `메이크업 · 1인` 등 실제 기준을 표시한다. 비교표와 CSV는 스튜디오·드레스·메이크업·패키지를 각 행/열로 분리하며 임의 합계를 만들지 않는다. 무료/포함 상태와 유료 기본가도 분리한다. 이 profile을 포함한 초기 요약 JSON은 653,833바이트이며, 전체 공시 본문은 상세 API로 지연 로드한다.

상세 열기 시 닫기 버튼으로 포커스를 옮기고 닫을 때 원래 카드로 복귀한다. 680px 이하에서는 Tab/Shift+Tab을 상세 안에서 순환시킨다. 비교/가이드 Dialog는 shadcn/Radix 포커스 동작을 사용한다.

기존 정적 client의 카탈로그 설명이 시스템 stock에 추가되어 Next.js 설명과 같은 SYS 번호·앱 포트로 혼동될 수 있는 것을 확인했다. 내용을 보존한 채 LEGACY-CATALOG-001로 구분하고, 정적 client의 3077/3097 및 통계와 Next.js 3078/projection 통계를 각각 명시했다.
