# 2026-10-26 가격표 필터 분리

사용자가 prices-toolbar의 높이도 표를 작게 만든다고 요청했다. 종류/검색/필터를 한 줄로 압축하고 세부 조건은 즉시 반영되는 모달로 이동했다. 활성 조건은 줄바꿈 없는 요약으로 표시한다. 모바일 종류는 select로 바꾸고 확보한 높이를 표에 배정했다. WEB-009에 현재 UX를 반영했다.

검증: lint/standalone build 통과. 브라우저1440/390/320px에서 지역·하객·예산·초기화·종류·상품단위 전환과 Escape 닫기 확인. 기본 툴바40px, 활성조건 포함62.5px. 표 스크롤 높이513/306.5/263px, 문서 가로 넘침 및 pageerror 없음.
