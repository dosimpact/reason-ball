# 2026-10-25 지도 마커의 업체명 우선 표시

## 맥락

사용자가 지도에서 가격보다 가게·웨딩홀 이름을 먼저 볼 수 있도록, 마커에 이름을 표시하고 가격을 subtext로 내려달라고 요청했다. 변경일은 2026-10-25 KST다.

## 결정과 변경 범위

- **MAP-LABEL-001**: 업체·웨딩홀 이름을 첫 줄의 주 정보로, 가격을 작은 둘째 줄의 보조 정보로 표시한다.
- 긴 이름은 한 줄 말줄임으로 정리하되 전체 이름과 가격을 툴팁·접근성 이름에 보존한다. 마우스와 키보드로 전체 내용을 확인할 수 있어야 한다.
- 마커의 두 줄 크기에 맞춰 겹침을 판단한다. 밀집 구간에서 축약된 점도 이름·가격 확인과 상세 선택을 지원한다.
- 선택한 업체의 두 줄 마커를 우선 표시하고 강조한다.
- 가격 계산·좌표·지역 대표점의 의미는 기존 규칙을 유지한다.

## 진행과 검증 상태

기존 stock과 마커 구현을 확인하고 이름/가격의 정보 우선순위를 현재 설계에 반영했다. 최초 기록 시점에는 화면 수정과 브라우저 검증이 진행 중이다. 정적 검사, 긴 이름, 밀집·선택 마커, 모바일 및 키보드 검증 결과는 구현 완료 후 후속 항목에 추가한다. 기존 flow는 당시 구현 기록으로 보존한다.

## 2026-10-26 구현 및 최종 검증

마커를 이름 위/가격 아래의 두 줄로 변경했다. 이름은12px·650 굵기, 가격은10px·400 굵기와 보조 색상으로 표시한다. 긴 이름은178×54px 카드 안에서 말줄임 처리하고, 전체 이름·가격은 툴팁과 접근성 이름에 보존한다. 겹침 판정도 새 카드 크기에 맞췄으며 선택 마커 우선순위를 유지한다. 밀집 구간의 작은 점도 hover와 키보드 focus로 이름과 가격을 보여준다.

전체 ESLint·TypeScript·운영 빌드 PASS. 운영 Chrome의1440×1000 및390×844에서14개 항목을 검증했다. 두 줄 순서·폰트 크기/굵기, 이름 마커 간 겹침, 축약점 hover/focus, 선택→상세, 긴 이름의 말줄임/전체 툴팁, 모바일 표시·상세 연결·가로 넘침 없음, 준비대행도 같은 표시 규칙을 확인했다. JavaScript/콘솔 오류0건이다. 가격 계산·좌표·원본 데이터는 변경하지 않았다.
