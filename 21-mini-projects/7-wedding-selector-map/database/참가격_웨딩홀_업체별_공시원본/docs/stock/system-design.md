# 참가격 업체 기본정보: 데이터 설계

## META-DATA-001 입력과 연결 키

기본정보·엑셀 추출 대상은 `database/참가격_웨딩홀_업체별_공시원본`의 기존 지역별 공시 275건이다. 보존한 원본은 `.xlsx` 273개와 확장자가 `.xls`인 2개이며, 후자의 실제 형식은 XLS 1개와 HWP 1개다. `수집목록.json`의 기존 공시 범주 275건에서 파일 경로, SHA-256, 게시물 URL, 첨부파일 ID, 목록 등록일을 대조한다. 목록의 나머지 8건은 이전 전체 수집 범위의 자료이며 현재 지역별 공시 대상에 포함하지 않는다. 현재 원본 수집 범위는 추가 비엑셀·ZIP을 포함하며 META-DATA-005를 따른다.

업체별 접근용 파일은 XLSX·TXT·MD 각 275개다. 구형 XLS와 실제 HWP에만 XLSX 사본을 추가했다. 원본 275개는 변경하지 않았다.

업체별 게시물 274개는 상세 페이지의 `fileRgtnSeq`와 원본 다운로드 URL의 ID를 대조한다. 상세 페이지에 연결된 `BoardReadView.do` 본문 표에서 `주소`, `연락처`, `자료 공개일`을 읽는다. 이전 MH컨벤션 공시는 [과거 대구 통합 본문](https://www.price.go.kr/tprice/portal/board/BoardReadView.do?boardSeq=37745&boardTypeCode=0090000121)의 해당 업체 행에 있는 첨부 ID `30728`로 대조한다.

## META-DATA-002 출력 스키마

통합 엑셀은 `업체별 기본정보` 시트 하나를 사용한다. 표 범위는 `A6:P281`, 데이터는 275행이며, `C7`에서 행·열 틀을 고정한다.

| 열 | 항목 | 저장 규칙 |
| --- | --- | --- |
| A–D | 지역, 업체명, 주소, 연락처 | 본문과 기존 지역 분류를 보존. 연락처는 문자열. |
| E | 자료 공개일 | 유효한 값은 날짜형과 `yyyy-mm-dd` 표시. 원문 형식 오류는 문자열로 보존. |
| F | 공시 구분 | 업체별 공시 또는 이전 공시. |
| G–I | 원본 상대 경로, 첨부파일 ID, 게시물 번호 | 지정 폴더를 기준으로 원본을 추적. ID는 문자열. |
| J–L | 게시물 URL, 본문 URL, 첨부 다운로드 URL | 실제 확인한 출처와 원본 다운로드 주소. |
| M | 수집 확인일 | 2026-10-25. |
| N | 목록 등록일(기존 수집목록) | 기존 수집목록의 참고값. 이번 작업의 재검증 대상은 아님. 이전 공시의 미확인 값은 빈칸. |
| O–P | 확인 상태, 비고 | 원문 날짜 형식 오류와 이전 공시 연결 근거를 표시. |

업체별 TXT와 통합 TXT는 UTF-8을 사용한다. TXT는 공개일 원문과 수집 시각을 보관한다. 누락 값과 실제 0을 같은 값으로 치환하지 않는다. 주소의 별도 정제나 좌표 변환은 수행하지 않는다.

## META-DATA-003 검증과 갱신

저장된 엑셀의 275행을 수집 데이터와 비교하고, 전화번호 문자열, 날짜형 274건과 원문 오류 문자열 1건, 출처 URL, 원본 상대 경로를 대조한다. 업체별 TXT 275개와 통합 TXT 275블록을 대조하고 원본 해시를 다시 확인한다. 엑셀의 처음·중간·끝 영역과 날짜 확인 필요 영역을 렌더링하여 확인한다.

갱신 시 첨부파일 ID로 원본 연결을 다시 확인하고, 본문 값과 수집일을 새로 기록한다. 공시 첨부가 바뀌면 기존 파일과 같은 버전으로 간주하지 않는다. 변경 이력은 새로운 날짜의 flow 문서에 추가한다.

관련 업무 규칙: [META-001–004](business-design.md). 검증 근거: [수집 및 검증 기록](../flow/2026-10-25-company-details.md).

## META-DATA-004 시트 내용의 Markdown·TXT 추출

지역별 XLSX 275개와 통합 XLSX 1개에서 전체 시트 305개를 추출한다. 숨긴 시트도 포함한다. TXT에는 시트별 원본 좌표·셀 값·병합 범위·별도 숫자 표시 형식·주석·링크·도형 텍스트를 보관한다. 현재 업체 MD는 기본정보와 원문을 위치·홀별 가격·추가 항목·이용 조건·취소 규정으로 재구성한다. 원본 좌표를 MD의 주 표 구조로 사용하지 않는다.

빈 셀을 0으로 채우거나 병합된 가격을 여러 셀에 반복하지 않는다. 개행과 표 구분자는 `<br>` 및 HTML 이스케이프로 처리한다. 날짜·숫자의 텍스트 표현과 가격의 단위·조건은 원문을 기준으로 한다. 수식이 있으면 수식과 저장된 계산값을 별도 항목으로 구분하는 방식이다. 현재 대상에는 수식 셀이 없다.

XLSX ZIP 내부의 원본 이미지 75개와 HWP에서 보존한 이미지 3개를 각 업체의 `<파일명>.assets/`에 바이트 그대로 추출한다. 시트의 이미지 관계를 따라 MD에서 연결한다. EMF 2개는 Markdown 뷰어의 직접 표시 지원이 달라 다운로드 링크로 보관한다. 이 중 PNG/JPEG 76개는 Vision의 보조 자동 판독 텍스트를 함께 제공한다. EMF 2개는 원본 링크를 유지한다. 자동 판독 결과를 검증된 가격으로 승격하지 않는다.

캠퍼트리 XLS 사본은 기존 셀 값과 병합 구조를 옮겼다. MH컨벤션 HWP 사본은 가격 안내·이용 약관 원본·계약서 원본 시트를 제공한다. 가격 안내의 확인된 9개 금액을 셀로 옮기고 가격표·약관·계약서 스캔 3개를 함께 보존했다. 적용연도가 원문에 없으므로 임의로 연도를 부여하지 않는다.

라비니움 `참가격정보` 시트의 `D9`, `E9`, `F9`, `G9`, `K13`은 원본 스타일 인덱스가 유효하지 않다. 셀 값은 추출하고 표시 형식 판독 불가 사유를 해당 MD에 적었다. 원본 파일을 수정하지 않는다.

TXT는 기존 기본정보를 보존하고 `EXCEL_CONTENT_EXPORT_V1` 구간에 시트 내용을 추가한다. 통합 TXT의 현재 대상 경로 표기 1곳도 현재 폴더명에 맞췄다. 새 목록 [엑셀_추출_목록.md](../../엑셀_추출_목록.md)가 XLSX·TXT·MD 탐색의 진입점이다.

좌표형 추출 단계의 검증 JSON은 당시 셀 값 대조의 이력이다. 현재 의미 중심 MD는 원본 해시·게시물 범위·본문/출처 연결·상대 링크·가격 해석 회귀 사례를 검증한다. TXT의 좌표형 원문 추출은 보존한다. 새 XLSX 사본의 네 시트는 렌더링하여 확인했다. 세부 근거는 [검증 JSON](../flow/2026-10-25-workbook-extraction-validation.json)과 [추출 이력](../flow/2026-10-25-workbook-markdown-export.md)에 있다.

## META-DATA-005 비엑셀 원본 보존과 첨부 연결

추가 파일 58개는 `<지역>/<업체명>__<첨부ID>.<실제형식 확장자>`로 보관한다. 사이트 다운로드 응답 바이트를 그대로 저장하며, ZIP 내부 PDF는 별도 사본으로도 보존한다. 경원재 ZIP 안의 기존 XLSX는 기존 파일과 동일하므로 덮어쓰지 않는다.

[추가원본_수집목록.json](../../추가원본_수집목록.json)의 `files`는 저장 경로, 업체·지역·게시글·첨부 ID, 게시글·다운로드 URL, 서버 파일명, 크기, SHA-256, 다운로드 시각과 현재 `parsing_status`를 기록한다. ZIP 내부 파일은 `archive_file`과 `archive_member`로 원본 컨테이너에 연결한다. `current_attachment_mapping`은 현재 첨부 332건의 실제 로컬 경로를 제공한다. 첨부가 없는 6건은 `no_attachment_posts`에 보존한다.

새 파일은 실제 서명 또는 ZIP 내부 구조로 형식을 확인하고 다운로드 바이트와 저장 파일의 크기·해시를 대조했다. 57개 다운로드 응답은 직전 실시간 검토의 SHA-256과 모두 일치했다. 내용 추출은 META-DATA-006을 따른다. 기존 통합 Excel/TXT의 275행 범위는 유지한다. 현재 전체 정보 목록과 웹은 META-DATA-007의 338개 공시 프로필을 따른다. 기존 수집목록과 HTML 목록도 이번 작업에서 재작성하지 않았다.

검증과 변경 근거: [미수집 원본 다운로드 이력](../flow/2026-10-25-remaining-attachments-download.md).

## META-DATA-006 비엑셀 Markdown 추출

재현 도구는 프로젝트의 `packages/document-extractor/`에 있다. 추가 원본 58개를 `<원본파일명>.md`로 추출하며, 원본 확장자를 유지해 기존 XLSX Markdown과 충돌하지 않는다. 원본별 `.assets/`에 PDF 페이지 PNG, 변환 XHTML·문단 텍스트, 내장 이미지, OCR 입력 사본·좌표·신뢰도 JSON과 `extraction.json`을 보존한다.

- PDF: PDFium으로 전체 52페이지를 렌더링하고 pdfplumber의 텍스트 레이어·표와 페이지별 Vision OCR을 구분해 보관한다.
- HWP: pyhwp의 문단 텍스트와 XHTML 표를 추출하고 병합 범위를 기록한다. 표는 문단 텍스트의 `<표>` 표시와 별도로 셀 내용을 보존한다. 내장 이미지는 OLE 스트림에서 추출해 OCR한다.
- HWPX·DOCX: ZIP 내부 XML 본문·표·내장 이미지를 추출한다. HWPX는 원본 셀 주소와 병합 범위를 보존한다.
- PNG·JPEG 및 HWP 내장 이미지: 원본을 유지하고 명암 조정·최대 2배 확대 사본으로 한국어·영어 Vision OCR을 수행한다. PDF 페이지는 렌더링한 원본 페이지를 OCR한다.
- ZIP: 내부 파일명·크기·SHA-256과 PDF/XLSX Markdown 링크를 기록한다.

현재 결과는 문서 본문 57개와 ZIP 목록 1개, 추출 표 102개, OCR 원본 이미지 64개다. OCR을 포함한 43개 문서는 `extracted_with_ocr_review_required`, 나머지는 `extracted` 상태이며 수집목록에 `markdown`, `markdown_sha256`, `extraction_method`를 추가했다. 신뢰도는 글자 정확도의 보증으로 사용하지 않는다. 호텔 농심 내장 이미지 1개의 확인된 금액 5항목은 원본 대조 확인 사항으로 별도 기록하며 자동 OCR 원문은 추적을 위해 유지한다.

검증기는 원본 해시, 전체 페이지 수, PDF 텍스트·표, HWP 변환본의 문단·셀, XML 본문, OCR 인식 행, 상대 링크를 대조한다. 기존 XLSX와 원본 해시도 확인한다. 기존 엑셀 Markdown의 별도 편집은 이전 검증 스냅샷과의 차이로 기록하고 덮어쓰거나 되돌리지 않는다. 모든 OCR 숫자의 수동 검수는 수행하지 않았으며 가격 정규화·지도용 통합 스키마는 이번 추출 범위에 포함하지 않는다.

목록: [추가원본 추출 목록](../../추가원본_추출_목록.md). 검증: [비엑셀 추출 JSON](../flow/2026-10-25-nonexcel-extraction-validation.json). 이력: [비엑셀 Markdown 추출](../flow/2026-10-25-nonexcel-markdown-export.md).


## META-DATA-007 의미 중심 카탈로그와 클라이언트

재현 도구는 `client/scripts/build_catalog.py`다. Python 표준 라이브러리로 원본 셀·병합 헤더·주석·도형 안내·하이퍼링크와 기본정보를 읽고 `catalog.json` schemaVersion 2를 생성한다. 같은 데이터의 `catalog.js`는 서버 없이 HTML을 직접 여는 대체 경로다. 웹은 정상 HTTP 실행에서 JSON을 우선 읽는다.

원문 공개 시트 중 해석 가능한 현재/최신 명칭을 우선하고, 없으면 보이는 첫 가격 시트를 대표로 사용한다. 숨긴 참고 자료는 문서에 보존하되 다른 업체/과거 가격을 대표 통계에 섞지 않는다. 헤더·행 조건으로 성인 단가, 대관, 장식, 소인, 음주류, 추가 인원, 패키지 총액, 할인액을 구분한다. 가격 원문과 시트·셀 근거를 함께 보관한다.

기존 275개 프로필에 게시물 기본정보와 현재 첨부 연결을 결합해 전체 338개 프로필을 제공한다. 추가 63개의 의미 중심 MD/TXT를 `__post-<게시물ID>` 이름으로 생성한다. 현재 원본 공유 프로필 1개는 `duplicateOf`로 연결해 통계에 중복 반영하지 않는다. 기본 식대 236개·대관료 222개·대관/장식 합계 6개의 원본을 각각 비교한다.

비엑셀 자동 추출본은 가격·이용 안내와 취소·환급 안내로 묶고 원문 파일·이미지를 함께 연결한다. 확인하지 않은 OCR 가격을 통계용 값으로 추정하지 않는다. 전체 이미지 링크는 142개의 고유 파일 경로를 제공한다. 원본 Excel과 추가 첨부의 해시는 변경하지 않는다.

클라이언트는 `client/`에 구현되며 실행 주소는 `http://127.0.0.1:3077/client/`다. 원본 형식별 다운로드 버튼을 표시하고, 첨부 없는 6개 게시물도 기본정보·주소·출처로 찾을 수 있다. 서버·테스트·코드 구조는 [프로젝트 시스템 설계](../../../../docs/stock/system-design.md)를 따른다.
