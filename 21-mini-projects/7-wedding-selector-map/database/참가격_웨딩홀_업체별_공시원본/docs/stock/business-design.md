## META-001 수집 범위

`database/참가격_웨딩홀_업체별_공시원본`은 2026-10-25 확인한 전국 14개 지역, 게시글 338개의 공개 첨부를 보존한다. 현재 첨부가 있는 게시글 332건은 모두 로컬 파일에 연결되며, 첨부 ID가 없는 6건은 별도 상태로 관리한다. 동일 내용의 첨부는 해시로 기존 파일에 연결한다.

기존 공시 원본 275개에 대한 기본정보·엑셀 추출 범위는 유지한다. 업체별 공시 274개와 이전 대구 공시 1개를 포함한다. 기존 원본의 실제 형식은 XLSX 273개, XLS 1개, HWP 1개이며, HWP는 기존 파일의 확장자가 `.xls`로 되어 있다.

추가 수집은 미수집 비엑셀 첨부 56개와 경원재 ZIP 원본 1개, ZIP 내부 PDF 1개로 총 58개 파일이다. PDF 35개, HWP 14개, HWPX 2개, 이미지 5개, DOCX 1개, ZIP 1개를 지역 폴더에 저장했다. 추가 문서 57개는 본문·표·이미지 OCR을 Markdown으로 추출했고, ZIP 1개는 내부 파일 목록과 PDF/XLSX 추출본에 연결했다. 가격 비교를 위한 숫자 정규화나 모든 OCR 금액의 수동 검수는 완료하지 않았다.

## META-002 기본정보

각 원본에 업체명, 지역 분류, 주소, 연락처, 자료 공개일, 확인일, 게시물과 본문 URL, 첨부파일 ID를 연결한다. 자료 공개일은 게시물 본문 표의 값을 사용한다. 가격 적용연도와 동일한 의미로 취급하지 않는다. 기존 수집목록의 등록일은 참고 열로 분리한다.

원문 값은 임의로 추정 보정하지 않는다. 퍼스트가든 웨딩의 공개일 `026-05-20`은 원문을 유지하고 확인 필요 상태와 사유를 표시한다.

## META-004 원본 보존과 검증

기존 공시 원본은 수정하지 않는다. 원본 275개의 SHA-256이 수집목록과 일치함을 확인했다. 주소·연락처·공개일 원문은 275건 모두 확보했으며, 그중 공개일의 유효한 날짜 형식은 274건이다. Markdown 추출 과정에서도 기존 공시 및 통합 엑셀 총 276개의 해시를 다시 대조해 원본 보존을 확인했다.

기존 TXT에는 전체 305개 시트와 값이 있는 셀 19,074개의 좌표 기반 추출 내용을 보관한다. 현재 MD는 같은 원문을 의미 중심으로 재구성한 문서이므로 기존 좌표형 Markdown 검증 스냅샷과 형식이 다르다. 이미지 78개는 바이트가 동일한 원본 자산으로 보존했다. 라비니움 원본의 스타일 참조 오류 5개 셀은 값을 추출하고 표시 형식 확인 사항을 해당 MD에 남겼다.

## META-005 전체 공시 웹과 의미 중심 읽기 문서

`client` 정적 웹과 `catalog.json`/`catalog.js`는 게시글 338건 모두를 포함한다. 기존 Excel 기반 문서 275개를 재구성하고, 추가 원본·기본정보를 연결한 프로필 문서와 TXT 63쌍을 별도 생성했다. 비엑셀 원본 추출 MD 58개와 원본 파일은 덮어쓰지 않고 근거로 연결한다.

가격 비교는 기본 성인 최저 식대 236개, 공간 대관료 222개, 대관·장식 합계 6개의 해석 가능한 원본으로 한정한다. 소인·음주류 별도 단가·추가 인원·할인액·패키지 총액·미검증 OCR 가격은 섞지 않으며, 동일 원본 공유 공시는 통계에 한 번 반영한다. 이전 공시 가격은 기본 표본에서 제외한다. 읽기 문서에는 이미지 자동 판독의 한계를 명시한다.

전체 목록의 원본 공개 정보는 지도·검색·필터·정렬·상세·관심·비교·가격 분포와 연결된다. 현재 문서 체계와 검증은 [웹·MD 재구성 이력](../flow/2026-10-25-semantic-web-catalog.md)을 따른다.
