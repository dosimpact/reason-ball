# 2026-10-25 미수집 원본 다운로드

## 배경과 결정

사용자가 미수집 PDF 및 다른 모든 미수집 형식도 우선 내려받고 파싱은 나중에 진행하도록 요청했다. [직전 완전성 검토](2026-10-25-site-completeness-audit.md)의 미수집 첨부 56개와 경원재 ZIP 원본을 수집 대상으로 삼았다.

## 변경

- 사이트에서 PDF 34개, HWP 14개, PNG 3개, JPEG 2개, HWPX 2개, DOCX 1개 등 미수집 첨부 56개를 다운로드했다.
- 경원재 바이 워커힐의 ZIP 첨부 `31623`도 원본 그대로 보존하고 내부 PDF를 별도 저장했다. 기존 XLSX는 유지했다.
- 새 파일은 총 58개: PDF 35개, HWP 14개, 이미지 5개, HWPX 2개, DOCX 1개, ZIP 1개다. 기존 지역 폴더에 `<업체명>__<첨부ID>.<확장자>`로 배치했다.
- [추가원본 수집목록](../../추가원본_수집목록.json)에 파일별 출처·해시·미파싱 상태 및 현재 첨부 전체의 로컬 연결을 기록했다.
- 추가 파일의 본문 파싱·OCR·가격 정규화와 XLSX·TXT·MD 변환은 수행하지 않았다.

## 검증

- 다운로드 57개 응답의 SHA-256이 직전 실시간 검토 결과와 전부 일치했다.
- 저장 파일 58개의 크기와 SHA-256을 다운로드 데이터 또는 ZIP 내부 원본과 대조했다.
- PDF·HWP·이미지는 파일 서명을, HWPX·DOCX·ZIP은 컨테이너 구조와 CRC를 확인했다. 본문 내용 검증은 수행하지 않았다.
- 현재 게시글 338개 중 첨부가 있는 332개는 모두 로컬 파일에 연결됐다. 사이트에서 첨부 ID가 없는 6개는 별도 목록으로 보존했다.
- 새 파일과 목록을 저장한 직후, 작업 전 존재한 925개 파일의 SHA-256이 변경되지 않았음을 확인했다. 이후 아래 stock 문서 2개만 승인된 현재 수집 범위에 맞춰 수정했다.
- 같은 내용의 셀레네하우스 청주 첨부 `31591`과 MH컨벤션 `31644`는 기존 파일에 연결했으며 중복 원본을 추가하지 않았다.

## Stock 반영 및 후속 상태

[업무 설계 META-001·003·004](../stock/business-design.md)에 확대된 원본 수집 범위와 미파싱 상태를 반영했다. [데이터 설계 META-DATA-001·005](../stock/system-design.md)에 추가 수집목록 스키마와 첨부 연결 규칙을 반영했다.
