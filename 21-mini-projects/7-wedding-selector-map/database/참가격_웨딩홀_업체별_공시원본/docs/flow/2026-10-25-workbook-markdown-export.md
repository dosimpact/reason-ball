# 2026-10-25 업체별 엑셀 내용 Markdown 추출

## 요청과 범위

사용자가 현재 폴더 하위의 업체별 공시 내용을 Markdown으로 추출하고, 업체마다 TXT·XLSX·MD를 모두 갖추도록 요청했다. 기존 업체별 공시 275건과 하위 통합 기본정보 파일을 대상으로 한다.

## 채택한 처리 기준

- 기존 XLSX 및 공시 원본은 보존하고 같은 이름의 MD에 모든 시트의 셀 내용을 추출한다.
- TXT의 기존 기본정보는 보존하고 뒤에 공시 내용의 텍스트 표현을 추가한다.
- 원본 행·열 좌표와 병합 범위를 명시하여 빈 셀과 병합 관계를 구분한다.
- 구형 XLS 1건은 XLSX 사본을 추가한다. 확장자가 XLS인 실제 HWP 1건은 원본 스캔을 보존한 XLSX와 MD를 추가한다.
- 이미지 등 셀 외의 원본 내용은 별도 자산으로 추출해 연결한다. 원문 가격의 연도·단위·조건을 임의로 정규화하지 않는다.

## 완료 및 검증 결과

- 업체별 공시 275건 모두 같은 이름의 TXT·XLSX·MD를 제공한다. 통합 기본정보 1건도 3종으로 제공한다.
- 기존 XLSX 273개는 보존했다. 캠퍼트리 XLS 1건과 MH컨벤션 HWP 1건에 XLSX 사본을 추가하고 변환 전 원본도 보존했다.
- 총 276개 XLSX, 305개 시트, 값이 있는 셀 19,074개를 MD와 TXT로 추출했다.
- Markdown의 표를 다시 해석해 원본 셀 좌표별 텍스트 값과 전부 대조했다.
- 이미지 78개(기존 XLSX 75개, HWP 원본 3개)를 별도 자산으로 추출하고 바이트 해시를 대조했다. 이미지 전체 OCR 텍스트로 확정한 결과는 아니다.
- 주석·하이퍼링크·도형 텍스트·병합 범위·셀 표시 형식도 추출했다. EMF 2개는 다운로드 링크를 제공한다.
- 라비니움 원본의 스타일 참조가 유효하지 않은 5개 셀은 값은 그대로 추출하고 MD에 확인 사항을 표시했다. 원본 수정을 하지 않았다.
- 기존 원본 및 통합 엑셀 총 276개의 SHA-256이 모두 동일하다. TXT 276개의 기존 기본정보도 보존했다. 통합 TXT에 적힌 이전 폴더명 1곳은 현재 이름으로 갱신했다.
- 새 XLSX 두 개의 셀 및 이미지 원본을 대조하고 네 시트를 렌더링해 확인했다. 캠퍼트리 사본의 변환 안내 줄이 잘리지 않도록 병합 범위만 조정했다.
- 새 MD와 이미지 자산의 상대 링크, 275개 업체별 파일 3종 존재 여부를 확인했다.
