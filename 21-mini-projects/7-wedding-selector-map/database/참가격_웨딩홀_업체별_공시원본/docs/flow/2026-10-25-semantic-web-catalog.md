# 2026-10-25 의미 중심 MD와 전체 웹 카탈로그

## 배경과 변경

사용자가 기존 Markdown을 Excel 좌표 표가 아니라 모든 정보를 재가공한 업체 안내로 만들도록 요청했다. 동시에 지도·가격 통계·전체 테이블을 제공하는 정적 `client` 앱을 요청했다.

기존 Excel 기반 공시 275개의 MD를 위치·홀별 가격·포함/추가 항목·이용 조건·취소 규정·별도 참고 자료·이미지·출처로 재구성했다. 기존 TXT의 좌표형 전체 추출은 보존했다. 원본 파일을 변경하지 않았다.

추가된 58개 비엑셀·ZIP 원본 및 추출 MD와 기본정보를 읽어 추가 프로필 63개를 생성했다. 원본 추출 MD는 보존하고 `__post-<ID>.md/.txt`의 읽기 문서를 별도 제공한다. 전체 카탈로그는 338개 게시물 모두와 연결된다. 전체 목록은 338개 프로필을 연결하지만 통합 Excel/TXT에 대응하는 개요 MD는 원래 275개 범위를 유지한다.

## 가격 해석과 근거

- 기본 성인 식대, 공간 대관료, 대관·장식 합계를 구분한다.
- 소인·음주류 별도 비용·추가 인원·패키지 총액·할인액은 성인 기본 단가로 취급하지 않는다.
- 표의 누락 병합, 반복 헤더, 복수 홀, 현재 보이는 대표 시트와 숨김 참고 시트를 구분한다.
- 가격 원문과 시트·행·열 근거를 보관한다. 자동 판독 가격을 검증 없이 수치 통계에 넣지 않는다.
- 기본 식대 236개, 공간 대관료 222개, 대관·장식 합계 6개의 원본이 비교 가능하다. 동일 원본을 공유하는 청주점 프로필은 한 번만 집계하고 이전 공시 가격은 기본 표본에서 제외한다.
- 원본 이미지 142개 경로와 관련 텍스트·참고 링크를 웹과 문서에 연결한다.
