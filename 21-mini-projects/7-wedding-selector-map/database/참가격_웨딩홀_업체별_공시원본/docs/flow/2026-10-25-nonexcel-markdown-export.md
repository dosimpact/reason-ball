# 2026-10-25 비엑셀 원본 Markdown 추출

## 배경과 결정

사용자가 추가 수집한 PDF·HWP 등의 전체 내용을 Markdown으로 추출하도록 요청했다. 추가 원본 58개를 대상으로 하며 기존 원본과 엑셀 추출본을 보존한다. 원본 확장자를 유지한 `.pdf.md`, `.hwp.md` 등의 이름을 사용해 경원재 PDF와 기존 XLSX Markdown의 이름 충돌을 방지한다.

## 구현과 진행

`packages/document-extractor/`에 PDF 텍스트·표·페이지 렌더링, HWP 문단·표·내장 이미지, HWPX·DOCX XML, 한국어·영어 Vision OCR과 ZIP 내부 파일 연결을 구현했다. PDF 페이지·내장 이미지 및 OCR 좌표·신뢰도는 원본 옆의 형식별 `.assets/`에 보존한다. OCR은 원문 텍스트와 구분하며 자동 추출에 남는 오인식 가능성을 표시한다.

## 결과와 검증

- 추가 원본 58개 전체 추출, 오류 0건. 본문 문서는 PDF 35개·HWP 14개·HWPX 2개·이미지 5개·DOCX 1개 등 57개이며 ZIP 1개는 내부 파일 목록과 추출본을 연결한다.
- PDF 52페이지, 원본 표 102개, OCR 원본 이미지 64개를 처리했다. 자동 OCR이 포함된 문서는 43개다.
- 원본 58개 및 기존 공시 원본 275개, 기존 XLSX 276개의 SHA-256 보존을 확인했다.
- PDF의 전체 페이지·텍스트·표 셀, HWP 변환 XHTML의 문단·셀, HWPX·DOCX 본문, OCR 인식 행의 Markdown 보존과 상대 링크를 검사했다. 58건 모두 통과했다.
- PDF 52페이지 및 스캔·내장 이미지 연락판을 시각적으로 확인했다. 이 검토는 전체 글자·금액의 수동 검수가 아니다.
- 저해상도 호텔 농심 `BIN0001.png`에서 통화 기호가 숫자로 인식되는 사례를 확인했다. 명암·확대 전처리를 적용하고 확인한 금액 5항목을 원본 대조 확인 사항으로 기록했다. 원본 OCR은 추적을 위해 보존했다. 나머지 OCR 결과에도 오인식 가능성이 남아 있다.
- 기존 엑셀 Markdown 275개가 병행 작업으로 재구성돼 이전 검증 스냅샷과 달랐다. 이 추출기는 형식 확장자가 붙은 새 Markdown만 작성했으며 해당 변경을 되돌리지 않았다. 기존 XLSX 해시는 모두 유지됐다.

[검증 JSON](2026-10-25-nonexcel-extraction-validation.json)에 도구 버전, 파일별 방법·페이지·표·OCR 정보와 검증 결과를 보존했다. 재현 명령은 프로젝트 `packages/document-extractor/README.md`를 따른다.
