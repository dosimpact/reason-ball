# Canvas 데이터와 DuckDB 갱신 설계 범위 확장

- 날짜: 2026-10-18
- 맥락: 사용자가 Canvas 데이터 모델, DuckDB SQL/도구 시뮬레이션 포함, OpenUI 변경 시 호환성, 생성 이후 결정적 API 갱신을 요청했다.
- 변경: 요구사항 문서 끝에 D 섹션을 append했다. 기존 B/C는 보존하고 D에서 우선 적용할 범위 확장을 명시했다.
- 결정: DuckDB 분석·쿼리 도구와 LLM 없는 반복 갱신 시뮬레이션을 PoC에 포함한다. 자동 호환성을 가정하지 않고 버전·fixture 마이그레이션을 검증한다.
- 이유: 생성 UI와 반복 데이터 조회를 분리하고 갱신 비용·상태 보존·오래된 데이터 표시를 명시하기 위함이다.
- 영향: business CANVAS-001, system CANVAS-101, 요구사항 DATA-01~03/FRESH-01~04/COMPAT-01 및 SPIKE-08~10.
- 검증: 기존 요구사항 prefix 보존과 문서 링크를 확인한다. 공식 OpenUI·DuckDB 문서를 참조했다. 코드·의존성·DB·환경 파일은 변경하지 않았다. 실행·브라우저·provider 검증은 미실행이다.
- 후속: P0 환경 분리 후 SPIKE-08/09 우선 검증. 데이터 모델과 API 이름은 제안이며 확정 구현이 아니다.
