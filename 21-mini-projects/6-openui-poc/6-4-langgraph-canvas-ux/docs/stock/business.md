# 제품 설계 — OpenUI Dynamic Canvas

## CANVAS-001 제품과 범위

`6-4-langgraph-canvas-ux`는 `6-3`의 Python LangGraph/OpenUI 기반에 `analytics-template`의 Canvas UX를 구현한 로컬 분석 PoC다. Chat은 질문·설명·미리보기 공간이고 Canvas는 독립 위젯을 배치·저장하는 공간이다. 요구사항 B~E가 범위 기준이며 A2UI/Tambo 런타임을 사용하지 않는다.

## CANVAS-002 전체 Canvas UX

- Chat의 독립 OpenUI 카드에 Add 버튼과 drag-and-drop을 제공한다. 복사한 카드의 입력값은 원본 Chat과 독립적이다.
- 여러 Canvas를 생성·선택·이름 변경·정렬·삭제하며 전체 비우기와 탭 삭제에는 확인창이 있다.
- 카드를 선택·삭제·정렬하고 다른 Canvas로 이동한다. 12열, 32px 행, 16px 간격 그리드에서 pointer/keyboard resize를 제공한다.
- bar/line/pie/표와 Markdown 카드를 표시한다. 일반 OpenUI 입력·카운터 등은 원래 카탈로그를 통해 동작한다. 제목·타입·조건 변경과 탭 관리는 자연어로 요청할 수 있다.
- 대화 목록·새 대화·삭제, 진행/도구 상태, 중단·오류·재시도, 밝은/어두운 테마, 좁은 화면의 세로 배치를 제공한다.

일반 분석 질문은 Chat 미리보기를 만든다. 명시적인 Canvas 요청만 Canvas를 변경하며 설명만 요청하면 기존 위젯을 보존한다. 선택한 widgetId와 현재 문서·Chat 결과를 전달해 맥락을 유지한다. 실패한 위젯은 성공한 위젯과 분리해서 다시 실행한다.

## DATA-001 분석과 갱신

DuckDB의 합성 일별 매출·광고 데이터를 실제 SQL로 조회한다. 지원 지역은 ALL/KR/US/JP, 통화는 USD, 시간대는 UTC다. 월별 비교는 같은 단위로 집계한 사실 테이블을 결합하고, 부분 월도 실제 날짜 범위로 집계한다. 비율은 NULLIF로 0 분모를 처리하며 null·빈 결과를 실제 0으로 바꾸지 않는다.

처음 생성하거나 새 지표를 정의할 때 모델이 SQL을 제안하고 서버가 검증·등록한다. 지역·기간 UI 변경과 새로고침은 모델 없이 등록 쿼리를 실행한다. 수동 갱신이 기본이며 snapshot은 자동 조회하지 않고 polling은 활성 Canvas에서 60초마다 갱신한다. 화면 비활성·오프라인에는 polling을 쉬고 실패 시 간격을 늘린다.

각 결과에 합성 데이터 표시, 표시 조건, 조회 시점, 원천 반영 날짜와 revision을 표시한다. 갱신 실패 시 마지막 정상 결과를 유지한다. 이전 필터의 늦은 응답은 버리고 과거 설명의 데이터 버전이 달라지면 ‘이전 데이터 기준 설명’으로 표시한다. 자연어로 새 설명을 요청할 때만 다시 분석한다.

## SAVE-001 보관과 호환성

문서·배치·프로그램·입력 상태·마지막 정상 snapshot은 이 브라우저에 자동 저장한다. 쿼리 정의는 Python의 로컬 runtime에 영속 저장한다. 지원 문서는 모델 호출 없이 복원하며 수동/snapshot 카드는 복원 과정에서 조회하지 않는다. polling은 복원 후 해당 정책을 재개한다.

문서 v1→v2 fixture를 명시적으로 변환한다. 미지원 문서/카탈로그/결과 계약은 원본을 덮어쓰지 않고 읽기 전용 마지막 결과와 다운로드/백업 초기화를 제공한다. 앱을 이미 로드할 수 있는 상태에서 백엔드가 없어도 snapshot 복원이 가능하다. 최초 오프라인 접속을 위한 PWA 캐시는 포함하지 않는다.

## IUI-001 기존 OpenUI와 운영 경계

`/chat`에 원래 AgentInterface와 mock 날씨·주가·검색 도구, 기존 함수·액션·갤러리를 유지한다. Canvas 화면의 일반 UI 요청도 전체 카탈로그로 생성한다. 외부 미디어 API의 가용성은 해당 서비스에 의존한다.

Python 2037 / Next.js 3045를 사용한다. 실제 모델 키는 backend의 `.env`에만 둔다. 계정·인증·공유·보고서·운영 실시간 push, 임의 root 내부 부분 추출은 이번 구현에 포함하지 않는다. 예측·가정 수치를 실제 분석 결과로 대체하지 않는다. 자연어 모델은 확률적이므로 실패한 출력은 적용하지 않고 오류로 표시한다.
