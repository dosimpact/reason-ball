# 비즈니스 설계

- DEMO-01: 공식 Open Intelligent UI 데모를 로컬에서 실행한다. 3D 설명, 표와 차트, 계산 도구, 지도 여행을 실제 에이전트 요청으로 생성한다.
- DEMO-02: 현재 공식 버전의 OpenAI 답변 모델과 Jev 시각화 라우터를 사용한다. 채팅 UI에서 두 제공자의 방문자 키를 모두 요구한다. OpenAI 단독 실행은 구현되어 있지 않다.
- DEMO-03: API 키는 로컬 환경 파일 및 브라우저 세션 메모리에만 둔다. Git 및 문서에 비밀키를 기록하지 않는다.

정확한 설치·검증 상태는 [2026-10-20 기록](../flow/2026-10-20-demo-install.md)을 따른다.
