# 사용자 관점 시나리오 정리

- 날짜: 2026-10-25
- 요청: 구현에 앞서 `goal.md`에 사용자가 무엇을 할 수 있는지 문서화한다.
- 변경: 기존 US-01~16을 유지하고 사용자 목적별 요약 표를 추가했다. US-07에 입력값 변경에 따른 계산과 결과 버튼 사용 경험을 구체화했다.
- 이유: 기술 명세를 읽지 않아도 대화, 보고서 분석, Canvas 조작과 보관 흐름을 이해할 수 있게 한다.
- 문서 동기화: `goal.md`의 사용자 시나리오 절과 `docs/stock/user-scenarios.md`를 일치시켰다. 제품 목적과 시스템 구조는 변경하지 않았다.
- 검증: 시나리오 16개 및 두 문서의 내용 일치를 확인했다. 이번 변경은 문서만 해당하며 기능 구현 또는 실행 검증을 의미하지 않는다.

## 대화와 Canvas 전환 경험 보완

- 요청 맥락: 사용자 관점에서 가능한 경험만 문서화한다.
- 변경: US-09에 대화 화면, Canvas 화면, 함께 보기 전환과 대화·기업·보고서·패널 맥락 유지 경험을 명시했다.
- 이유: 화면 이동 자체뿐 아니라 전환 후에도 분석을 이어갈 수 있다는 기대를 설명한다.
- 영향 문서: `goal.md` 사용자 시나리오 절과 `docs/stock/user-scenarios.md`를 동기화했다. 기존 개발 요구사항과 구현 코드는 수정하지 않았다.
- 검증: US-01~16의 연속 ID와 두 문서의 시나리오 내용 일치를 확인했다. 목표 경험 문서이며 구현 완료를 주장하지 않는다.
