## 현재 원본 계약 직접 대조와 E2E

- 기준 파일: 6-2의 `frontend/package.json` generate 명령이 생성하는 `src/generated/system-prompt.spec.json`(84 구성요소), 6-5의 `src/generated/spec.json`(137 구성요소/59 함수/1 액션). 6-2에 남은 별도 `spec.json`은 현재 생성 명령과 연결된 기준이 아니므로 비교에서 제외했다. 현재 회귀 fixture는 6-2의 실제 생성 명세와 정확히 일치한다.
- 직접 대조 결과: 기존 명세는 보존되며 Card의 허용 자식만 추가됐다. 나머지 인자와 함수·액션 정의는 동일하다. 프런트엔드 생성 프롬프트와 백엔드 패키지 프롬프트의 바이트가 일치한다. 증거: `frontend/output/playwright/final-catalog-inheritance.json`.
- 최신 `E2E_EXTERNAL_SERVERS=1 npm run test:e2e`: 네 테스트 모두 통과. 표/출처·반응형 입력·함수 별칭·SVG·클립보드, 45개 갤러리 예제의 light/dark 렌더, 실제 문서 비교와 후속 질문/SQLite reload, 실제 모델의 카운터 생성/클릭/이력 복원이다. 증거: `frontend/output/playwright/final-inheritance-e2e.txt`와 `frontend/playwright-report/index.html`.
- 테스트 자료 조건: 역사 보고서가 추가되어도 실행되도록 정확히 3개라는 개수 가정 대신 NVIDIA/AMD/Intel 필수 문서 ID 존재를 검사한다. 테스트가 생성한 임시 대화만 정리하고 대표 검토 대화는 보존한다.
