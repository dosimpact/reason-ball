## 검증과 한계

- 16개 대화를 브라우저에서 각각 열고 assistant 내용이 렌더링됨을 확인했다. 추가로 US-07 입력 계산, US-12 이동 버튼, US-15 reload를 검증했다.
- 일부 최초 실행은 불필요한 Canvas 계획, 표시/저장 실패, 로컬 자료 부재 오안내를 보였다. 실패 기록을 지우지 않고 같은 대화에서 정정/재표시/실제 버튼 추가로 보완했다. 따라서 첫 요청의 무오류 성공 또는 모든 자연어 표현의 안정성을 증명하는 세트는 아니다.
- US-10에서 근거 검사가 사용자 요청의 연도 제외를 자료 누락 오류로 판단한 사례가 있었다. 차트에 제외 의도를 명시한 후 저장했다.
- 마지막 실행 진단은 16개 모두 missing=[]이지만, 이것만으로 정확성을 주장하지 않는다. 실제 화면/패널/다운로드 증거와 함께 본다.
- 증거: `backend-langgraph/output/us-review/manifest.json`, 시나리오별 메시지/상태/SSE, `frontend/output/playwright/us-review-16-browser.txt`와 `US-xx-review.png`.
- US-14 실제 파일: `frontend/output/playwright/US-14-export.json`, `.csv`, `.pdf`(2페이지). 기존 PDF 준비 자료/SEC 신규 수집과 구분한다.


## US-10 근거 검사 수정 후 추가 회귀

`[회귀 검증] 연도 제외와 근거 검사` (`05a0c606-5371-490e-928f-edf7f8f9120f`)에서 실제 NVIDIA PDF51 원문→3년 매출 패널→짧은 FY2025 제외 후속 요청을 실행했다. FY2024=60,922/FY2026=215,938 백만 USD, 동일 패널 ID/배치, 브라우저 새로고침 복원을 확인했다. 첫 생성의 OpenUI 구문 오류는 같은 실행 내 자체 수정됐고 이력에 남는다. SEC 다운로드 증거는 아니다.


## US-07~10 목적지와 모호한 기간 회귀

`[회귀 검증] 채팅 차트와 Canvas 추가` (`0e8b3943-39f7-47e2-816c-f9f054d22633`)에서 실제 PDF51 매출 차트 생성→명시적 Canvas 추가→설명만 요청→“1년치는 빼줘” 확인 질문을 볼 수 있다. 처음에는 Canvas 패널이 없고 추가 요청 이후1개이며, 설명 및 모호한 제외 요청은 기존 패널/버전을 유지했다. 브라우저 reload에서 세 연도와 확인 질문 복원을 확인했다.


## 공식10-Q 추가 검토

`[실데이터 검토] 10-Q 분기와 누적 실적` (`3c5b1b38-446f-4bc2-811e-cd93185c26b3`)에서 FY2027 Q2 공식 IR PDF3쪽 실적과34쪽 Part II 요약을 확인한다. 최종 Canvas는3개월 매출 두 점과 별도6개월 누적 표다. 게시 실패→중복 생성→삭제, 위험 요인 예외 문구 누락→정정도 같은 이력에 남아 있다. `[실패 보존] 10-Q 분석의 Canvas 오분류` (`394dfd8f-5444-48f0-9c93-a1363d652c08`)는 출력 위치 분리 전 실패 증거다. 이력 생성은 무오류 기능 완료를 뜻하지 않는다.


## 단일 패널 게시 회귀

`[회귀 검증] 단일 분기 패널 게시` (`b759b659-58e7-4b98-b8df-3bf2dd8ec468`)는 채팅 분석→정확히1개 패널 저장→동일 패널 제목 변경의 새 검증 이력이다. 저장 실패/중복 없이 패널1개를 유지하고 reload를 확인했다. 최초 프로그램의 분기 종료일 설명에 Fiscal Year Ended 문구가 남아 있어, 이번 증거는 게시/개수/동일성 검증이며 모든 분석 표현의 정확성 검증은 아니다.


### 분기 기간·위험 요인 후속 회귀

`[회귀 검증] 분기 기간과 위험 요인` (c763a580-e535-4570-a4a9-90c06f27d750): 실제 PDF3쪽의 분기 매출46743/96221 차트와34쪽 요약을 확인한다. turn7의 과도한 단정은 보존하며, 최신 turn9은 아래 기술된 위험 요인을 제외한다는 원문 범위를 유지한다. Canvas 전체 상태는 동일하다. 단일 분기 패널 게시 대화의 현재 Canvas도 실제 요청으로 Quarter Ended로 정정했다. 초기 잘못된 요약과 turn6 실패도 보존한다. 검증 전 초안은 최종 응답 스트림에서 제외했다.


### 자체 SEC 수집·캐시·재무 차트 최신 검토

`[실데이터 검증] 자체 SEC 수집과 캐시` (5b6ee045-b0e9-4b95-b253-bed548dc58e5): 실제 Apple10-K3건/10-Q3건 보관 상태, SEC Company Facts3년 차트, FY2024 제외와 동일 패널 갱신을 확인한다. 첫 갱신의 동기DB 차단 오류는 수정 후 같은 대화에서 성공했다. 과거 US-01의403은 당시 기록이며 현재 자체 Python 수집은 성공했다.


### SEC 원문 분석과 자동 갱신 검토

같은 자체 SEC 대화의 후속3턴에 검색·Item1 사업 요약, 두 해 Item7 비교,10-Q 분기/누적 매출 표를 추가했다. 실제 원문 금액·기간·단위를 대조하고 브라우저 복원을 확인했다. Canvas1개와 FY2024 제외 조건은 유지된다. 자동1분 갱신 및 Snapshot230초 요청0건 검증 후 Live/자동끔으로 복원했다. 최신 완료 범위와 한계는 [완료 감사](completion-audit.md)를 따른다.
