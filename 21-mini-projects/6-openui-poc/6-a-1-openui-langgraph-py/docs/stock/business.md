# 기본 OpenUI 채팅 제품 설계

## BASIC-001 목적과 범위

Next.js OpenUI 화면에서 질문하고 Python LangGraph/DeepAgents의 응답을 스트리밍으로 렌더링하는 기본 예제다. 날씨·주가·검색 도구는 mock 데이터이며 실제 정보 조회 서비스가 아니다. 모델 호출은 실제 OpenAI API를 사용한다.

문서 비교, 보고서 전용 의도 분류, Canvas는 별도 형제 예제의 기능이다. 실행은 [프로젝트 README](../../README.md), 구현은 [시스템 설계](system.md)를 따른다.
