# 2026-10-18 OpenUI의 Markdown 표현 설명

> 문서 비교 기능이 있던 원본 프로젝트에서 복사된 문서 변경 이력(PY-009).

- 결정: 응답의 외부 UI 문법과 화면에 표시되는 Markdown을 구분했다. UI 모드도 텍스트·Markdown·컴포넌트를 함께 표현할 수 있음을 설명했다.
- 근거: 당시 카탈로그의 TextContent/MarkDownRenderer와 실제 인사 응답을 확인했다. 이 컴포넌트명은 당시 원본 계약이다.
- 검증·범위: 문서 예시와 Markdown 구성을 확인했으며 실행 코드·프롬프트·환경·서비스는 변경하지 않았다. 현재 UI 계약은 [IUI-102](../stock/system.md#iui-102-ui-계약)를 따른다.
