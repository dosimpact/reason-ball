- backend: `uv run ruff check agent tests` 통과, `uv run pytest` 33개 통과.
- frontend: `npm run typecheck` 통과, `npm run lint` 오류 0개·기존 경고 4개, `npm test` 9개 파일·331개 테스트 통과.
