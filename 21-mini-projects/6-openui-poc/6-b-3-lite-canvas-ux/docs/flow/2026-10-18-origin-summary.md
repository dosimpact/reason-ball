# 복사 원본 이력 요약 — 2026-10-18~20

6-3에서 복사된 이력이다. 아래 결과는 당시 원본의 검증이며 6-7 실행 증거가 아니다.

| 결정 | 핵심 내용과 당시 검증 |
|---|---|
| Python 이관·독립 프로젝트 분리 (PY-001~008) | Python LangGraph/DeepAgents와 Next.js를 HTTP로만 연결. 키는 backend만 소유하고 생성 프롬프트를 backend 자산으로 동기화. Python 13 tests/Ruff, frontend 정적 검사·빌드·패키징, 실제 도구/후속 대화/오류 입력/브라우저 확인. |
| 변환기 재검토 | 주요 이벤트 6개 시나리오 비교. 빈 텍스트와 최종 결과 없는 도구 출력 조각에는 차이 존재. 전체 JS 패키지 동등성·provider 도구 지원을 보증하지 않음. |
| Intelligent UI 이식 (IUI-101~104) | 원본 라이브러리 43파일 byte 동일, MIT 라이선스 보존. frontend 318 tests, 카운터 조작·복원, 갤러리 45예제, 지도/사진 API 확인. 잘못된 Text 크기와 상태 참조 사례로 생성 지침 보강. |
| 주석·문서 | 한국어 구조 주석 추가 후 AST/설정 동일성 확인. OpenUI 응답 문법과 Markdown 화면 표현의 차이를 문서화. |
| 이동 후 개발 환경 복구 | 소유 `.next` 캐시 재생성, 오래된 venv shebang은 `uv sync --frozen --reinstall`로 복구. HTTP 200 외 실제 브라우저 청크 로드까지 확인; 모델 호출 미실행. |
| 초기 벤더 보고서 구상 | 표 중심 자료를 KPI·차트·필터로 표현하고 원문 모순을 보존하는 방향. 복사 당시 구현 중이었으며 완료 증거로 사용하지 않음. |

계승한 원칙: 프롬프트 자산 변경 후 backend 재시작, 원문 주장과 계산값 구분, 데모 도구를 실시간 데이터로 표시하지 않기. 현재 구조는 [시스템 설계](../stock/system.md)를 따른다.
