# 개인 서버 정보 정리

- 날짜: 2026-11-14
- 맥락: 공개 파일에서 개인 서버 주소가 확인됨.
- 변경: 모바일 기본값을 localhost로 전환하고 Vite의 개인 호스트 허용 목록을 제거함. 실제 접속 주소는 로컬 환경변수로 설정함.
- 이유: 개인 인프라 정보를 공개 코드·문서에서 분리함.
- 현재 설계: `../../aidlc/spaces/default/knowledge/documents/frontend-architecture.md` 실행·검사 절과 모바일 README. DocumentKB 복제본·해시도 동기화함.
- 범위: Git 제외 산출물·세션 원본과 과거 커밋은 보존함. 폴더 공유 시 해당 파일을 제외해야 함.
- 검증: 모바일 테스트 7개 통과, 모바일·웹 타입 검사 통과, `git diff --check` 통과. Git 추적 파일에서 기존 개인 서버 도메인이 남지 않았음을 확인함. 실제 기기 접속은 별도 환경변수 설정 후 확인해야 함.
