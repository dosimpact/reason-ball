# Rain Room 디자인 시스템

상위 방향: [비즈니스 북](business-book.md). FocusFlight의 디자인 언어를 참고하되 Rain Room의 기존 컴포넌트와 일러스트 톤을 유지한다.

## UI 기준

| 항목 | 기준 |
| --- | --- |
| 바탕·표면 | 검정 `#000`, 차콜 `#181818`·`#222` |
| 텍스트 | 기본 `#f5f5f5`, 보조 `#a3a3a3`, 약한 정보 `#737373` |
| 강조 | 민트 `#39d5ac`. 음악 재생 등 주요 실행과 진행 상태에 사용 |
| 글라스 | 검정 반투명·얇은 테두리·블러. 현재 몰입 플레이어 배경은 검정 약30% |
| 크기 | 최소44px 터치 영역, 일반 버튼56px. 페이지 여백20px, 카드24px |
| 형태 | 카드 모서리24px, 조작부14px, 얇은 선 아이콘과 명확한 포커스 표시 |

토큰의 원본은 `apps/web/src/shared/styles/design-tokens.css`다. Tailwind CSS와 공용 shadcn/ui·Radix 컴포넌트를 사용하고 기존 색·크기·간격을 보존한다.

## 화면과 상호작용

- 모바일·태블릿·PC에 대응한다. 안전 영역·주소창·키보드로 변하는 실제 뷰포트를 기준으로 설정과 플레이어를 배치한다.
- 주문대는 스크롤 없는 고정 POS 프레임, 메뉴는 음료 일러스트만4열로 보여준다. 이름은 접근성 레이블·주문 확인·영수증에 유지한다.
- 영수증은 실제 주문 내용·날짜·번호·품목·합계·바코드의 종이 인상과 롤 출력 모션·소리를 갖는다.
- 상단 톱니 아이콘은 빠른 설정을 순차 표시한다. 플레이어 톱니 아이콘은2열 설정 목록 모달을 열고, 음악·환경음·공간·시간·언어·커피·컬렉션의 개별 시트로 이동·복귀한다.
- 몰입 플레이어는 남은 시간·곡 정보·재생·다음 곡·단일 재생 방식 순환 아이콘을 간결하게 배치한다. 타이머 왼쪽 설정 아이콘은18px·터치44px이며 닫기는 원형 배경 없는 X다.
- 공간 변경은 어둡게 가린 후 준비된 새 장면을 밝힌다. 플레이어 표시와 상단 조작부의 자동 숨김은 분리한다.
- 불필요한 안내 문구·클릭 힌트·별도 큰 제목을 추가하지 않는다. 컬렉션 달성 토스트는 잠깐 표시하고 입력·초점을 가로채지 않는다.

## 그림과 접근성

공간과 음료는 저채도 세이지·크림·나무색의 색면·얇은 선 일러스트로 통일한다. 인물은 안경 없이 평온·집중·생각·졸림 등 자세와 표정을 구분한다. 조명·김·네온·날씨는 몰입을 보완하며 UI 조작을 막지 않는다.

아이콘 조작에는 접근성 이름과 필요한 툴팁을 제공한다. 모달의 초점·닫기·복귀, 모션 줄이기, 작은 화면 가독성을 유지한다. 디자인 변경은 모바일·PC의 실제 화면과 PNG로 검토하며 CPU 합성을 브라우저 검증으로 표시하지 않는다.
