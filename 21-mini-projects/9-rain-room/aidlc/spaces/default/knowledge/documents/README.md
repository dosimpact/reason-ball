# Rain Room 최신 스펙

현재 동작과 유지할 원칙만 정리한다. 변경 이력·과거 기획·전후 비교·검수 로그는 쌓지 않는다.

| 문서 | 확인할 내용 |
| --- | --- |
| [비즈니스 북](business-book.md) | 제품 방향, 사용자 흐름, 현재 기능, 미정 사항 |
| [디자인 시스템](design-system.md) | 색·컴포넌트·모바일·몰입 화면 원칙 |
| [공간 카탈로그](space-catalog.md) | 공간·날씨·동물·인터랙티브 오브제 관리 |
| [기술 구조와 개발](frontend-architecture.md) | 웹·모바일 구조, 저장, 음원, 실행·검증 |

비즈니스 북이 최상위 기획이다. 상세 구현의 전체 목록은 코드 카탈로그를 기준으로 확인한다. 변경할 때 해당 문서를 바로 수정하며, 확정되지 않은 사업 판단은 비즈니스 북의 미정 사항에 둔다.

검수 이미지는 필요할 때 `artifacts/`에 생성한다. CPU 합성·DOM 테스트·실제 브라우저·실기기 결과를 구분하고, 실행하지 않은 검증을 완료로 표시하지 않는다.
