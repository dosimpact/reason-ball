# Rain Room 비즈니스 북

현재 스펙 · 2026-11-14

## 제품 방향

거센 비가 내리는 바깥과 따뜻하고 안전한 실내의 대비로 몰입을 돕는 집중 앱이다. 커피 주문·영수증·착석이라는 짧은 의식에 공간 일러스트, 음악, 환경음과 집중 타이머를 결합한다. React 웹앱을 유지하며 모바일·WebView를 우선하고 태블릿·PC도 지원한다.

## 기본 경험

1. **주문대:** 작은 탁상 POS에서 일러스트 음료 10종을 아이콘으로 고른다. 한 행 4열이며 모바일 페이지 전체를 스크롤하지 않는다. HOT/ICE 선택은 없다.
2. **주문 확인:** 선택을 확인하고 체험 주문한다. 실제 결제나 커피 쿠폰 차감은 없다.
3. **집중 영수증:** 출력음과 함께 말린 종이가 화면 아래에서 위로 풀려 나온다. 같은 영수증에서 집중·휴식 시간을 정한다.
4. **착석:** 영수증을 누르면 커피 향 전환으로 공간에 들어간다. 직접 조작에서 오디오를 시작하고 공간 준비·착석 완료 후 타이머를 시작한다.
5. **집중 완료:** 카페를 나와 도장이 찍히는 커피 쿠폰을 받는다. 휴식 화면은 진입 시 자동 카운트다운하며 이후 새 주문으로 이어간다.

새로고침하면 항상 주문대로 돌아간다. 시간·음악·공간·언어 설정과 커피·오브제 수집 기록은 보존하며 집중 세션이나 음악을 자동 재개하지 않는다.

## 현재 기능

| 영역 | 스펙 |
| --- | --- |
| 시간 | 집중 25분·55분·직접 입력. 기본 집중35분/휴식5분, 입력 범위 집중1~180분·휴식1~60분. 어느 시간이든 변경하면 현재 단계 시간을 처음부터 계산한다. 집중·휴식 종료 알림음 제공. |
| 공간 | 일반38·프리미엄30, 총68개. 카테고리 선택과 작은 랜덤 변경 버튼. 선택은 바로 반영하고 전환은 어두워졌다 밝아진다. 옥상 영화관의 스크린은 영화 재생 애니메이션을 제공한다. |
| 몰입 화면 | 브라우저 Fullscreen API 없이 앱 내부 전체화면. 반투명 플레이어에 남은 시간·음악 제어와 작은 설정 버튼을 표시한다. 설정 버튼은 설정 목록 모달을 연다. 플레이어 X 토글은 상단 설정의 자동 숨김과 독립적이다. |
| 음악 | 23곡. 전체·집중과 탐구·활기와 카페·포근한 쉼·영감과 탐험에서 플레이리스트를 재생한다. 첫 곡 지정, 재생 방식 순환 아이콘, 다음 곡 제공. 검색·태그 셔플 UI는 없다. |
| 환경음 | 빗소리·귀뚜라미·카페 사람들·장작불·파도·시냇물·바람·새소리·물 위의 배·지나는 열차 10종을 동시 선택하고 각각 볼륨 조절. 음악과 별도 모달. |
| 커피 | 완료한 집중 시간25분당1잔 적립, 남은 시간 이월·중복 적립 방지. 설정에서 스탬프로 확인한다. 프리미엄 공간은 현재 모두 공개하며 잠금·차감은 적용하지 않는다. |
| 나의 컬렉션 | 숨겨진 사물242개. 최초 클릭 반응이 수락되면 토스트·수집 저장·그림 해금. 미수집은 이름·공간·잠금만 공개. 전체·수집 완료·미수집 필터 제공. |
| 언어 | 한국어·영어·중국어 간체. 수동 선택을 우선하며 미선택 시 브라우저 언어, 미지원은 영어. 전환해도 타이머·오디오는 유지한다. |

음악 변경은 타이머·환경음을 초기화하지 않는다. 상단 톱니 아이콘은 빠른 설정을 순차적으로 펼치고, 플레이어의 작은 톱니 아이콘은 설정 목록 모달을 연다. 목록에서 개별 설정으로 이동·복귀할 수 있고 닫으면 플레이어 버튼으로 초점을 돌린다. 볼륨은 음악 설정에서 조절하며 몰입 플레이어에는 슬라이더를 두지 않는다.

## 유지할 원칙

- 어두운 검정·차콜 UI와 민트 강조, 차분한 SVG 일러스트 감성을 유지한다. 실사 음료를 섞지 않는다.
- 공간마다 인물·인테리어·식물·동물·광원·창문 형태를 구분한다. 프리미엄은 고유 인물·오브제와 최소3~4개의 동적 포인트로 차별화한다.
- 동물은 스스로 생활하지만 인터랙티브 오브제는 눌렀을 때만 반응한다. 발견을 유도하는 표시나 안내는 두지 않는다.
- 수집과 설정은 현재 기기의 localStorage에 저장한다. 서버 계정·동기화는 아직 도입하지 않는다.

## 미정·남은 과제

대상 사용자 세분화, 수익 모델·가격, 성공 지표, 출시 일정, 프리미엄 잠금 도입 시점은 미정이다. 서버 저장 전환 시점도 미정이다.

실제 iOS·Android의 오디오·백그라운드·타이머 복귀·안전 영역 검수가 필요하다. Expo/EAS 계정 연결, 서명 빌드, 운영 HTTPS 주소와 최종 앱 식별자·스토어 제출은 남아 있다. 브라우저 연결 오류로 실제 화면 검수가 완료되지 않은 범위는 별도 실검증이 필요하다.
