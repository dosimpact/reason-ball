# 2026-11-02 — Phase 1 MVP

## Context

OAuth 2.0과 OIDC를 실제 HTTP 흐름으로 관찰하는 로컬 학습 환경이 필요했다.

## Accepted change

- `21-mini-projects/8-oauth-oidc-lab` 독립 학습 프로젝트를 추가한다.
- confidential BFF client와 PKCE를 함께 사용한다.
- token은 서버 메모리에만 보관하고 브라우저에는 불투명 세션 쿠키만 전달한다.
- 네트워크 실측 trace와 재구성 trace를 데이터 모델에서 구분한다.
- Keycloak 26.8.1 realm import로 동일한 client/user/role/scope를 재현한다.

## Rationale

BFF는 refresh token과 client secret을 브라우저에서 제거하면서도 Authorization Code, PKCE, state, nonce의 실제 프로토콜을 직접 구현하고 관찰할 수 있다. 별도 Resource Server는 로그인과 API 인가가 서로 다른 책임임을 코드 수준에서 보여준다.

## Reconciliation notes

- 호스트의 기존 `8080` 사용자를 방해하지 않도록 Keycloak public port를 `8180`으로 확정했다.
- 전체 realm import에서는 built-in `profile`, `email`, `roles`, `basic` scope가 자동 생성되지 않았다. 현재 realm 파일은 username, email, full name, realm roles, access-token subject, resource audience mapper를 모두 명시하여 import 결과를 재현 가능하게 한다.
- 브라우저 cookie가 같은 host의 Keycloak 경로로 전달되지 않도록 BFF session cookie 경로를 `/api`로 제한했다.
- Trace 마스킹은 endpoint/algorithm metadata를 보존하고 code, state, nonce, verifier, token, cookie, Authorization 값만 완전히 제거하도록 검증했다.
