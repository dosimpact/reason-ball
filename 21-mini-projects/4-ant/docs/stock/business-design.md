# Cat Atelier 비즈니스 설계

## 목표
작은 고양이들이 픽셀 그림을 해체하는 색상·수량·순서 퍼즐. React 웹 및 React Native iOS/Android 앱을 제공한다. 아래 계약은 구현된 게임 규칙이며 플랫폼별 실행 판정은 테스트 설계와 유량 검증 기록을 따른다.

## 게임 계약
- GAME-01: 중앙에 인식 가능한 픽셀 그림, 그 아래 운반 목적지 구멍과 정확히 5개 활성 상자 자리가 있다.
- GAME-02: 3개 세로 대기열의 맨 앞 상자만 선택한다. 색상과 숫자는 수집할 픽셀 색과 개수다. 선택하면 첫 빈 자리에 배치한다. 가득 찼을 때 추가 배치는 거부한다.
- GAME-03: 바깥 빈 공간과 상하좌우로 연결된 테두리 블록만 접근 가능하다. 밀폐된 내부 구멍과 대각선 틈은 길이 아니며, 예약 블록은 실제로 집을 때까지 장애물이다. 같은 색 고양이가 상자에서 출발해 픽셀 하나를 집고 구멍에 운반한 뒤 사라진다. 픽셀 예약은 중복 수집을 막는다. 수량만큼 운반을 마치면 상자 자리가 비워진다.
- GAME-04: 모든 픽셀이 구멍에 도착하면 승리한다. 진행 가능한 고양이가 없고 슬롯이 모두 막히거나 제한 시간이 끝나면 실패한다. 재시작과 다음 레벨을 제공한다.
- LEVEL-01: 쉬움·보통·어려움 각각 1~100, 총300레벨. 같은 난이도/레벨은 동일 배치다. 20종 캐릭터/음식 ×5테마로100개 도안을 구성하고 난이도별로 동일 도안과 색을 보존한다. 상자 분할·시간 제약으로 난이도를 구분한다. 모든 레벨의 해법을 자동 검증한다.
- UX-01: 1배/3배 속도, 일시정지, 도움말, 힌트, 레벨 선택, 로컬 진도 저장. 선택은 마우스·터치·키보드로 가능하다. 색과 숫자 외에도 접근성 색 이름을 제공한다.
- UX-02: 게임을 열거나 재시작한 뒤 첫 상자를 성공적으로 배치하기 전까지 제한시간은 시작하지 않는다. 도움말을 닫아도 이전 수동 일시정지 상태를 보존한다. 속도 버튼은 고양이 이동만 가속하며 제한시간 속도는 그대로다.
- UX-03: 현재 선택 가능한 상자와 다음 두 상자의 색·수량을 겹치지 않게 구분한다. 주요 조작은 최소 44px 터치 영역을 제공한다. 빈 슬롯 수와 작업 상태를 표시하고 슬롯이 가득 차면 추가 큐 선택을 비활성화한다.
- UX-04: 고양이의 귀·얼굴·꼬리와 운반 블록을 모바일 크기에서도 식별할 수 있게 그린다. 아이보리 그림 트레이, 그 아래 집 구멍, 다섯 상자 자리를 분리한다. 현재 접근 가능한 픽셀의 테두리를 표시하며 이 표시는 GAME-03 판정과 일치한다.
- UX-05: 힌트는 구성적 해법의 다음 상자를 우선한다. 앞선 활성 상자가 남았어도 움직이는 고양이가 없다면 노출 색과 일치하는 큐 맨 앞 상자를 추천한다. 이는 현재 행동 가능 안내이며 임의로 선택한 모든 상태의 완주 보장은 아니다.

## 광고
ADS-01: 게임 중 강제 광고를 넣지 않는다. 레벨 결과의 자연스러운 전환에 빈도 제한 전면 광고를 사용한다. 사용자가 선택한 보상형 광고는 SDK 보상 이벤트 후에만 힌트를 지급한다. 광고 실패나 인터넷 불가 시 일반 게임은 계속 가능해야 한다. 추천할 수 있는 상자가 없을 때는 보상 광고를 요청하지 않고 현재 대기 상태를 안내한다. 광고 준비·보상 대기 중에는 게임을 정지해 추천 대상이 변하지 않도록 한다. 개발은 테스트 ID, 운영은 별도 등록 ID·동의/개인정보 처리 설정이 필요하다. 수익 금액을 보장하지 않는다.

## 범위
사진은 참고 분석 자산으로 보존한다. 원작 로고·캐릭터를 게임 자산으로 재사용하지 않는다. 계정·서버·결제·랭킹은 이번 범위가 아니다. 실제 앱스토어 제출과 운영 광고 승인은 소유자 계정 설정 이후의 배포 작업이다.

## 최신 UX 결정
사진의 원본 캐릭터는 개미지만 사용자의 추가 요청에 따라 현재 게임 표현은 고양이로 변경했다. 사진 재분석과 변경 근거는 [UX 감사 기록](../flow/2026-10-01-cat-ux-improvements.md)을 따른다.

- WALK-01: 고양이는 아래 슬롯과 공용 통로에서 출발해 빈 셀을 따라 직각으로 걷고, 목표 앞에서 잠깐 멈춰 집은 뒤 같은 빈 길과 통로를 거쳐 집에 돌아온다. 남은 블록이나 구멍을 대각선으로 가로지르지 않는다.

최신 도안·노출·보행 변경과 검증 범위는 [피드백 반영 기록](../flow/2026-10-01-artwork-and-walking.md)을 따른다.
