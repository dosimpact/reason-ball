# 흐름 노드 관리 편집만 허용

- 요청: 흐름 노드 관리에서 노드 추가·삭제 불가.
- 변경: 추가·삭제 버튼과 UI 요청 핸들러 제거. 기존 노드 선택·이름/연결 문서 수정·드래그는 유지.
- 범위: 작업 공간 UI. 기존 저장 데이터와 서버 API 계약은 변경하지 않음.
- stock: 프로젝트 관리.
- 검증: 진행 중.

- 완료: lint·production build(타입 검사 포함) 통과. 임시 DB/소유 서버에서 추가·삭제 버튼 없음, 기존 노드 이름/연결 수정, 드래그 저장·실패 복원 회귀 2/2 통과. 4000 서비스에 반영.
