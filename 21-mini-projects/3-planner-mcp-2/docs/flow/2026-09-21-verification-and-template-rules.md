# 재검증·결과 문서·템플릿 인스턴스 합의

- 날짜: 2026-09-21
- 맥락: 재검증 체크 처리, AI 결과 표시, 템플릿 변경 전파에 대한 사용자 답변.
- 변경: REQ-006에 AI의 영향 항목 선택적 체크 해제와 이를 위한 MCP 조회·수정 인터페이스를 명시. REQ-007에 항목별 결과 표시 및 AI 결과 자식 문서를 추가. REQ-008에 템플릿 변경으로부터 기존 인스턴스 독립성을 명시.
- 이유: 불필요한 재검증을 줄이고 검증 기록을 설계와 연결하며 원본 템플릿 변경으로 기존 문서가 변하지 않도록 함.
- 영향 stock: 비즈니스 설계의 REQ-006~008 및 미정 사항. master-requirement.md 동기화.
- 해석: 인스턴스 불변은 템플릿 변경에 대한 불변으로 기록. 기존 합의의 문서 편집·상태 갱신은 유지.
- 검증: 사용자 답변 세 항목과 문서 반영 내용을 대조. 코드 변경 없음.
- 후속: 반복 검증 결과 문서의 누적 방식과 AI·사람 체크 표시 구분은 미정. 이전 기록의 체크 해제 범위 미정 사항은 이번 합의로 대체.
