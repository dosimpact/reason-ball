# 0005: 설계 입력 보존·사용자 검토·구현 에이전트 인계

날짜: 2026-09-15

상태: 여섯 제안 방향은 사용자 수락으로 확정. 상세 필드·전이·버전 계약은 제안.

## 변경 전후와 이유

- 이전에는 설계 작성과 실시간 시각화 중심이었으며 프로젝트 생성·본문 조회·검토 역할이 미정 또는 제안이었습니다.
- 원본 입력 보존, 사실·가정·질문 구분, 사용자 검토·승인, 프로젝트 생성과 초기 화면을 요구사항으로 반영합니다.
- MVP UI는 조회·검토·질문·승인을 담당하며 본문 직접 편집은 제외합니다.
- 별도의 구현 에이전트가 설계 완료 후 MCP로 인덱스와 본문을 가져가 개발합니다.
- 승인된 설계와 AI 작성물을 구분하고 대화 기록 없이도 개발에 필요한 맥락을 전달하기 위함입니다.
- 입력 저장 위치, revision 보존, 상태 전이 상세 등 선택이 남은 부분은 제안으로 구분합니다.
