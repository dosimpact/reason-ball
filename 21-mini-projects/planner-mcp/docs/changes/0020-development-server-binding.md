# 개발 서버 기본 바인딩 변경

- 날짜: 2026-09-15
- 상태: 확정

## 변경 전후

- 변경 전: `dev`는 `127.0.0.1:3100`, `dev:lan`은 `0.0.0.0:3100`에서 실행했다.
- 변경 후: `dev`와 `dev:lan` 모두 `0.0.0.0:4000`에서 실행한다.
- 생산 실행 명령인 `start`의 `127.0.0.1:3100` 기본값은 변경하지 않았다.

## 이유

사용자가 기본 개발 명령으로 서비스를 모든 네트워크 인터페이스의 4000번 포트에 바인딩하도록 요청했다. 기존 `dev:lan` 진입점도 같은 설정으로 유지해 명령에 따른 포트 차이를 없앴다.
