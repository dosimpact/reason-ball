# 프로젝트 목록 화면 추가

날짜: 2026-09-15
상태: 프로젝트 목록 구현·검증 완료. 협업 UX 확장은 미확정 제안.

- 사용자 요청: 사이드바뿐 아니라 프로젝트 리스트를 볼 수 있는 화면 추가.
- 이전: 프로젝트 미선택 시 프로젝트 존재 여부와 무관하게 첫 프로젝트 안내 표시.
- 이후: 중앙 목록에 이름·설명·열기 버튼을 표시하고 전체 프로젝트로 복귀한다. 최초 로딩·실패·빈 목록을 구분한다.
- 기존 SSE 조회 결과를 재사용하며 새로운 저장 형식이나 인증 기능은 추가하지 않았다.
- 영향: 현재 요구사항 01, 상세 계약 10, README, workspace, CSS, completion E2E.
- 검증: 목록 표시·카드 선택·전체 목록 복귀·모바일·새로고침 보존을 기존 E2E에 추가했다. 최종 실행 결과는 종료 후 아래 기록한다.

## 협업 UX 후속 제안 (미확정·미구현)

후속: 사용자 구현 요청에 따라 [0015](0015-collaboration-ux.md)에서 채택·구현했다. 아래는 제안 당시 기록이다.

사용자는 전체 UX를 협업 시나리오 관점에서 검토해 달라고 요청했다. 아래는 에이전트 제안이며 구현 범위 확정이 아니다.

- 프로젝트 홈을 문서 목록만이 아니라 검토할 초안·답변할 질문·참조 변경·인계 대상으로 구성한다.
- 입력 자료 전달부터 설계 AI 작업 지시 복사, 검토 피드백, 고정 revision 인계까지 다음 행동을 연결한다.
- 승인과 구현 완료를 구분하고, 앱이 실제 에이전트를 실행하지 않을 때 실행 중인 것처럼 표시하지 않는다.
- 사용자 인증은 기존 제외 범위를 유지한다. 이름 표시는 인증된 작성자나 권한 통제를 뜻하지 않는다.

- 목록 카드 선택·복귀·모바일·실시간 추가·새로고침 유지 검증을 포함한다.
