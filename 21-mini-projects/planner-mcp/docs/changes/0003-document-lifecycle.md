# 0003: 현재 설계와 변경 이력 분리

날짜: 2026-09-15

상태: 확정 — 사용자가 요청한 두 가지 문서 유형을 적용합니다.

## 변경 전후

- 이전: 현재 설계는 `docs/design/`, 결정은 `docs/decisions/`에 있었으며 현재 원칙을 결정 기록에서도 참조했습니다.
- 이후: 계속 유지하는 현재 설계는 `docs/design/`, 변경 사항과 결정 이유는 `docs/changes/`로 구분합니다.
- 기존 결정 0001·0002는 변경 이력으로 이동하고 본문은 과거 기록으로 보존합니다.
- 현재 원칙은 `00-principles.md`로 모으고 AGENTS에는 문서 운영과 원본 참조 규칙을 둡니다.
- 아키텍처의 모듈 경로 미정 표현을 이미 확정된 Flow Spec feature와 구분합니다.

## 이유

작업자가 과거 이력을 조합하지 않고 현재 설계만으로 작업하고,
변경 배경은 필요할 때 별도로 확인할 수 있도록 합니다.

## 영향 문서

- [AGENTS.md](../../AGENTS.md): 작업 재개·변경 기록·일관성 점검 규칙.
- [현재 설계 목차](../design/README.md): 문서별 원본 책임.
- [현재 원칙](../design/00-principles.md): 계속 적용할 기반 원칙.
- [요구사항](../design/01-requirements.md), [아키텍처](../design/02-architecture.md): 현재 원본 참조.
- [프로젝트 README](../../README.md): 두 문서 유형의 진입점.

## 검증

- 이동 후 Markdown 로컬 링크와 기존 결정 경로 참조를 확인합니다.
- 문서 운영 변경이며 애플리케이션 코드·패키지 의존성 변경은 없습니다.
