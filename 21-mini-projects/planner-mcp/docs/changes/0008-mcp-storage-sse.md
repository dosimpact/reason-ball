# 0008: MCP·저장·SSE 기본 계약 수락

날짜: 2026-09-15

상태: 사용자 수락으로 기본 방향 확정, 세부 구현 제안은 구분 유지.

## 변경 전후와 이유

- 미정·제안이던 작업 순서, revision 충돌, 재시도 중복 방지, 문서별 저장 결과와 구분된 오류를 기본 계약으로 채택합니다.
- 프로젝트 메타데이터와 문서 JSON을 분리하고 인덱스는 메모리 파생 데이터로 정합니다.
- SSE 식별 정보, 재연결 최신 조회, 손상 파일의 명시적 오류 처리를 채택합니다.
- 운영 환경·외부 편집 지원 수준·승인 문서 인계 집합은 아직 선택이 필요합니다.

## 영향과 검증

- [상세 계약](../design/08-mcp-storage-sse.md)을 추가하고 요구사항·아키텍처·카탈로그·목차를 연결합니다.
- 로컬 문서 링크와 변경 공백을 확인합니다. 런타임 구현은 없습니다.
