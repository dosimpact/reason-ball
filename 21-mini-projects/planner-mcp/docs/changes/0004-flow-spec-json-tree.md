# 0004: Flow Spec JSON 트리 원본과 탐색 설계

날짜: 2026-09-15

상태: JSON 트리 관리 방향 확정; 세부 모델과 탐색 방식은 제안.

## 변경 전후와 이유

- 이전: 텍스트 source를 원본으로 저장하고 위치 기반 ID로 파생 트리를 구성하는 제안.
- 이후: JSON 트리를 원본으로 저장하고 텍스트는 가져오기·내보내기 표현으로 사용합니다.
- 안정적인 노드 ID, 전위 DFS, 파생 조회 인덱스, 표시 노드 탐색을 제안합니다.
- 사용자가 요청한 트리 구조와 탐색 전략을 구체화하고 편집 후 UI 접힘 상태를 유지하기 위함입니다.
- 텍스트 전체 재가져오기는 ID가 새로 생성되므로 일반 JSON 갱신과 구분합니다.

## 영향과 검증

- [요구사항](../design/01-requirements.md): REQ-016 추가.
- [아키텍처](../design/02-architecture.md), [카탈로그](../design/03-document-catalog.md), [Flow Spec](../design/04-flow-spec.md): 원본 저장 모델 정합성 갱신.
- [JSON 모델·탐색](../design/05-flow-spec-tree.md): 상세 원본 추가.
- 문서 링크 및 JSON 예시 구문·구조를 검증합니다. 런타임 구현·테스트는 아직 없습니다.
