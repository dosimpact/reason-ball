# 협업 시나리오 기반 UX

날짜: 2026-09-15
상태: 구현·자동 검증 완료

후속: [0016](0016-startup-recovery.md)에서 초기 네트워크 실패 시나리오 누락을 확인하고 로딩 복구를 보완했다.

## 요청과 변경

- 사용자 요청: 앞선 협업 UX 고민을 실제 구현까지 진행.
- 이전에는 프로젝트 진입 시 문서 탭을 보여줬다. 이후 프로젝트 홈에서 다음 행동과 상태를 확인하고 검토함에서 질문·초안·승인 대기·기준 변경을 처리한다.
- 전체 목록에도 미해결 질문과 검토 대기를 요약한다. 홈은 최근 수정 문서와 입력·인계 이동, 설계 AI 작업 지시 복사를 제공한다.
- 질문별 답변은 optional questionId가 연결된 기존 검토 의견으로 저장한다. 저장 시 revision과 requestId를 확인하고 없는/해결된 질문에 대한 답변을 거부한다. 답변만으로 질문 해결·승인을 수행하지 않는다.
- 자동 AI 실행·인증·구현 완료 상태는 추가하지 않았다. 승인 버전 인계는 기존 계약을 재사용한다.
- 요약은 기존 파일 조회를 조합하며 현재 모든 프로젝트를 조회하는 로컬용 구현이다. 일부 문서 조회 실패는 경고로 표시한다. 대규모 원격 팀 성능을 검증한 결과는 아니다.

## 영향과 검증

- 현재 설계 01·06·09·11, README와 설계/변경 목차를 갱신했다.
- codebase-memory: 오래된 인덱스와 제외된 테스트는 소스 직접 확인으로 보완했다.
- apb-unit-test-write: 정상 답변·중복 방지·버전 충돌·없는 질문과 빈/실패 요약을 검증했다.
- apb-playwright-e2e: 전용 서버에서 홈·검토함의 접근성 트리를 확인하고 기존 화면 이동과 협업 시나리오를 보강했다.
- 단위 테스트 89개, lint, typecheck 통과. 기존 E2E 11개 통과.
- 질문 답변 → MCP 확인 → AI 반영 → 사용자 승인 → 고정 인계 및 모바일 시나리오를 포함한 최종 실행 결과는 아래에 기록한다.
