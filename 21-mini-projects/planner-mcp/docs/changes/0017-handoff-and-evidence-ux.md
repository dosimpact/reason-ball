# 인계 선택 버전과 근거 탐색 보완

날짜: 2026-09-15
상태: 설계 비교 진행 중. 이 기록은 인계·근거 탐색의 한정된 검증이며 전체 요구사항 재감사 완료를 뜻하지 않는다.

후속: [0018](0018-write-response-recovery.md)에서 일반 UI 쓰기의 응답 유실 복구를 보완했다.

## 비교 기준과 발견

사용자 요청은 최초 설계와 대조한 누락 확인 및 사용성 개선이다. 01 요구사항과 06 생명주기·08 저장 계약을 기준으로 현재 코드 및 테스트를 확인했다. 과거 0010의 PASS 표를 현재 완료 판정으로 재사용하지 않았다.

| 비교 항목 | 변경 전 | 조치 |
| --- | --- | --- |
| REQ-022·06: 사용자가 고른 승인 revision 인계 | Partial: MCP는 고정 버전을 지원하지만 UI는 ID만 저장하고 묶음 생성 시 현재 버전을 선택 | 선택 순간 revision 저장, 새 초안 이후에도 유지, 차이 안내·선택 해제·역사 버전 확인 제공 |
| REQ-017·018: 원본 보존 및 근거 구분 | Matched: 원문과 sourceId는 보존되지만 문서에서는 제목만 표시 | Extra UX: 설계 맥락에서 원문·수집 시각·링크를 펼쳐 읽기. 누락 근거 경고 |
| 08: 응답 유실 후 동일 쓰기 재시도 | Partial: 서버 영수증은 지원하지만 일반 UI 재제출에서 새 requestId 생성 | 후속 보완 필요. 일반 생성·입력·의견의 응답 유실과 재제출 검증 필요 |

이 표의 변경 전 Match Rate는 1 / 3 = 33.3%다. 의도적으로 확인한 세 계약의 부분 비교이며 전체 제품 구현률이나 코드 커버리지 수치가 아니다. 원문 펼치기는 최초 설계의 미구현 기능으로 계산하지 않고 사용성 개선으로 구분한다.

## 영향

- 현재 설계: 06은 선택 시점 버전 고정의 UI 의미를 명시하고, 11은 근거 원문 탐색을 정의한다.
- 코드: `src/widgets/planner-workspace/ui/workspace.tsx`.
- 저장 포맷·MCP 계약·사용자 데이터는 변경하지 않는다. 인증은 계속 제외한다.
- 인계 선택은 현재 화면 세션의 상태이며 브라우저 재시작 후 선택 복원 기능을 추가한 것은 아니다.

## 검증

- `completion.spec.ts`: 승인 문서 선택 → MCP로 새 초안 작성 → SSE 변경 안내 → 원래 승인 revision 묶음 생성 및 실제 본문 검증.
- `workspace.spec.ts`: 근거 원문 펼치기 → 수집 시각 확인 → MCP 설계 수정 뒤에도 원문 유지 확인.
- `pnpm --filter planner-mcp test`: 9개 파일·89개 PASS.
- `pnpm --filter planner-mcp lint`, `typecheck`: PASS.
- `pnpm --filter planner-mcp test:e2e`: 생산 빌드·Chromium 17개 PASS (43.8초). 전용 서버 `127.0.0.1:63561`과 임시 데이터는 실행 스크립트가 종료 시 정리했다.

## 도구 사용과 한계

- apb-gap-analysis: Matched/Partial/Extra를 구분했다. PGV gradate가 없어 저장소 현재 설계로 대체했으며 PGV 승인 판정은 하지 않는다.
- apb-playwright-e2e: 기존 Chromium 시나리오를 보강해 전용 서버·임시 데이터에서 검증한다. Playwright MCP 도구는 제공되지 않아 CLI를 사용했다.
- codebase-memory: 관련 Workspace 경계 조회와 coverage 확인 후, 오래된 그래프와 제외된 테스트는 현재 소스로 확인했다.
- 전체 요구사항의 재감사와 일반 UI 쓰기 재시도 보완은 계속 진행한다. 실제 Figma 계정 API는 이 테스트에서 검증하지 않는다.
