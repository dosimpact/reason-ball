# 0001: 프로젝트 내부에서 설계 문서 관리

상태: 확정

기록 유형: 과거 결정. 문서 관리 방식은 [0003](0003-document-lifecycle.md)으로 대체되었습니다.

날짜: 2026-09-15

## 배경

Planner MCP는 기존 pnpm workspace의 하위 프로젝트이며 설계를 먼저 진행합니다.
프로젝트별 설계와 구현 변경을 같은 경로에서 추적할 위치가 필요합니다.

## 결정

- 설계 원본과 목차는 `docs/design/`에 둡니다.
- 주요 결정 기록은 `docs/decisions/`에 둡니다.
- 프로젝트 `README.md`를 문서 진입점으로 사용합니다.
- 패키지는 `private: true`로 설정하고 상위 workspace 및 lockfile을 공유합니다.

## 영향

설계와 구현을 함께 버전 관리할 수 있습니다. 저장소 공통 문서가 이 프로젝트를
소개할 경우 원본을 복제하지 않고 프로젝트 문서로 연결합니다.
