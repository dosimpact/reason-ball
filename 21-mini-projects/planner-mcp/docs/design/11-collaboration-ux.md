# 협업 UX

상태: 사용자 요청으로 채택. 사용자·설계 AI·구현 AI의 협업이며 인증과 자동 에이전트 실행은 제외한다.

- 전체 프로젝트 목록은 미해결 질문·검토 대기·최근 변경을 요약한다.
- 프로젝트 홈은 입력 → 설계 요청 → 질문/검토 → 승인 → 인계의 다음 행동을 제공한다. 문서 탭과 검토함으로 이동할 수 있다.
- 검토함에는 미해결 질문, 답변 기록/설계 반영 대기, 초안, 승인 대기, 기준 변경 문서를 모은다. 각 항목에서 원문으로 이동한다.
- 질문 답변은 questionId가 연결된 검토 의견으로 기록한다. 문서 revision과 requestId를 검사한다. 답변 저장은 resolved나 approval을 바꾸지 않는다. 설계 AI가 본문·질문 상태에 반영해야 해결된다.
- 작업 지시는 projectId, 입력 자료 조회, 질문/검토 의견 확인, 충돌 검사, 사용자 승인 금지를 포함한 복사 가능한 텍스트다. 복사 불가 시 수동 복사를 제공한다. 앱에서 에이전트를 실행하거나 전송 완료로 표시하지 않는다.
- 최근 변경은 현재 문서의 updatedAt 순서이며 전체 활동 감사 로그를 뜻하지 않는다. 인계는 기존 고정 승인 버전 계약을 유지하며 구현 완료를 주장하지 않는다.
- 설계 맥락의 근거는 제목만 나열하지 않고 연결한 입력 원문·수집 시각·URL을 그 자리에서 펼쳐 확인한다. 원문은 가공된 사실·가정과 구분하며 찾을 수 없는 근거는 경고로 표시한다.
- 요약 조회 실패·손상은 경고로 드러낸다. 요약을 0건으로 조용히 대체하지 않는다. SSE 후 다시 조회하고 이전 요청 결과는 버린다.
- 첫 조회는 SSE ready와 독립적으로 시작한다. 실시간 연결 실패 시에도 조회·수동 새로고침이 가능하다. 협업 요약은 목록과 별도로 로딩하며 실패 시 재시도를 제공한다. 브라우저의 읽기 API 요청은 15초 후 대기를 중단하고 오류를 안내한다. 쓰기는 30초 후 결과 미확인으로 표시하며 원래 요청의 재시도 UX는 [08](08-mcp-storage-sse.md)을 따른다.
- 검증: 홈/검토함 이동, 답변 기록과 미해결 유지, AI 반영 후 해결, 승인/인계, 기준 변경, 모바일 및 기존 회귀 테스트.
