# 5개 도메인 기능 확정

- 날짜: 2026-09-21
- 맥락: 사용자가 제안된 5개 영역을 도메인 기능으로 확정하도록 요청.
- 변경: DEC-001 — 프로젝트 관리, 템플릿 관리, 문서 관리, 진행·검증 관리, AI 작업 안내로 책임 구분. 각 도메인의 INDEX.md 생성 및 문서 지도 연결.
- 보완: 앞서 요청한 정형 공용부·체크리스트 요구를 REQ-009로 master-requirement.md와 비즈니스 설계에 반영.
- 이유: 최소 MCP 설계를 기능별 책임에 따라 진행하고, 본문과 상태 및 전체 작업 절차의 경계를 명확히 함.
- 영향 stock: 통합 비즈니스 설계, 공통 시스템 설계, 공통 기술 지도, 5개 도메인 진입 문서. 요구사항과 전체 문서 지도도 동기화.
- 검증: 수정·생성 문서의 로컬 링크 대상 존재 및 5개 식별자 일치 확인. 코드 변경 없음.
- 후속: 도메인별 MCP 입력·출력·오류 계약은 미작성. 서버·패키지 분리와 상세 도구 목록을 확정한 것은 아님.
