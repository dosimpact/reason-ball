# 문서 관리

상태: 핵심 기능 구현. [MCP·REST 계약](../tech-shared/interfaces.md)에서 입력과 도구 목록을 확인합니다.

- 식별자: `document-management`
- 책임: 템플릿 인스턴스 생성, 본문 편집, index·부모·자식 관계, Overview 관리.
- 근거: [시스템 설계의 DEC-001](../tech-shared/system-design.md), [통합 비즈니스 설계](../project-design/business-design.md).

## 맥락 안에서 생성·탐색

- index 및 문서 상세 상단에 하위 문서 목록과 만들기 CTA가 있습니다. 생성 Dialog는 상위 문서와 프로젝트를 표시하고 parentId/phase를 자동 지정합니다. 생성 후 새 문서를 엽니다.
- 왼쪽 카탈로그는 단계 탭·문서 검색·부모/자식 들여쓰기를 제공합니다. 문서 상세에서 부모 문서로 돌아갈 수 있습니다.
- 미저장 문서가 있을 때 문서/프로젝트/탭 이동과 새 하위 생성은 확인 Dialog를 거칩니다. 취소하면 초안을 유지합니다.

## 문서 확장 (REQ-012, 구현)

- 문서는 본문·체크리스트 외에 확장 목록을 가집니다. 첫 지원 타입은 `react-flow-diagram`입니다.
- 문서 관리에서 확장을 추가하고, 해당 문서의 확장 영역에서 React Flow 렌더링 결과를 봅니다.
- AI는 MCP로 다이어그램을 조회·작성·수정할 수 있습니다. UI와 MCP는 같은 확장 데이터를 사용합니다.
- 프로젝트 단계/문서 관계를 자동 표시하는 캔버스와 별개의 문서 첨부 다이어그램입니다.

구현 계약:

- 확장 데이터: `id`, `type`, `title`, `schemaVersion`, `data`. 다이어그램 data는 `nodes`(id·label·position), `edges`(id·source·target)를 포함하는 정형 JSON입니다.
- React 실행 코드 대신 선언적 데이터를 저장·렌더링합니다. 노드 ID 중복, 존재하지 않는 연결 대상, 잘못된 좌표를 검증합니다.
- 저장은 문서의 `expectedRevision`으로 충돌을 검출합니다. 검증 완료 문서의 확장 변경은 기존 설계 변경/reopen 정책을 따릅니다.
- UI는 확장 추가·제거, 제목·노드 이름·연결 폼, 노드 드래그·연결점 조작을 제공합니다. 문서/템플릿 저장 시 반영하고 템플릿 미리보기에도 렌더링합니다.
- 확장 최대 10개, 노드 100개, 연결 200개. schemaVersion은 1이며 다른 버전은 거부합니다.

## Notion 스타일 Markdown 편집

- 본문은 서식 편집 / Markdown 원문 / 미리보기 모드를 제공합니다. 제목·목록·체크 목록·인용·표·코드·Mermaid 블록과 굵게·기울임·취소선·인라인 코드를 지원합니다.
- 빈 문단에서 `/`를 입력하면 블록 메뉴가 열립니다. 검색 후 ↑/↓·Enter로 선택하거나 클릭하며 Esc로 닫습니다.
- 목록에서 `→`(Tab)는 들여쓰기, `←`(Shift+Tab)는 내어쓰기입니다. 예: ‘설계’와 ‘컴포넌트’ 목록을 작성한 뒤 두 번째 항목에서 →를 누르면 설계 아래 자식 항목으로 이동하고 ←로 복원합니다.
- 저장 형식은 기존 Markdown 문자열이며 MCP·revision·미저장 보호는 유지합니다. 원문 모드 전환이나 단순 조회만으로 내용을 다시 저장하지 않습니다. HTML/각주 등 확장 문법은 원문 모드로 보존합니다.
- Mermaid는 코드 블록으로 편집하고 미리보기에서 렌더링합니다. 본문의 체크 목록은 공용 진행 체크리스트와 별개입니다.

## CodeWeave 확장

- 확장 영역의 CodeWeave 추가 버튼으로 여러 개를 첨부하고 제목·원문을 편집합니다. React Flow와 같은 문서에 혼합할 수 있습니다. 저장 버튼으로 확정합니다.
- 들여쓰기 트리와 변경 표시·주석을 렌더링하며 전체/가지 접기·펼치기, 라인 상세 정보를 제공합니다. 문법 오류는 해당 라인을 표시하고 저장을 거부합니다.
- 템플릿 미리보기·인스턴스 복사·revision·reopen 정책은 기존 확장과 같습니다. [core 및 어댑터 계약](../codeweave/INDEX.md)을 참고합니다.
