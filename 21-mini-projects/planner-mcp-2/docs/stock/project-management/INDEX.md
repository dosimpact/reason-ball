# 프로젝트 관리

상태: 핵심 기능 구현. [MCP·REST 계약](../tech-shared/interfaces.md)에서 입력과 도구 목록을 확인합니다.

- 식별자: `project-management`
- 책임: 프로젝트 CRUD, 설계·구현·검증 흐름과 노드 관리.
- 근거: [시스템 설계의 DEC-001](../tech-shared/system-design.md), [통합 비즈니스 설계](../project-design/business-design.md).

- 작업 공간: 캔버스·상세 패널 가로 크기 조절, 둥근 단계 노드, 프로젝트 사이드바와 본문의 독립 스크롤을 제공합니다. 좁은 화면에서는 세로 배치를 유지합니다.

- 단계 흐름의 기본값은 설계 → 구현 → 검증 가로 배치입니다. 노드를 드래그해 옮길 수 있고 드롭한 좌표는 프로젝트에 저장되어 재조회 후에도 유지됩니다. 저장 실패 시 오류를 표시하고 저장 전 위치로 복원합니다.

- 상세 패널 상단의 닫기 버튼으로 캔버스를 전체 너비로 확장합니다. 캔버스의 상세 패널 열기 버튼으로 복원하며 저장 전 편집 내용과 조절한 패널 비율을 유지합니다.

## GitHub 스타일 작업 공간

- 사이드바는 프로젝트 검색·목록·새 프로젝트 버튼·설정 메뉴를 표시합니다. 생성/이름변경/삭제는 접근성 있는 Dialog로 제공합니다.
- 프로젝트 선택 시 설계 index 자동 선택. 단계별 문서 탭과 맥락형 생성 버튼을 제공합니다. 흐름은 작게 유지하며 기존 가로 배치·드래그 저장은 유지합니다.
- 상세 패널을 닫은 뒤 다른 문서를 선택하면 상세를 다시 표시합니다. 패널 접기 자체는 초안을 보존합니다.

- 흐름 노드 관리 UI에서는 기존 노드의 이름·연결 문서 수정만 제공합니다. 노드 추가·삭제는 제공하지 않으며 드래그 이동은 유지합니다.

- 설계·구현·검증 단계 아래에 문서 트리를 표시합니다. index는 단계 노드로 대표하고 일반 문서·검증 결과는 parentId를 따라 연결합니다. 부모 없는 문서는 해당 단계 아래에 표시합니다.
- 하위 문서 클릭은 상세를 열며 문서 노드는 자동 배치합니다. 단계 드래그 시 하위 트리도 함께 이동합니다. 문서 추가·삭제 시 화면 범위를 자동 맞춥니다.

- 하위 문서 노드는 문서 아이콘(FileText)과 연한 파란 배경·파란 테두리로 단계 노드와 구분합니다. 둥근 카드 형태를 유지하며 선택 시 진한 파란 테두리로 강조합니다.

- 프로젝트 선택 URL은 `/projects/:projectId`입니다. 클릭·생성 시 주소가 바뀌며 직접 접속·새로고침·뒤로/앞으로 가기로 프로젝트 선택을 복원합니다. 진입 시 설계 index를 기본 표시합니다. 없는/삭제된 프로젝트 주소는 `/`로 복귀합니다. 문서 선택 자체는 URL에 포함하지 않습니다.
